# S87：双中性窗口的带秩精确公式，以及S85失衡族的跨边界修复

日期：2026-10-03。父数学快照：S86 @ `25b4afd50cc37ddac71fbe0b6feb084010c2fa4b`。状态：自含研究稿；未获外部独立审稿或穷尽首创性调查。主猜想、一般宽度三、TEN40仍OPEN；U58状态不变。

## 本轮结果

**S87-TWO-NEUTRAL。** 固定有限核心Q，向同一个双侧窗口插入t点有序链，且该链在旧核心中恰只与两个不可比标签x,z不可比。全部总计数与候选事件x<g_r由六个核心整数(c0,c1,h,b0,b1,i)精确决定：
[
E_t=c_0+c_1(t+1)+h(t+1)(t+2),
]
[
U_{t,r}=b_0+b_1(t+1)+r[i+h(t+2)].
]
因此固定t时方向计数关于实际链秩r是等差数列；最佳链标签由最近整数舍入得到。这把S86“新标签需要带秩切口信息”的接口，在双中性结构中压缩为六整数闭式。

**S87-RANK-SELECT。** 写A_t=b0+b1(t+1)、S_t=i+h(t+2)。若S_t>0，最佳r最小化|A_t+rS_t-E_t/2|。若U_(t,1)≤E_t/2≤U_(t,t)，则某个链标签平衡度至少1/2-S_t/(2E_t)。这依赖“恰两个旧中性标签”的真实结构，不是任意宽度三选择定理。

**S87-GUARD-REPAIR。** 回到S85-TWOSIDED-GUARD同一个宽度三族R_t。旧固定对(1,2)在全部t≥2有概率大于2/3；本轮不撤回该护栏。取新增链g_1<...<g_t和旧标签2，六整数为(4,8,3,2,6,1)，故
[
E_t=3t^2+17t+18,qquad U_{t,r}=(3t+7)r+6t+8.
]
对t≥2，最佳新增链伙伴恰为r=floor(t/2)，且
[
operatorname{bal}_{R_t}(2,g_{lfloor t/2floor})ge 7/16.
]
t=3取等号；t=1唯一链点也给7/19>1/3。于是此前“旧核心对失衡”的整个无限族，均可由依赖实际链长、但在每个给定偏序中预先固定的跨边界标签修复。

## 与主猜想的关系

S86证明已通过的旧标签证书可在核心增广下保持，但一般新标签接口未压缩为少量状态；无界重复类型还否定了无条件type-only小核心目标。本轮在“新增链只有两个旧中性标签”的真实宽度三接口上，将新标签计数压成六个核心整数，并把S85的一个无限失败族完全修复。这说明保留实际重数t与链秩r确实能产生type-only松弛看不到的好对。

仍未证明任意低平衡宽度三对象都含这种双中性链段，也未把六整数与S53的小排序缺陷rho建立一般强制关系。因此这是结构接口，不是全部宽度三或主猜想闭合。
