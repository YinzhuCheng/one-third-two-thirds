# S87：双中性窗口的带秩精确计数与跨边界候选

日期：2026-10-03。父稿：在线 S86。以下概率始终属于相应有限偏序完整线性扩张的均匀律。参数族中的标签规则可以依赖参数 t，但必须在抽取随机扩张之前固定。

## 1. 双中性窗口模型

设 Q 为有限偏序，顶点分成

    V(Q) = D disjoint_union {x,z} disjoint_union F,

并假设 x 与 z 不可比。对每个整数 t>=1 加入新链

    g_1 < g_2 < ... < g_t,

规定每个 d in D 都在全部 g_r 之前，每个 f in F 都在全部 g_r 之后，而全部 g_r 与 x,z 不可比。假定这些是新链在旧核心中的确切关系，即传递闭包不会额外迫使 g_r 与 x 或 z 比较。

对 tau in L(Q)，把旧位置编号为 1,...,n，定义 L(tau) 为最后一个 D 元素的位置（D 空时取 0），R(tau) 为第一个 F 元素的位置减一（F 空时取 n）。新链只能与旧位置 L+1,...,R 内的元素交错。

因为核心中除 D,F 外只有 x,z，

    w(tau) := R(tau)-L(tau) in {0,1,2}.

给定 w=j，t 个有序新点与窗口中 j 个按 tau 固定次序的旧点交错，共有 C(t+j,j) 种。

定义六个核心整数：

- c_j = #{tau : w(tau)=j}, j=0,1；
- h = #{tau : w=2 且窗口顺序是 x,z}；
- b_j = #{tau : w=j 且 x 在窗口之前}, j=0,1；
- i = #{tau : w=1 且 x 是窗口中的唯一旧点}。

当 w=2 时窗口恰由 x,z 组成。把二者交换仍是 Q 的线性扩张：二者仍处在全部 D 之后和全部 F 之前，且 x,z 不可比。因此两种窗口顺序数量相同，故 c_2=2h。

## 2. S87-TWO-NEUTRAL：六整数闭式

**定理 1。** 对所有 t>=1，

    E_t := e(P_t)
         = c0 + c1(t+1) + h(t+1)(t+2).

对 1<=r<=t，令 U_(t,r) 为 P_t 中事件 x<g_r 的完整扩张数，则

    U_(t,r)
      = b0 + b1(t+1) + r [ i + h(t+2) ].

### 证明

总数按 w=0,1,2 求和：

    E_t = c0
        + c1 C(t+1,1)
        + 2h C(t+2,2),

即第一式。

再计数 x<g_r。

1. w=0。若 x 在窗口前，唯一插回满足事件；否则不满足。贡献 b0。
2. w=1。若 x 已在窗口前，全部 t+1 种插回满足，贡献 b1(t+1)。若 x 是窗口唯一旧点，则 x 可放在新链的 t+1 个槽位，恰有 r 个槽位位于 g_r 之前，贡献 ir。
3. w=2。若窗口旧顺序是 x,z，把两个旧点在总长 t+2 的交错中的位置记作 p<q。x<g_r 当且仅当 p<=r，因此计数为

       sum_{p=1}^r (t+2-p)
       = r(t+2) - C(r+1,2).

   若窗口顺序是 z,x，则 x<g_r 当且仅当 q<=r+1，计数为 C(r+1,2)。两种旧顺序各有 h 条核心扩张，相加得到 h r(t+2)。

合并即得第二式。

### 2.1 最佳链秩

写

    A_t = b0 + b1(t+1),
    S_t = i + h(t+2).

于是

    U_(t,r) = A_t + r S_t.

若 S_t=0，所有链标签与 x 的方向概率相同。若 S_t>0，使 (x,g_r) 最平衡的 r 恰是 1<=r<=t 中最小化

    |A_t + r S_t - E_t/2|

的整数。

因此最佳 r 是把实数

    alpha_t = (E_t/2 - A_t)/S_t

舍入到最近整数，再截断到区间 [1,t]。

特别地，如果

    U_(t,1) <= E_t/2 <= U_(t,t),

则最近整数造成的方向计数误差至多 S_t/2，所以存在链标签满足

    bal_Pt(x,g_r) >= 1/2 - S_t/(2E_t).

这是双中性结构内部的精确选择公式，并不声称任意宽度三偏序都含这种窗口。

## 3. S85-TWOSIDED-GUARD 的六整数

沿用 S85 的七点核心，严格前驱掩码为

    Q = (0,1,0,3,15,3,31),

Hasse 边为

    0<1, 1<3, 1<5, 2<4, 3<4, 4<6.

取

    D={0,1}, F={4,5,6}, x=2, z=3.

加入 t 点链 g_1<...<g_t，位于 D 上方、F 下方，并与 2,3 不可比。这正是 S85 的 R_t。S85 已证明旧固定对 (1,2) 对全部 t>=2 都有 p(1,2)>2/3；本轮不撤回这一护栏。

Q 恰有 18 条线性扩张。按窗口分类：

- w=0 共 4 条，其中 x=2 在窗口前 2 条，所以 c0=4,b0=2；
- w=1 共 8 条，其中 x 在窗口前 6 条，x 为唯一窗口点 1 条，x 在窗口后 1 条，所以 c1=8,b1=6,i=1；
- w=2 共 6 条，窗口必为 2,3，两种顺序各 3 条，所以 h=3。

定理 1 给出

    E_t = 3t^2 + 17t + 18,

以及事件 2<g_r 的方向数

    U_(t,r) = (3t+7)r + 6t + 8.

第一式与 S85 的总扩张公式一致；第二式是本轮新增的带秩跨边界方向谱。

## 4. S87-GUARD-REPAIR：全参数 7/16 见证

使 U_(t,r) 最接近 E_t/2 的实数秩为

    alpha_t
      = [E_t/2 - (6t+8)]/(3t+7)
      = (3t^2+5t+2) / [2(3t+7)].

### 4.1 偶数 t

令 t=2m, m>=1。则

    m - alpha_t = (2m-1)/(6m+7),

严格位于 (0,1/2)，所以最近合法整数是 r=m=t/2。

代入可得

    2U_(t,t/2) - E_t = 2t-2.

因此

    bal(2,g_(t/2)) = 1/2 - (t-1)/E_t.

又

    E_t - 16(t-1) = 3t^2+t+34 > 0,

所以平衡度严格大于 7/16。

### 4.2 奇数 t

令 t=2m+1。对 t>=3 即 m>=1，

    alpha_t - m = (m+5)/(6m+10),

严格位于 (0,1/2)，所以最近合法整数是

    r=m=(t-1)/2=floor(t/2).

此时

    2U_(t,r) - E_t = -(t+9),

故

    bal(2,g_r) = 1/2 - (t+9)/(2E_t).

同时

    E_t - 8(t+9) = 3(t+6)(t-3) >= 0.

因此

    bal_Rt(2,g_floor(t/2)) >= 7/16    for all t>=2.

t=3 恰取等号。因为 floor(t/2) 是最近整数，它也是所有链标签 g_r 中与旧标签 2 组成的最佳候选。

当 t=1 时只有 g_1，E_1=38，U_(1,1)=24，因此平衡度为 14/38=7/19>1/3。

**推论。** S85-TWOSIDED-GUARD 的整个族 R_t,t>=1 都有显式跨边界平衡对：t=1 取 (2,g_1)，t>=2 取 (2,g_floor(t/2))；后者统一至少达到 7/16。

这里不是在随机扩张后选标签。对每个确定参数 t，标签秩先由 t 确定，再在原完整均匀扩张律中计算概率。

## 5. 与主猜想的连接和准确限制

S86 的一般核心增广公式指出，涉及新点的候选通常需要带秩切口计数，并没有普遍低维状态。本轮在“新链对旧核心恰有两个中性不可比标签”的结构中把接口压缩为六个整数，且方向谱关于链秩完全线性。

S85 的失衡族给出真实校准：旧核心对 (1,2) 在 t>=2 失效，但同一个造成失效的外部链本身含更强的跨边界见证。这支持“证书失败时迁移候选到有实际容量的外部链段”，而不是继续要求 type-only 核心对。

仍未证明：

1. 任意潜在反例存在这种只有两个旧中性标签的链段；
2. 固定最大不可比度或全局低平衡反设会迫使半点 E_t/2 落入某个 S87 等差谱的有效秩区间；
3. 六整数与 S53 的 rho 或 S62 共同多数序之间存在一般强制不等式；
4. 7/16 只属于 S85 这一明确族与给定候选规则，不是一般宽度三界，也未证明为该偏序全局最优平衡常数。
