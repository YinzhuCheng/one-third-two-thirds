# S87：双中性窗口的带秩精确计数与跨边界候选

日期：2026-10-03。父稿：在线S86。以下所有概率均为相应有限偏序完整线性扩张的均匀律。固定标签在随机扩张之前选定；参数族中允许标签规则依赖偏序参数t，但不能依赖随机扩张结果。

## 1. 双中性窗口模型

设Q为有限偏序，顶点恰分成
[
V(Q)=Dsqcup{x,z}sqcup F,
]
其中x与z不可比。对每个整数t≥1，加入新链
[
g_1<g_2<cdots<g_t,
]
并规定它在旧核心中的确切关系为
[
d<g_r (din D),qquad g_r<f (fin F),
]
而所有g_r与x,z不可比。假定这些关系与Q共同生成一个偏序P_t；“确切”意味着传递闭包不会额外迫使g_r与x,z比较。

取tau∈L(Q)。用1,...,n表示旧位置，定义
[
L(	au)=max({operatorname{pos}_	au(d):din D}cup{0}),
]
[
R(	au)=min({operatorname{pos}_	au(f):fin F}cup{n+1})-1.
]
新链可与旧扩张交错的旧窗口正是位置L+1,...,R。因为核心中除D,F外只有x,z，
[
w(	au):=R(	au)-L(	au)in{0,1,2}.
]

给定w=j，t个有序新点与窗口中j个按tau固定次序的旧点交错，共有binom(t+j,j)种。

定义六个核心整数：

- c_j=#{tau:w(tau)=j}，j=0,1；
- h=#{tau:w=2且x在z前}；
- b_j=#{tau:w=j且x在窗口之前}，j=0,1；
- i=#{tau:w=1且x是窗口中的唯一旧点}。

若w=2，窗口只能由x,z组成。交换二者给出Q线性扩张之间的无固定点对合：两者都在全部D之后、全部F之前，而x与z不可比，所以交换保持所有旧比较。因此c_2=2h。

## 3. 应用于S85-TWOSIDED-GUARD

沿用S85七点核心
[
Q=(0,1,0,3,15,3,31)
]
（严格前驱掩码），Hasse边为
[
0<1,quad1<3,quad1<5,quad2<4,quad3<4,quad4<6.
]
取
[
D={0,1},qquad F={4,5,6},qquad x=2, z=3.
]
加入t点链g_1<...<g_t，位于D上方、F下方，与2、3不可比。这正是S85的R_t。S85已证明旧固定对(1,2)对所有t≥2满足p(1,2)>2/3；本节不改变该事实。

Q共有18条线性扩张。按上述窗口分类：

- w=0共4条，其中x=2在窗口前2条，所以c_0=4,b_0=2；
- w=1共8条，其中x在窗口前6条、x为唯一窗口点1条、x在窗口后1条，所以c_1=8,b_1=6,i=1；
- w=2共6条，窗口必为2、3，两种顺序各3条，所以h=3。

定理1立即给
[
oxed{E_t=3t^2+17t+18,}
]
[
oxed{U_{t,r}=(3t+7)r+6t+8,}
]
其中U_{t,r}计数事件2<g_r。第一式与S85总扩张公式一致；第二式是本轮新增的带秩跨边界方向谱。

## 5. 对主线的意义与限制

S86核心增广公式指出，涉及新点的候选一般需要带秩切口计数，未得到普遍低维接口。本轮在“新链对旧核心恰有两个中性不可比标签”的结构中把接口压缩为六整数，且方向谱关于链秩完全线性。

S85失衡族提供真实校准：旧核心对(1,2)在t≥2失效，但同一个造成失效的外部链本身含更强的跨边界见证。这支持“证书失败时迁移候选到有实际容量的外部链段”，而不是继续要求type-only核心对。

仍缺：

1. 未证明任意潜在反例存在这种只有两个旧中性标签的链段。
2. 未证明固定最大不可比度或低平衡反设会迫使半点E_t/2落入某个S87方向等差谱的有效范围。
3. 未将六整数与S53的rho或S62共同多数序建立一般不等式。
4. 7/16只针对S85这一明确族和给定候选菜单；不声称是该偏序全局最优平衡常数，也不声称改善已知一般宽度三界。
