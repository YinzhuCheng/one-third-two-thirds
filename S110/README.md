# S110：有界不可比度的局部化与有限加性代表

日期：2026-10-10。本目录保存四项通过独立数学研究审查的自含推导及必要有限检查。这里的 D 始终是整个有限偏序的最大不可比度上界；编号来自真实参考线性扩张。概率始终按相应完整偏序的均匀线性扩张律计算。

## 已证明的结果

1. **真实截面计数的统一正性。** [截面比值定理](bounded_cut_profiles.md)证明合法截面的前、后完成数各自相差至多 C_D=(2D)!/D!；合法状态坐标有仅依赖 D 的正下界。逐纤维计数允许非均匀删除。见[独立审查](independent_audit/independent_audit.md)。
2. **一次充分条件拼接。** [单次缓冲拼接](single_splice_stability.md)在明确的内点、间距、完整局部关系和前后缓冲计数接近假设下，保持真实偏序与不可比度，并控制所有保留同侧实际对及新跨缝对的原局部见证。不同实际标签与局部见证分开处理；见[独立审查及重叠切口负控](splice_independent_audit/AUDIT.md)。
3. **实际点对的有限窗口定量逼近。** [局部衰减定理](local_decay/local_probability_decay.md)令 M_D=(2D)!、τ_D=(M_D−1)/(M_D+1)，证明完整偏序与保留实际点对的诱导窗口之间，方向概率误差至多 tanh((log C_D)τ_D^m)。不可比对所需窗口至多 (4m+6)D 点，正确处理物理端点。证明比较真实前后完成权重及完整中段路径律；不把均匀扩张的删除律当成均匀律。见[独立审查](local_decay/independent_audit/independent_audit.md)。
4. **有限加性代表，而非精确阈值归约。** [有限代表定理](finite_epsilon_representative.md)给任意 ε>0 一个可计算 N(D,ε)，使每个 P 都有同度界的 P′，满足 |P′|≤min(|P|,N)、|δ(P′)−δ(P)|≤ε；非链保持为非链。δ 是全部实际不可比对中的最大平衡度。取 R=2D−1、q=2B+3R+6，可用 N=q+2·2^{R(q−1)}−2；B 由原稿的整数不等式确定。标记最大平衡对的完整缓冲片段后缩短有限词路径，每个最终对只与一个原局部见证比较，没有逐次误差累积。见[独立审查](finite_epsilon_audit/AUDIT.md)。

有限代表定理还证明：固定 D≥1，所有有限非链的最佳平衡度下确界 b_D 可由有限类最小值 b_(D,N) 逼近，b_D≤b_(D,N)≤b_D+ε。这里不假设下确界被某个有限偏序取得。该界很大，是有效性结论，不是实用复杂度保证。D=0 的非链类为空；D=1 有精确二点反链代表。

## 条件性结论与未决边界

- 单次拼接的结论须满足其全部充分假设；中心计数接近不自动推出缓冲计数接近。
- 若原偏序的全部不可比对都严格低于 1/3，且有已知余量 γ，则 ε<γ 的代表仍严格低于 1/3。这里 γ 可能依赖原偏序，不能删去。
- 有限逼近不能决定 b_D 是否恰等于 1/3，也没有证明严格反例具有统一非零余量或仅依赖 D 的精确点数界。
- **MAIN33、WIDTH3、TEN40 仍 OPEN；MC3 固定菜单仍 REFUTED；U58 仍 UNDER_AUDIT。** 本目录不改变 S109 的一般平方结果，也不改变旧反例的准确范围。

## 经典方法与先行研究

正矩阵的射影收缩及 de Bruijn／有限词图的路径缩短是经典工具，本目录给出所需的自含实现。有限状态不等于有限多个精确概率。

有界不可比度下随机线性扩张的极限唯一性已有 Brightwell 的 [Linear extensions of infinite posets (1988)](https://doi.org/10.1016/0012-365X(88)90087-8) 及 Brightwell–Łuczak 的 [Order-invariant measures on fixed causal sets (2012)，定理 8.1](https://arxiv.org/pdf/0901.0242) 的先行结果；后者讨论 past-finite causal sets，明确回溯前者关于有限均匀扩张事件极限的工作；不能把其定义范围无条件扩大到任意双侧无限偏序。[Brightwell–Felsner–Trotter (1995)，第 7 节](https://trotter.math.gatech.edu/papers/97.pdf)另回顾了 thin locally finite 双侧偏序及 order-convex 穷尽的情形。本目录的有限窗口定量推导与旧文全部定量引理之间的重合程度尚未完成逐项核对，**不主张新颖性**。逐项来源、准确量词及读取边界见[先行方法核对](prior_art_locality.md)。
