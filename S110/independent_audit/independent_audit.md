## 2. 结论成立所需的精确假设

1. P 是有限偏序。编号 1,…,n 必须来自 P 的一条真实参考线性扩张；任意编号不能直接代入。
2. D 是非负整数，每个点在整个 P 中的不可比点数均不超过 D。允许 D 大于真实最大不可比度，甚至 D>n。
3. r 是 0,…,n 中的整数，J 遍历真正的 r 元下理想。
4. F_J=e(P[J])，B_J=e(P\J)，均为真实诱导偏序的线性扩张数。不能替换为任意递推权重、点对方向细分计数或重置后的随机删除律。
5. 两侧共同基准分别是 e(P[L]) 与 e(P[R])，其中 ℓ=max(0,r−D)、u=min(n,r+D)、L=[ℓ]、R={u+1,…,n}。

在这些假设下，主张的统一常数 C_D=(2D)!/D!、层常数 C_F=(a+t_F)!/t_F! 与 C_B=(b+t_B)!/t_B! 均正确，其中 a=r−ℓ、b=u−r、t_F=min(D,ℓ)、t_B=min(D,n−u)。

## 3. 逐环节证明审查

### 3.1 秩位移与窗口守卫

任一点 x 在任意扩张中的位置等于严格前驱数加 1，再加排在 x 前方的不可比点数。因此两条扩张中的位置差至多 d(x)，特别是相对自然参考编号的位移至多 D。

每个理想 J 的扩张都能与补集扩张连接为全 P 的扩张。于是 i≤r−D 的点必须属于 J，i>r+D 的点不能属于 J。整数端点正确：禁止位移是 D+1，故 L 包含标签 r−D，R 从 r+D+1 开始。

### 3.2 合法支持恰由窗口确定

J↦J\L 的逆映射确为 S↦L∪S。关键不是忽略外部关系，而是自然标号保证 x∈W 的每个前驱都位于 L∪W，不可能来自 R；L 本身又是理想。因此窗口内每个 a 元理想都给出全局合法状态，没有漏掉额外边界约束。

支持个数 1≤k≤binom(a+b,a)≤binom(2D,D) 正确。这里必须保留选点数 a；单独知道一个未标明 a 的窗口偏序，不足以指定正在讨论的截面支持。

### 3.3 删除纤维的实质论证

一般插入引理只需要：不存在 A→K 比较，而且每个 A 点与 K 中至多 D 点不可比。对固定 K 扩张 σ，若一个 A 点 x 位于某个 K 点之前，则排在 x 后面的所有 K 点都必须与 x 不可比。因此至少 m−min(D,m) 个 K 点构成不被插入点打断的固定前缀。

剩下 t 个 K 点的相对次序固定，a 个带标签 A 点任意排列与插入至多给出 binom(t+a,a)·a!=(t+a)!/t! 个候选排列。允许 A 点紧跟固定前缀，故没有少算最左插槽。忽略剩余偏序关系产生上界，方向正确。

连接 σ 与任何 A 扩张给出合法扩张，故每个纤维至少 e(P[A])≥1。逐纤维成立的界可以求和；完全不需要删除后均匀分布或等大纤维。

### 3.4 后向量的对偶

原偏序中窗口补集 T 的标签全部小于 R，因此不存在 R→T 比较。转到对偶后，这恰是初段插入引理所需的“不存在 T→R”。扩张与其逆序一一对应；不可比度不变。因此 B_J 的基准是 e(P[R])，固定区段在原方向中是 R 的后缀。原证明没有误把后缀问题当成同方向初段问题。

### 3.5 正坐标与归一化

F、B 都处于各自共同正基准 c 的区间 [c,Cc]。逐坐标使用其它 k−1 个数的统一上下界，给出的分式界正确。合法理想把所有全局扩张按前 r 点集分割，故 e(P)=Σ_J F_JB_J；μ_J 的乘积常数 C_FC_B 与相应 β_D 正确。

这些结论只涉及合法支持。补零嵌入更大的掩码空间后，非法坐标仍然为零；额外带点对方向的细分坐标也可能为零。原文已明确这些限制。

在同一合法支持上，任意两个合法坐标的比值不超过 C_D，故两个归一化前向向量的 Hilbert 距离至多 2 log C_D；后向同理。该推论也正确，但不意味着有限多个精确权重。

## 4. D=0、D=1 与截断边界

- D=0：P 是链，W=∅，k=1，F=B=e(P[L])=e(P[R])=1；所有比值与归一化界为等式。n=0 也成立。
- r=0 或 r=n：合法支持仅一个状态，所有归一化坐标均为 1。相应的另一方向计数仍按截断基准处理，无须假设其等于 1。
- r<D：L=∅、a=r、t_F=0，故前向界退化为 1≤F_J≤r!，正确。n−r<D 的后向界完全对称。
- n<2D：内部层可能为空，但截断版本仍有定义且成立。D>n 也没有问题，此时可直接落到全部点处于窗口的情形。
- D=1：原常数 C_1=2、α_1=1/3、β_1=1/5 都有效，但不锋利。实际上不可比关系构成互不相交的相邻点对；其余关系全可比，所以 P 是单点与二点反链的序数和。每一秩层有一个或两个理想；有两个时 F 与 B 各自在层内相等，p=q=μ=(1/2,1/2)。这给出可选加强，并不是对原定理的修正。

D=1 的结构断言理由：若不可比点 i<j 的参考编号间还有点 k，则因不可比度≤1，i 与 k、k 与 j 都必须可比；自然标号强迫 i<_P k<_P j，矛盾。不同不可比点对又不共享端点。

## 5. 非均匀纤维例核验

原文的六点例满足最大不可比度 2。在 r=4、L={1,2}、J={1,2,3,4} 时，基序 (1,2) 的两个扩张是 (1,2,3,4)、(1,3,2,4)；基序 (2,1) 只有 (2,1,3,4)。故纤维大小 2 和 1，F_J/e(P[L])=3/2，删除后的概率确为 2/3、1/3。该例是真实内部层实例，确实排除了均匀删除偷换。
