# S110-A: 有界不可比度的截面计数比值

日期：2026-10-10。状态：下述定理自含证明；独立精确检查见同目录脚本与结果。
范围：有限偏序的真实线性扩张计数。本文不声称近似泵定理、有限反例点数界，亦不声称证明 1/3–2/3 猜想。

## 1. 定义与结论

设 P 是 n 点有限偏序，固定一条参考线性扩张，并按此扩张将点标为 1,…,n。因此 i<_P j 蕴含 i<j。设每个点的不可比点数至多整数 D≥0。记 e(Q) 为有限偏序 Q 的线性扩张数，约定 e(∅)=1。

固定输出秩 r，0≤r≤n；令 ℐ_r 为 P 全部大小为 r 的下理想。定义

- ℓ=max(0,r−D)，u=min(n,r+D)；
- L={1,…,ℓ}，R={u+1,…,n}，W={ℓ+1,…,u}；
- a=r−ℓ=min(r,D)，b=u−r=min(n−r,D)，故 |W|=a+b≤2D；
- 对 J∈ℐ_r，F_J=e(P[J])，B_J=e(P\J)。

这里 P\J 是在补集上的诱导偏序，并没有重置任何随机删除律。

**S110-A.1（比值定理）。** 令

C_D=(2D)!/D!，其中 C_0=1。

则全部 r 和全部 J∈ℐ_r 同时满足

1 ≤ F_J/e(P[L]) ≤ C_D，

1 ≤ B_J/e(P[R]) ≤ C_D。

特别地，题设内部层 D≤r≤n−D 满足 L=[r−D]、R={r+D+1,…,n}，正是所需结论。更精确的层常数为

C_F=(a+t_F)!/t_F!，其中 t_F=min(D,|L|)，

C_B=(b+t_B)!/t_B!，其中 t_B=min(D,|R|)。

分别以 C_F、C_B 代替 C_D 后仍成立；二者均≤C_D。

**S110-A.2（精确有限支持）。** J↦S=J\L 是 ℐ_r 与 P[W] 的全部 a 元下理想之间的双射。因此合法状态支持完全由窗口内诱导偏序和 a 决定。所有这些状态的 F_J、B_J 都严格为正。若 k=|ℐ_r|，则

1≤k≤binom(a+b,a)≤N_D:=binom(2D,D)。

**S110-A.3（归一化远离相对单纯形边界）。** 定义仅在合法状态上归一化的向量

p_J=F_J/(Σ_{K∈ℐ_r}F_K)，

q_J=B_J/(Σ_{K∈ℐ_r}B_K)。

则对每个合法 J，

1/[1+(k−1)C_F] ≤ p_J ≤ C_F/[C_F+k−1]，

1/[1+(k−1)C_B] ≤ q_J ≤ C_B/[C_B+k−1]。

故仅依赖 D 的共同下界可取

α_D=1/[1+(N_D−1)C_D]>0。

真实均匀随机线性扩张在秩 r 的状态分布是

μ_J=F_J B_J/e(P)，

它满足

1/[1+(k−1)C_F C_B] ≤ μ_J ≤ C_F C_B/[C_F C_B+k−1]，

尤其 μ_J≥β_D:=1/[1+(N_D−1)C_D²]>0。

这些是合法支持单纯形的坐标下界。若把向量补零到全部 N_D 个潜在掩码，非法坐标仍为零；不能宣称其远离整个 N_D 维单纯形的边界。带点对方向监视器的进一步细分坐标也不自动获得上述正下界。

## 2. 自含窗口守卫与支持证明

对点 x，令 p(x) 为其严格前驱数，d(x) 为其不可比点数。在任意线性扩张 τ 中，

rank_τ(x)=p(x)+1+#{y∥x : y 在 τ 中先于 x}。

因此同一点在任意两条线性扩张中的秩差至多 d(x)≤D。这里比较其中一条与固定参考扩张，得到 |rank_τ(x)−x|≤D。

任一有限偏序下理想 J 都可作为一条完整线性扩张的前 |J| 个点：任取 J 的扩张，再接补集的扩张；不存在补集点小于 J 内点。若 |J|=r，前述秩界给出

L⊆J⊆L∪W。

具体地，标签 i≤r−D 若不在 J，其秩至少 r+1，位移至少 D+1；标签 i>r+D 若在 J，其秩至多 r，位移至少 D+1。裁剪 0、n 后完全同理。

于是 J=L∪S，且 |S|=a。J 是下理想必使 S 为 P[W] 的下理想。反过来，若 S 是窗口内下理想，则 J=L∪S 也是 P 的下理想：

- L 是参考扩张初段，本来就是下理想；
- 对 x∈S，任何前驱 y 都有 y<x≤u；若 y∉W，则 y∈L；若 y∈W，则窗口下理想性使 y∈S。

这证明双射及局部支持。每个有限诱导偏序都至少有一条扩张，故 F_J、B_J>0。且 k≤binom(a+b,a)。将 a 个被选位置补上 D−a 个固定被选虚位，将 b 个未选位置补上 D−b 个固定未选虚位，给出到 2D 位置的 D 元子集的单射，故 binom(a+b,a)≤binom(2D,D)。r=0,n 或 D=0 时此论证仍成立。

## 3. 逐条扩张的有界删除纤维

下面先给出适用于任意初段核心的基本引理。它比单纯比较总数更强，并明确避免均匀删除假设。

**S110-A.4（初段插入纤维引理）。** 设 Q 的点集分为 K⊔A，其中任意 k∈K、x∈A 均不满足 x<_Q k；设 |K|=m、|A|=a，每个 x∈A 与 K 中至多 D 点不可比。固定 Q[K] 的任意一条线性扩张 σ=(σ₁,…,σ_m)。令 h(σ) 为删去 A 后恰得 σ 的 Q 扩张数。则

1≤h(σ)≤(t+a)!/t!，其中 t=min(D,m)。

更强的下界 h(σ)≥e(Q[A]) 也成立。

**证明。** 下界来自连接：对 A 的任意扩张 τ，σ 后接 τ 是 Q 的扩张，因为不存在 A→K 的比较。

现考察任一删去 A 后为 σ 的 Q 扩张 λ。若某个插入点 x∈A 出现在某个 K 点 k 之前，那么 x 与 k 必不可比：不可能 x<_Q k（假设排除），也不可能 k<_Q x（λ 为扩张）。因此 λ 中位于 x 后面的全部 K 点都是 x 的不可比邻居，数量至多 D。

若 m>D，任何 A 点都不能位于 σ_{m−D} 之前，否则 σ_{m−D},…,σ_m 共 D+1 个 K 点都在它后面。因此 λ 的前 m−D 项必须恰为 σ₁,…,σ_{m−D}，它们前面或中间不允许 A 点。注意：A 点可以紧跟 σ_{m−D}，即出现在剩余 D 个 K 点之前；这正是计数中允许的最左插槽。

若 m≤D，前面这段是空段，所有 m 个 K 点都保留在尾部。统一地，固定前缀长度为 m−t，剩余区间由 t 个 K 点与 a 个 A 点组成，且 t 个 K 点的相对顺序固定。忽略其余偏序约束只会增加可选序列数，因此

h(σ)≤binom(t+a,a)·a!=(t+a)!/t!。

这是对每条 σ 独立成立的纤维界，没有把 h(σ) 视作常数。证毕。

## 4. 应用到 F 与严格对偶 B

固定合法 J。令 A=J\L，|A|=a。所有 L 标签小于所有 A 标签，故不可能有 A 点小于 L 点。任一 A 点在 L 中的不可比点数至多全 P 不可比度 D。对 Q=P[J]、K=L 应用纤维引理，并对全部 σ∈LE(P[L]) 求和，得到

e(P[L]) ≤ F_J ≤ C_F e(P[L])。

这一步只用逐纤维上下界求和，不要求不同 σ 的纤维大小相同，也不比较不同 J 的删除分布。

对 B，令 T=(P 的点集\J)\R；它有 b=u−r 个点，且 T 的标签都小于 R 的标签。在原偏序中不可能有 R 点小于 T 点。取 Q=P\J 的对偶 Q^op，以 K=R、A=T 应用初段插入引理：

- 在 Q^op 中不存在 T 点小于 R 点，因为这等价于原 Q 中 R 点小于 T 点；
- 取对偶不改变不可比度；
- Q 与 Q^op 的扩张通过整序反转一一对应；R 的诱导偏序也同理。

于是

e(P[R]) ≤ B_J ≤ C_B e(P[R])。

用原方向说，删去 T 后固定一条 R 扩张，所有 T 点只能出现在其最前 D 个 R 点附近；余下 R 尾段不被插入点打断。这是前向尾段论证的精确反转，而非重新使用一个不匹配的初段假设。

最后 a,b,t_F,t_B≤D，且 (t+a)!/t!=Π_{i=1}^a(t+i) 对非负 t、a 单调。因此 C_F,C_B≤Π_{i=1}^D(D+i)=C_D。D=0 时空乘积为 1，偏序是链，全部结论均为等式。

边界无需另加虚拟真实元素：r<D 时 a=r、L=∅，前向界自然变成 F_J≤r!；n−r<D 时 b=n−r、R=∅，后向界自然变成 B_J≤(n−r)!。n<2D 时内部层可能不存在，但裁剪定义与上述证明对全部层有效。

## 5. 归一化与真实截面质量

一般地，若 k 个正数 x_j 满足 c≤x_j≤Cc，其中 c>0、C≥1，则

x_j/(Σ_i x_i)≥x_j/[x_j+(k−1)Cc]≥1/[1+(k−1)C]；

x_j/(Σ_i x_i)≤x_j/[x_j+(k−1)c]≤C/[C+k−1]。

应用到 F（c=e(P[L])，C=C_F）和 B（c=e(P[R])，C=C_B）即得 p、q 的界。

每条 P 扩张的前 r 位点集是唯一的 J∈ℐ_r；反过来，任一 J 扩张与补集扩张的连接都合法，且数目为 F_JB_J。因此

e(P)=Σ_{J∈ℐ_r}F_JB_J。

对乘积向量应用同一归一化引理，取 c=e(P[L])e(P[R])、C=C_FC_B，得到 μ 的界。又 k≤N_D、C_F,C_B≤C_D，即得 α_D、β_D。

可选的射影表述：未归一化合法坐标的任意两坐标之比均在 [1/C_D,C_D]。若两个切口通过相同窗口关系与相同选点数辨识为同一合法支持，它们的前向归一化向量的 Hilbert 射影距离至多 2 log C_D，后向也一样。这只是紧的正锥切片；不是有限个精确权重。

## 6. 非均匀删除确实存在

取六点自然标号偏序：1∥2，1<3，2∥3；4 在 1、2、3 上方，且 4<5<6。此偏序最大不可比度 D=2。取内部层 r=4，则 L={1,2}，R=∅，J={1,2,3,4}。

L 有两条扩张 (1,2)、(2,1)。删去 {3,4} 的两个纤维分别是

- 基序 (1,2)：(1,2,3,4)、(1,3,2,4)，纤维大小 2；
- 基序 (2,1)：(2,1,3,4)，纤维大小 1。

故 F_J/e(P[L])=3/2；从 J 的均匀扩张删除窗口点后，L 的两条扩张概率分别为 2/3、1/3，并不均匀。纤维不等大完全不影响本定理。

## 7. 独立精确检查方法与适用范围

`check_s110.py` 不调用 S102 的前沿转移，也不预设窗口守卫。它从自然参考序出发，递归枚举全部自然标号传递关系：新增最大标签的前驱集遍历全部子集，并只按传递性定义过滤。所有自然标号有限偏序恰出现一次。

第一检查器在完整子集格上计算真实下理想路径数 F 与 B；验证：

1. 所有合法下理想的窗口守卫；
2. 前后向精细常数 C_F、C_B 与统一 C_D 比值界；
3. 对所有更宽松 D=π(P)+1,…,n 再核查统一比值；
4. 用窗口诱导偏序独立重建支持，逐层验证其恰等于全局合法下理想；支持数量界及 Σ F_JB_J=e(P)；
5. p、q、μ 的六个上下界，全部使用整数交叉相乘。

第二检查器对 n≤6 的每个偏序、每个合法下理想，直接枚举相关诱导偏序的全部排列，并按偏序关系过滤，不复用计数 DP。它构造每一条实际删除纤维，逐条验证满射、纤维界、固定前缀/对偶固定后缀，并与第一检查器的总数互检。它还计数实际非均匀纤维，确保测试并非只覆盖均匀删除实例。

复跑命令：

python check_s110.py --max-n 7 --fiber-max-n 6 --output s110_checks.json

实测全部通过：n=0,…,7 共 101,660 个自然标号偏序、2,902,131 个下理想；807,571 次逐层支持精确相等检查；5,804,262 项主比值检查、17,412,786 项归一化整数不等式、10,528,206 项更松 D 的比值检查。n≤6 的第二检查器核验 213,508 个逐基序删除纤维，总计 1,568,430 条相关诱导扩张；其中 6,008 个前后截面配置含实际非均匀纤维。逐 n 统计与可复跑结果见 `s110_checks.json`、`s110_checks.log`。穷举检查只是证明的独立有限核验，不能代替任意 n、D 的上述证明。

## 8. 已建立与仍未建立

已建立：固定 D 的真实未标记前沿计数，在每个合法支持上有明确、与 n 无关的正坐标下界；前后向真实计数都满足；支持由局部窗口偏序精确决定；边界及不同删除纤维都已处理。

未建立：向量只有有限个精确值；任意精度近似可保持所有实际点对方向；两个相近切口可在仍属 π≤D 的真实偏序中安全拼接；全部跨缝点对受控；对任意严格反例存在统一非零余量；固定 D 的有效反例点数核。以上任一项均不得从本比值引理直接跳步推出。
