S104 — 保留实际释放标签的平方余项接口：精确账本与尚未闭合的串行双阻挡
2026-10-10。自含计数推导；尚待独立审核。未证明 WIDTH3、MAIN33、MC3 或 1/3 平衡定理；不认领文献新颖性。

结果先行
1. 对任意实际不可比对 a,b，只要其共同不可比集 N 是链，可以把共享下集条件化中的每个对角释放计数精确保留到一个事先固定的后继标签 c，并用同一个原 P 完整均匀扩张律加权：
       r_c = [1/e(P)] sum_{j>=tau(c)} f_j e(Q_j-a-c).               (L1)
   sum_c r_c=r，但 r_c 一般不等于 Pr_P(c<b)。后者还包括双阻挡质量，以及“另一个后继先出现、c 也在 b 前”的遗漏质量。
2. 全局最小多数对的假设给出标签级联合容量：
       r_c + sum_d k_cd + eta_c <= beta,
       l_d + sum_c k_cd + theta_d <= beta.                        (L2)
   所有 c,d 都是固定原偏序标签；没有逐扩张任选一个候选平衡对。
3. 交叉标签 d,c 确实可用，但精确恒等式是
       Pr(a<d,c<b)=Pr(c<d)+Pr(a<d<c<b).                           (L3)
   全局无平衡约束只直接控制第一项。第二项“串行双阻挡”在真实偏序中可为正，甚至在 d<c 为原偏序关系时承担全部双阻挡。没有得到把它抵消到一个固定少数事件的注入。
4. 两个真实宽3、五点偏序有完全相同的 E,C,V,kappa，却有不同的释放标签分布；其中一个的每个释放选择质量为 3/10，而实际比较概率为 1/2。这严格定位了两处信息损失。

一、设定、依赖与原律事件
P 为有限偏序，a∥b，所有 Pr 均指原 P 的均匀完整线性扩张。严格上下集记 D(x),U(x)。定义
 A={a 在 b 前},
 S={某个 a 的严格后继在 b 前},
 T={某个 b 的严格前驱在 a 后}.
S,T 都包含于 A。按 h,r,l,k 分别记 A 中无阻挡、仅 S、仅 T、S 与 T 都发生的质量。反向为 h',r',l',k'。交换 a,b 的合法扩张对合给 h'=h>0。

固定标签集合
 C=min(U(a)\U(b)),  Dtag=max(D(b)\D(a)).
本文用 Dtag 区别于下面共享下集 D*。有
 S=union_{c in C}{c<b},  T=union_{d in Dtag}{a<d}.
C 中每个 c 都满足 a<c、c∥b；Dtag 中每个 d 都满足 d<b、d∥a。width(P)<=3 时 |C|,|Dtag|<=2。

对每条发生 S 的扩张，令 c_first 为 C 中最先出现的标签；它必在 b 前，也是 a 的第一个严格后继。对每条发生 T 的扩张，令 d_last 为 Dtag 中最后出现的标签；它必在 a 后，也是 b 的最后一个严格前驱。这些选择只用于将事件分成互不相交的格，全文一直保留每一个 c,d 的下标；不把样本依赖标签当成一个固定比较对。

依赖：S104/normalized_square_global_application.txt 的共享下集、共享上集条件化与 rr'<=h^2、ll'<=h^2；S103/backend_matrix_constraints.txt 的真实首两步矩阵及 Schur 恒等式；S102/global_extremal_exchange.txt 的全球最小多数对与生成事件<=beta。后两个计数引理和本节标签细化下面重新证明。没有引入新的外部相关性定理。

二、固定 c 的精确原律加权公式
令 D*=D(a) union D(b)。给 P 增加 D* 中每点都在 a,b 之前的关系，取传递闭包，得到 Q=Q_down。于是
 E_down={D* 全部在 a,b 之前}=(T union T')^c,
 LE(Q)=LE(P) intersect E_down.
新增关系不改变 U(a),U(b)，也不改变共同不可比集 N。a,b 在 Q 中有共同严格下集 D*。假定 N 是链 n1<...<nR；width(P)<=3 是充分条件。

写 N_j={n1,...,nj}，Q_j=Q-(D* union N_j)，
 a_j=e(Q[D* union N_j]), a_{-1}=0,
 c_i=a_i-a_{i-1}, f_j=sum_{i=0}^j a_i=sum_{i=0}^j(j-i+1)c_i.
D* 为空时 a_j=1,c_0=1,c_i=0(i>0)，按同样公式处理。

对固定 c∈C，定义
 tau(c)=max({i:n_i<c} union {0}).
由于 c 是私有上集的极小标签，c 的前驱除 a 外全在 D* union N_tau(c) 中：若还有某前驱 z 属于 a 的私有上集，则违背 c 的极小性；若 z 属于 b 的上集或 z=b，则 c 属于 U(b)，也矛盾。故 c 在删除 a 后从 Q_j 新释放，当且仅当 j>=tau(c)。因此真实对角细化为
 delta_{j,a,c}=1_{j>=tau(c)}e(Q_j-a-c),
 (V_j)_{aa}=sum_{c in C}delta_{j,a,c}.                         (2.1)

定义固定标签事件
 R_c={S 发生，T 不发生，且 c_first=c}, r_c=Pr_P(R_c).
则 (L1) 成立。

证明：在 R_c 对应的完整扩张中，最后一个 D* 标签完成时已消耗 N_i，其有序前缀有 c_i 种。设 c 出现前一共消耗 N_j。a 必放在 n_i,...,n_j 的链间隙之一，共 j-i+1 个可能；a 与 c 之间除了中性链点没有其他标签，因为 c 是第一个后继且 b 尚未出现。c 必须可释放，故 j>=tau(c)。随后剩余部分任取 Q_j-a-c 的完整扩张。反过来，上述数据唯一重建一条 R_c 中的扩张。故其计数为
 sum_{j>=tau(c)}sum_{i<=j}c_i(j-i+1)e(Q_j-a-c)
 =sum_{j>=tau(c)}f_j e(Q_j-a-c).
除以 e(P)，而非 e(Q)，即得原律概率。这个分母已经完成正确的条件化移回，不应再乘或除一次 d_down=e(Q)/e(P)。证毕。

交换 a,b 给 r' 的固定标签分解。对 P 的对偶使用同一构造给 l_d：
 l_d=Pr(T 发生，S 不发生，d_last=d)
    =[1/e(P)]sum_j f_j^up delta^up_{j,b,d}.                    (2.2)
这里 up 的全部计数在 P 的对偶上以首点 b、另一点 a 构造；严格后继标签就是原 P 的 b 前驱 d。down 与 up 不必有同一套前缀权重。

三、全局最小多数假设给出的联合标签账本
假设原 P 没有 [1/3,2/3] 内的实际标签对，并在全部不可比多数方向中选 Pr(a<b)=m 最小者，令 beta=1-m<1/3。

对 c∈C，{c<b} 真包含于 {a<b}，严格差事件 a<b<c 至少含一条扩张，所以 Pr(c<b)<m。全局无平衡及 m 的最小性迫使 Pr(c<b)<=beta。同理 Pr(a<d)<=beta 对每个 d∈Dtag 成立。这一步作用于原 P 律，不能替换为 Q_down 中的条件概率。

定义
 k_cd=Pr(S,T,c_first=c,d_last=d),
 eta_c=Pr(c<b,c_first!=c),
 theta_d=Pr(a<d,d_last!=d).
这里 eta_c,theta_d>=0；它们包括纯阻挡与双阻挡中相应的“非首/非末”情形。精确地，
 Pr(c<b)=r_c+sum_d k_cd+eta_c,
 Pr(a<d)=l_d+sum_c k_cd+theta_d.                              (3.1)
结合全局量化即得 (L2)。同时
 sum_c r_c=r, sum_d l_d=l, sum_{c,d}k_cd=k.
当 |C|=2 时
 sum_c eta_c=Pr(两个 C 标签都在 b 前),                       (3.2)
当 |Dtag|=2 时
 sum_d theta_d=Pr(a 在两个 Dtag 标签前).
所以这份账本严格保留了旧的并界中丢弃的同侧标签交叠，不能把 eta、theta 默认为零。

由 (L1)+(L2) 得到可以直接检查的、作用于同一实际标签 c 的后端约束：
 sum_{j>=tau(c)} f_j e(Q_j-a-c)
   +e(P)[sum_d k_cd+eta_c] <= beta e(P).                      (3.3)
对偶给 l_d 的对应式。这是可交给下一步联合计数/注入证明的明确接口。它尚非一个新平衡对定理；单纯求和并扔掉 eta、theta 会退回 r+k<=|C|beta、l+k<=|Dtag|beta。

四、交叉标签 d,c：控制交叉次序后仍有串行质量
固定 c∈C,d∈Dtag。原偏序不可能 c<d，否则 a<c<d<b 将推出 a<b。故要么 d<c，要么 c∥d。

仅用 a<c 与 d<b，在每条完整扩张逐条可核查：
 {a<d,c<b}={c<d} disjoint-union {a<d<c<b}.                    (4.1)
因为若 c<d，则必有 a<c<d<b；若 a<d,c<b 且 d<c，则顺序只能为 a<d<c<b。这证明 (L3)。

在全局假设下，多数序为延伸 P 的全序，并且 d 在 a 前、a 在 b 前、b 在 c 前。因此若 c∥d，则 Pr(c<d)<=beta；若 d<c 为原关系，此概率为零。将 k_cd 按两个次序再分开，
 xi_cd=Pr(S,T,c_first=c,d_last=d,c<d),
 zeta_cd=Pr(S,T,c_first=c,d_last=d,d<c),
 k_cd=xi_cd+zeta_cd,
 0<=xi_cd<=Pr(c<d)<=beta.                                    (4.2)
但是 zeta_cd 仍然没有从这些事实得到一个固定少数事件的容量。

真实最小障碍例：四点偏序 a<c、d<b、d<c（没有其他非传递关系）。它有 5 条完整扩张：
 a d b c; a d c b; d a b c; d a c b; d b a c.
对 (a,b) 有 h=r=l=k=1/5，h'=1/5，反向其他格为零。C={c},Dtag={d}，全部双阻挡为串行顺序 a d c b，故 k=1/5 而 Pr(c<d)=0。
这否定了无条件的 k_cd<=Pr(c<d) 或“跨标签少数概率会自动覆盖整个双阻挡”的说法。此例有其他平衡对，不是全局无平衡假设的反例；其用途只是证明串行项是一个真实计数事件，不能在恒等式中删掉。

五、为什么 Schur 余项本身不能恢复这些标签
在 S103 的 Delta_j>0 情形，令 A=E_j、z=C_{j+1}-(E_{j+1}/E_j)C_j。其 u 坐标给
 kappa_j=C_{j,u}^2/A-(A/Delta_j)z_u^2
           -sum_c delta_{j,u,c}.                             (5.1)
Delta_j=0 时删除中间项，使用已证明的兼容性。可见 kappa 只看到实际释放计数的和；保持和不变而分配到不同 c，不改变这个矩阵或余项。不能从总和的近饱和推出某个固定 c 的比较概率。

这个信息损失在真实偏序中确实发生。两个模型均有标签 u,v,w,z,y，y 独立：
 I:  u<v<w，u<v<z，w∥z；
 II: u<v<z，u<w<z，v∥w。
两者宽度均为3，D,N为空，R=0。精确计数同为
 E=10, C=(8,2), V=[[6,2],[2,0]],
 p=4/5,U=3/5,kappa=2/5,kappa/E=1/25.
但是 I 的 u 删除后只释放 v，delta_{u,v}=6；II 删除 u 后同时释放 v,w，delta_{u,v}=delta_{u,w}=3。
因此完整的 E,C,V,kappa 无法识别单个释放标签的分布。

更进一步，II 的两个首释放选择质量均为 r_v=r_w=3/10，而
 Pr(v<y)=Pr(w<y)=5/10.
差值 eta_v=eta_w=2/10，来自另一个后继先出现且该标签也在 y 前。这里 T 为空，尚无双阻挡，单是 eta 就足以使“首释放概率=实际比较概率”失效。两例均含其他平衡对，当然不是平衡猜想反例。

六、已有标量松弛仍可扩充成满足标签容量的账本
这只是数值约束系统的见证，不声称由真实偏序、均匀扩张或任何完整扩张分布实现。
取 S104 已有八格
 h=.12, r=l=.24,k=.15,
 r'=l'=.04,k'=.05.
则 p=.75,beta=.25，rr'=ll'=.0096<h^2=.0144。
给 C,Dtag 各两个固定标签，取
 r_c=.12,l_d=.12,k_cd=.0375 对全部四个格，
 eta_c=theta_d=.01.
每行/列容量为 .12+2*.0375+.01=.205<.25；同侧重叠总量为 .02，与相应首标签总质量相容。
再令 xi_cd=0,zeta_cd=k_cd；这满足 (4.2)，例如其零交叉少数质量与静态关系 d<c 的情形一致。反向也可均分为 r'_c=l'_d=.02,k'_cd=.0125，并使用足够小的正 eta',theta'。所有已列标量、容量和串行/交叉分解约束仍允许 p>2/3。
这个见证不说明真实偏序结构不足；它仅说明增加固定标签下标、单标签容量、以及 (4.1) 的交叉少数上界后，还没有数学理由宣告闭合。尤其未要求其满足每个其他标签对的全部均匀计数身份、CP 矩阵或原律计数兼容性。
