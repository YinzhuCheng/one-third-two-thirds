# S91：非自治链的原律分割点惩罚

2026-10-03，交互研究轮。小时任务已取消。本轮从实际读取的main S86与独立阅读的S82、S89/S90候选稿出发，不把未合入的自动稿视为全部认证。

## 主要数学增量

**任意链C，不再要求共同外部邻域。** 令S包含所有与C有非一致比较关系的外部点，x与C全不可比且不属于S。在原P的均匀完整扩张中，J_x是x前的C点数，K_s是s前的C点数。对于3≤r≤|C|−3，设ε_r=Pr(存在s∈S满足|K_s−r|≤2)，则

    Pr(J_x=r) ≤ 5/16 + 11ε_r/16.

若Pr(x<c_r)≤1/2≤Pr(x<c_(r+1))，两个固定候选中至少一个平衡度≥11(1−ε_r)/32；特别ε_r≤1/33足够给1/3平衡对。反之严格潜在反例的中央多数序插入必须发生在ε_r>1/33的切口。

证明不把均匀删点当边缘：固定x两侧相邻S点外的完整前后缀，中间条件律恰为诱导偏序均匀扩张；好纤维含自治中央链并有5/16原子界，坏纤维被同一原律拥挤事件覆盖。原稿还给参数b≥3的一般形式α_b+(1−α_b)ε_(r,b)，α_b=binom(2b,b)/4^b。

## 有限例提升为无限非自治族

链C_6、链A_L、链S_6和单点x，额外比较为A_L<s1、c_i<s_i、x<s6。宽度恰三，原链C的任何二点以上子链都非自治。精确反射计数与实际位置概率给ε_3≤30/(L+8)，并有p(x<c3)<1/2<p(x<c4)。因此所有整数L≥982固定菜单{(x,c3),(x,c4)}覆盖1/3。没有扩大参数盒外推，982不称最优，未宣称该族的定性存在性首创。

## 一项必须保留的更正

精确共同窗口链的外部D,N,F总能按D→N→F串接，所以κ=max窗口旧点数=|N|。这已是在线S82§3；S89候选中“κ可以严格小于|N|”的解释不成立。条件原子界没有因此被否定；错误的是称这个最大值有额外结构压缩。新ε_r为原律联合概率，确实是不同信息。
