## 0. 本轮为什么改变问题

S88–S90候选稿主要研究每个链点拥有相同外部关系的自治链，连续优化窗口原子界。本轮不再扩大这类参数盒，而问：**原链在真实偏序中不是自治模块时，哪些外部点的实际位置会破坏中央反集中，代价能否在同一原律中量化？**

答案是一个原律概率惩罚：若改变链外关系的分割点很少出现在所选切口附近，则原链仍有可用的小跳跃和固定标签伙伴。不能只看分割点个数；用的是它们在完整线性扩张里的联合位置事件。

## 1. 先更正一个参数解释：精确自治窗口的最大容量就是全部中性点数

若链C对每个外部点的关系均一致，外部准确分成D（低于整个C）、N（与整个C不可比）、F（高于整个C）。在旧偏序Q=P−C中，D、N、F各自内部任取线性扩张，然后按D→N→F串接，必定合法。

证明：D<F已由经C的传递性给出。若n∈N低于d∈D，则n<C，矛盾；若f∈F低于n∈N，则C<n，矛盾。因此串接没有逆向比较。

只有N可以出现在最后D与最先F之间，所以上界为|N|；上述串接达到它。因此

    max_tau |W_tau| = |N|,
    #{tau: |W_tau|=|N|}=e(D)e(N)e(F)>0.                 (1.1)

空偏序扩张数为1。

**归属与修正范围：** 这已经是在线S82原稿§3的内容，不是S91新定理。S89候选稿及其后续说明中，在同一精确自治模型里声称“κ=max|W_tau|可以严格小于|N|”不正确。单个纤维的k可以变，最大值不变。这里不否定其正确的条件原子公式，也不因此否定数值相位带；那些式子在此模型中应按κ=|N|解释。若转向只选部分纤维或非自治窗口，必须另写新的假设，不能沿用原来的无条件最大值。

## 2. 自治链中央的独立反集中引理

设C长度为ℓ，对外部所有点的关系均一致；x与C全不可比。取原完整扩张的均匀律，J_x是x之前的链点数。

条件于外部旧排列tau，若x不在合法窗口内，J_x只取0或ℓ。否则窗口有k个旧点，x在其中的秩为j，合法交错总数为binom(ℓ+k,k)，并有

    A_(ℓ,k)(q,j)
      = binom(q+j−1,j−1) binom(ℓ−q+k−j,k−j) / binom(ℓ+k,k).  (2.1)

这里条件律是真实纤维内的均匀律；不同tau的权重是它的合法完成数，而不是等权。

### 2.1 Beta积分与二项式峰值

由Euler Beta积分，(2.1)等于

    ∫_0^1 binom(ℓ,q) p^q(1−p)^(ℓ−q)
          · p^(j−1)(1−p)^(k−j)/B(j,k−j+1) dp.

因此

    A_(ℓ,k)(q,j) ≤ L_(ℓ,q)
       := binom(ℓ,q)(q/ℓ)^q(1−q/ℓ)^(ℓ−q).             (2.2)

这是经典Beta积分的应用，不认领概率分布基础。

L_(ℓ,q)关于q对称。设a_v=(1+1/v)^v，该序列递增，则

    L_(ℓ,q+1)/L_(ℓ,q) = a_q/a_(ℓ−q−1),

故从边缘向中部递减。对整数b≥1、ℓ≥2b、b≤q≤ℓ−b，有

    L_(ℓ,q) ≤ L_(ℓ,b) ≤ L_(2b,b) = binom(2b,b)/4^b=:α_b. (2.3)

第二步也可自含验证：将ℓ延为实数z>b，

    d/dz log L_(z,b)
      = Σ_(i=0)^(b−1) 1/(z−i) + log(1−b/z) <0,

因为该和是严格小于∫_0^b du/(z−u)的左端Riemann和。综上，

    Pr(J_x=q) ≤ α_b,    b≤q≤ℓ−b.                       (2.4)

本轮主要使用b=3，此时α_3=5/16。对于b=2且ℓ≥6，还可保留ℓ≥6而不取最粗ℓ=4：

    Pr(J_x=q) ≤ L_(ℓ,2) ≤ L_(6,2)=80/243<1/3,
                     2≤q≤ℓ−2.                         (2.5)

(2.2)的思路已出现在会话S90候选稿中央部分；本轮重新推导，并将其用于下一节的非自治对象，不把它包装成全新基础不等式。

## 3. S91-SPLITTER：任意链的分割点惩罚定理

P为任意有限偏序，C=(c_1<…<c_t)是一条指定链。令S⊆P\C包含所有非一致关系点：即删去S后，每个仍在C外的点要么低于整个C、要么高于整个C、要么与整个C不可比。称S中这些可能改变链外关系的点为分割点。S不要求成链，P没有宽度假设。

固定x∈P\(C∪S)，要求x∥C。全部概率均属于**同一个P的均匀完整扩张律**。定义

    J_x = #{c_i: c_i先于x},
    K_s = #{c_i: c_i先于s}  (s∈S).

取整数b≥3、t≥2b及b≤r≤t−b。置

    B_(r,b) = {存在s∈S使 |K_s−r|≤b−1},
    ε_(r,b) = Pr_P(B_(r,b)).

这是S中所有点的联合事件，不能以独立边缘乘积替换。

### 定理 3.1（原律非自治反集中）

    Pr_P(J_x=r) ≤ α_b+(1−α_b) ε_(r,b),
    α_b=binom(2b,b)/4^b.                               (3.1)

特别地b=3、3≤r≤t−3时，记ε_r=ε_(r,3)，

    Pr_P(J_x=r) ≤ 5/16 + (11/16) ε_r.                  (3.2)

### 证明：固定整个前后缀，而非无偏删掉S

对每条完整扩张，找出x之前最后一个S点及x之后第一个S点。若不存在，使用序列虚拟左右端。记录到左S点为止的整个有序前缀，以及从右S点开始的整个有序后缀。

固定这两个字符串之后，未固定标签形成确定的诱导偏序M，含x且不含S。其任意线性扩张夹在已固定前后缀之间都合法；反向限制唯一。因此中间部分的条件律恰是Unif L(M)，纤维的真实质量是e(M)/e(P)。这一步没有使用P−S的无条件均匀律。

设前缀已有a个C点，中间含连续子链c_(a+1),…,c_(a+ℓ)。因为中间没有S，这条子链对其中所有非链点的关系一致，所以是自治链。

若r不在[a,a+ℓ]内，纤维内J_x=r不可能。若

    b≤r−a≤ℓ−b,

应用(2.4)，条件原子≤α_b。否则，在可能有J_x=r的纤维中，必有r−a≤b−1或a+ℓ−r≤b−1。

前一种情况下，左边界不能是虚拟端点：否则a=0，与r≥b矛盾。因此左边界是真实s∈S，其K_s=a，满足|K_s−r|≤b−1。后一种情况对右边界相同；虚拟右端会给a+ℓ=t，与r≤t−b矛盾。

故所有未获α_b界、但原子可能非零的“坏纤维”都整体包含于B_(r,b)。令这些纤维的总质量为η≤ε_(r,b)，对它们只用上界1，对其余用α_b，得到

    Pr(J_x=r) ≤ α_b(1−η)+η ≤ α_b+(1−α_b)ε_(r,b).

证毕。

**加强与限制：** 真正坏纤维的质量η可能小于ε；使用ε的好处是它不依赖目标x，可在所有中性候选之间共享。条件“在r附近没有S”本身不是可以任意条件化后直接套自治公式的理由；证明依赖上述完整前后缀分割。

## 4. 固定标签选择、严格多数序与共享预算

令p_i=Pr_P(x<c_i)=Pr(J_x≤i−1)，则p_(r+1)−p_r=Pr(J_x=r)。如果

    p_r≤1/2≤p_(r+1),

两个预先固定标签c_r,c_(r+1)中至少一个满足

    bal_P(x,c_i) ≥ (1−α_b)(1−ε_(r,b))/2.               (4.1)

证明：两个累计值夹住1/2，与1/2较近者的距离不超过跳跃的一半，再用(3.1)。所有候选均为原P的实际标签，不随随机扩张改变。

当b=3时，

    max(bal(x,c_r),bal(x,c_(r+1))) ≥ 11(1−ε_r)/32,
    ε_r≤1/33 ⇒ 至少一个候选1/3平衡。                  (4.2)

一般阈值是ε_(r,b)≤(1/3−α_b)/(1−α_b)，b≥3时为正。b=4给23/279，但本轮具体应用只用b=3，不主张常数最优。

若假定全体不可比对均严格不平衡，>2/3方向连同确定比较组成全序：两步并合给Pr(a<c)>1/3，无中间概率再将它提升到>2/3。此处重用S62的多数序事实。

因此，若某中性点在该多数全序中插于c_r与c_(r+1)之间，则必有p_r<1/3、p_(r+1)>2/3，由(3.2)反推

    ε_r>1/33.                                        (4.3)

这把原律大方向跳跃定位到分割点在同一切口附近的正概率拥挤事件，而不是证明任意小ε切口都必定出现半点穿越。

共享的粗预算为

    Σ_(r=b)^(t−b) ε_(r,b) ≤ (2b−1)|S|,                (4.4)

因为每条完整扩张中，一个s最多落入2b−1个切口的半径b−1范围，对并事件取上界再求期望即可。b=3时，ε_r>1/33的切口数严格小于165|S|。

**不能过度解读：** 该个数界粗糙，仅凭|S|的多数序块数并不是本轮主要优化目标。各分割点沿C的确定比较模式最多改变两次，本来就可以把C切成少量关系一致区间。这里新增的信息是特定原律切口的ε_r及其与半点穿越的定量关系；没有证明任意潜在反例都存在同时满足两条件的切口。

## 5. S91-NONAUTONOMOUS：没有二点自治链段的一整个宽度三族

### 5.1 构造

取链C=(c_1<…<c_6)、A=(a_1<…<a_L)、S^+=(s_1<…<s_6)，以及单点x。除三条链内部关系外，只添加

    a_L<s_1 (L≥1时),  c_i<s_i (1≤i≤6),  x<s_6,

并取传递闭包。记所得偏序P_L，L≥1。

三链覆盖为C、A⊕S^+、{x}，而{c_1,a_1,x}是反链，故宽度恰为三。x与全部C不可比；真正分割点取S={s_1,…,s_5}，s_6在整个C之上。

任意i<j，s_i在c_i之上却与c_j不可比。因此原C没有大小至少二的自治子链。这正是不能直接套S88–S90的共同窗口假设的对象。

### 5.2 真实分割点拥挤概率的精确计数

先删除x。剩余偏序是两条链C与A⊕S^+。令C前缀已放i点、另一条链前缀已放j点，合法状态条件为j≤L+i。反射原理（或直接格点递推）给

    Z_L = binom(L+12,6)−binom(L+12,5)
        = (L+1)/(L+7)·binom(L+12,6).                  (5.1)

解释反射计数：合法词有6个C字母、L+6个第二链字母，全部前缀差“第二链−C”≤L；坏路径在首次达到L+1后反射，计数为binom(L+12,5)。

s_6是这个删除偏序的唯一最大元，x仅被要求在s_6前。每条删除扩张都有恰L+12个x合法槽，故此次删除投影确实均匀——这里有常数完成数的证明，不能推广到任意删除。

在r=3处，B_3就是某分割点有1≤K_s≤5。因为K_(s_1)≥1且K_(s_i)非减，补事件恰为“全部C先于s_1”。该补事件的删除扩张数是binom(L+6,6)：任意交错C与A之后串接S^+。

故

    ε_3=1−binom(L+6,6)/Z_L
       =1−∏_(i=2)^6 (L+i)/(L+6+i)
       ≤Σ_(i=2)^6 6/(L+6+i)
       ≤30/(L+8).                                    (5.2)

L≥982时，ε_3≤1/33。

### 5.3 半点穿越也在同一原律中得到

条件于B_3的补事件，C与A的交错均匀，随后为S^+；x仍在L+12个合法槽均匀。c_r在C/A交错中的期望位置是r(L+7)/7（均匀选6个位置的次序统计量，或按7个间隙的对称性）。因此

    q_r:=Pr(x<c_r | B_3^c)=r(L+7)/(7(L+12)).           (5.3)

由同一事件B_3分解原律，

    p_3≤q_3+ε_3<3/7+1/33<1/2,
    p_4≥(1−ε_3)q_4≥(32/33)·4(L+7)/(7(L+12))>1/2

对L≥982成立。最后一个严格不等式等价于25L>980。

结合(4.2)，得到

    对每个整数L≥982，
    max{bal_(P_L)(x,c_3),bal_(P_L)(x,c_4)}≥1/3.        (5.4)

更精确的下界是11(1−ε_3)/32。本结论是无限参数证明，不是把L检查到某值后外推。阈值982是方便、很保守的充分值，不宣称最小。也不宣称这个族的全局1/3存在性在文献中首次解决；本轮的用途是展示原选链完全没有非平凡自治段时，新的原律概率惩罚仍能选出固定原链标签。

L=1000时独立双链DP给：

    ε_3 = 42846274381/1459729025832 ≈0.0293522,
    p_3 = 1107921206182139/2585180104748472 ≈0.428566,
    p_4 = 19327416635/33823379744 ≈0.571422.

本轮不将这些小数当作解析证书，确切公式见(5.1)–(5.3)。
