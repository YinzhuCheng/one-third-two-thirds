# S117｜七点核的全部正整数链膨胀均有平衡对

2026-10-10。**完整定理及全部必要依赖均已通过独立研究审查 PASS。** 这是有限计算辅助证明，不是任意搜索盒中的实验结论。独立审查指分开的数学审阅与实现复核，不是外部同行评审或形式化认证。

## 精确结论

固定商核 Q 的覆盖关系为

`0<3; 1<2,4; 2<3,6; 3<5; 4<5`。

把顶点 i 替换为非空链 C_i，链间关系全部继承 Q；记链长

`(u,a,b,c,t,d,v)=(|C0|,|C1|,|C2|,|C3|,|C4|,|C5|,|C6|)`。

**对任意七个正整数链长，所得偏序在其实际全部带标签完整线性扩张的均匀分布下，必有一个不可比标签对 x,y 满足 1/3≤Pr(x<y)≤2/3。** 概率不在均匀商核扩张或删链后重新均匀抽样上计算；平衡区间包含两端点。

## 证明为什么闭合

1. **结构强迫与真实条件混合。** 既有 good-pair、秩链和插入／交织论证把“没有平衡对”转成严格必要方向与乘积不等式。其中必须有 Pr(T0<T2)<1/3；强终端事件是 T6<B5，不能误换成 T6<T5。
2. **第四终端秩：保留相邻尾事件的共同约束。** 真实条件律是正 Beta(α,5) 混合。最后一秩质量 Q 与前一秩质量 P 满足显式凹函数约束 P≤f_n(Q)。Jensen 不等式保留混合，n≥44 时它与反例要求 Q<1/3、P+Q>2/3 矛盾。因此 d=4⇒v≤43，对偶有 a=4⇒u≤43。其余权重任意，不靠采样。见[证明](fourth-terminal-rank-barrier/FOURTH_RANK_TRADEOFF.md)、[审查](fourth-terminal-rank-independent-audit/AUDIT.md)。
3. **gamma 张力给出完整有限化。** 令 A=log(3/2)、L=log3，γ_k=1/(exp(A/k)−1)−2/(exp(L/(k+1))−1)−1。所有正整数 k 上的严格解析界，与 γ_a u+γ_d v<min(u,v)+a+d 联用，得到 a,d≤181、a+d≤184、u+v≤110，进而假想反例总阶 **N≤1665**。精确耦合区域仅有 14,190 个 a≤d 的外权重／端口四元组。见[证明](global-seven-weight-reduction/GLOBAL_WEIGHT_BOUND.md)、[审查](global-seven-weight-independent-audit/AUDIT.md)。这一步不借用任何 census 结论。
4. **旧小外权重域与新补域构成完整分割。** a,d≤2 的证明排除 62,109 个必要候选，经解析筛选余 2,285 个；a,d≤3 且 max(a,d)=3 的证明排除 61,785,506 个必要候选，经解析筛选余 65,951 个。两者在本次 S117 首次发布，均已有独立 PASS。新补域保留所有 a≤3<d 的混合情形，不遗漏。
5. **精确计数收尾。** 新补域的 13,042 个端口四元组中，仅186个产生非空内权重区间；2,169个压缩区间完整表示6,088个七权重向量。按 T2 切开实际完整扩张，双和计数给出分母 Z 和分子 N02。所有残余均满足更强的 **2N02>Z**，与 Pr(T0<T2)<1/3 矛盾。新残余最大阶631只是筛选结果，不是预设上限。

## 独立实现验证了什么

新补域审查独立重建完整区间域，以不使用闭合二项式公式的词递推重算全部 **12,176 个整数**。另用实际带标签理想态 DP 检查15个确定性样本、对偶事件及最大阶631的向量，共3,774,024个可达理想态。样本 DP 用于校验实现与概率解释；穷尽结论来自已证明递推和全部6,088向量的重算，而不是这15例样本。

依赖关系非循环：结构／真实混合／秩链／交织引理 → 第四秩与全局有限界；三块 census 各自封闭其域；最后仅对三个结果取并。[依赖地图](DEPENDENCIES.md)直接链接已发布 S114/S115/S116 原文，本包不重复复制它们。

## 已知有限性与本次结果的区别

[Aires–Kahn，arXiv:2510.26134v1，Theorem 1.6](https://arxiv.org/html/2510.26134v1)已证明：固定宽度时，最大不可比度 π(P) 趋于无穷会使平衡常数趋于1/2。对本核每个顶点都有不可比顶点，所以链膨胀满足 π(P)≥max_i|C_i|，从而 N≤7π(P)。结合该定理可推出本固定核的潜在反例只有抽象有限范围。

因此，本次不主张“首次证明有限性”。本次成果是**给出可直接复现的具体完整区域，并实际排除该核的全部正整数权重类**。本证明的具体界不依赖上述外部定理；这里引用它是为了正确界定已有背景。不作外部新颖性声明。
