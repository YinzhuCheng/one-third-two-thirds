# S112：最小反例的必要结构与受保护前缀排除

本包针对有限偏序的 1/3–2/3 猜想，概率始终取**完整线性扩张上的原始均匀分布**。它整理结构证明、精确证书和有限枚举；不是猜想的解答，不给出普适反例阶数上界，也不主张结果具有文献新颖性。独立证明检查与独立程序复算不等于外部同行评审。

## 阅读顺序与结论边界

1. `minimal_counterexample_reductions_20261010.md`：若反例存在，最小阶反例具有连通的可比图和不可比图，所有真非平凡自治模块都是链，并具有唯一的强多数全序和刚性。合并极大链模块得到素骨架 Q，但必须保留正整数链长 w；原偏序是 Q 的链膨胀，不能把无权 Q 当作同一概率律下的反例。
2. `minimal-counterexample-reductions/audit/AUDIT.md`：复核上述证明、精确链模块纤维、带权词计数及实际顶点强迫图与端点图的等价。形式底/顶端点的有向环可排除所有正权重；仅当明确知道 w_i=1 时才可合并该块端点。
3. `poset-prefix-width3-search/README.md`：三组宽三核的有理数证书覆盖整个闭概率单纯形，因而排除满足保护条件的初始理想。三组充分保护条件下的“存在平衡对”结论已由保持下来的 very-good pairs 和既有定理推出；这里保留精确证书作为自适应选对、定量界与验证方法的展示，不将其列为额外结构排除。保护条件是：核为初始理想，且在指定切割秩之前没有核外元素能够出现。允许任意有限合法尾部及共同序和前缀。**任意诱导出现的未保护模板不在排除范围内。**
4. `poset-prefix-width3-independent-audit/AUDIT.md`：独立重建计数、全部严格坏取向单元、仅检查单纯形顶点不足以证明覆盖的负例，以及固定单对失效的合法续接实例。其 `author_snapshot/` 与 `author_rerun/` 是冻结的旧版原样快照，保留旧版 assert 验证器在 `python -O` 下失效的审计证据，不可视作现行通用验证器。须同时阅读[结构范围修正](poset-prefix-width3-redundancy-audit/AUDIT.md)：三组受保护族的平衡对存在性已被 very-good-pair 定理涵盖。现行验证器及两种 Python 模式各 267 项拒绝测试见[验证器加固报告](prefix-verifier-hardening/HARDENING.md)。
5. `prime-core-catalogue/README.md` 及 `prime-core-catalogue-independent-audit/AUDIT.md`：阶数不超过 8 的自然标号素核枚举、宽至少 3 分支、全正权重端点排除和单点块限制。剩余项仅为通过所列必要条件的候选，并非反例。

## 有限枚举摘要

精确自然标号偏序数量（阶数 1 到 8）为 1、2、7、40、357、4,824、96,428、2,800,472。这里不是无标号计数。

宽至少 3 的素核经本包所有全权重结构筛选后：阶数 1–6 无剩余，阶数 7 有 44 个自然标号代表，阶数 8 有 2,552 个；同构类数分别为 1 和 17。七点唯一核的指定代表必须满足 w0≥2、w6≥2；因此该核的反例膨胀至少有 9 个实际顶点。这只是该核的必要条件，不是所有反例的全局 9 点下界。完整分类及单点块必要条件以冻结 JSON 和目录说明为准。有限范围内没有发现比 very-good-pair 筛选更强的额外端点环排除，不表示两种筛选在所有阶数上等价。

## 复现

在本目录运行：

```sh
python3 reproduce.py --verify-only
python3 reproduce.py --mode standard --receipt /tmp/S112-standard-receipt.json
python3 reproduce.py --mode full --receipt /tmp/S112-full-receipt.json
```

Python 3.10+ 即可运行标准库核验及完整主枚举；本次使用 Python 3.12。`standard` 包括完整 n≤8 Python 主枚举，预计需数分钟。`full` 另编译并重跑两份独立 C++17 枚举程序，需要 `g++` 或用 `--cxx` 指定编译器。所有运行发生在临时副本中，不会覆盖包内源文件、结果或冻结审计。脚本逐一比较结构化 JSON，只忽略明确列出的耗时字段；其他差别一律失败。

探索性 `search.py`、`analyze.py`、`find_negative.py` 使用 NumPy/SciPy，仅为发现过程留档，不在标准库复现链中；独立标准库核验覆盖其 28 个已导出候选及最小二对覆盖。精确结论不依赖浮点 LP。含 assert 的旧版身份检验必须正常运行，不能用优化模式省略断言；仅明确加固的验证器另行接受 `-O` 测试。

`REPRODUCTION.json` 给出全部命令、输入和比较目标；`PROVENANCE.json` 记录原样快照的来源与逐文件哈希；`SHA256SUMS` 绑定包内文件，`FILE_LIST.txt` 列出交付内容。包内不包含软件包、缓存、密钥、原始聊天、S111 材料或全局近似路线，也不包含尚在推导的七点加权核新公式。
