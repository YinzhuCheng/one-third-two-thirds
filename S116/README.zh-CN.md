# S116：七点核的终端秩界，以及六个八点核的支撑下界

日期：2026-10-10。本包是本地整理的范围固定增量包，未进行远程发布，不改写任何既有冻结文件。

## 1. 三组最终 PASS 结果

所有概率都指实际链膨胀偏序的完整、带标签线性扩张的均匀分布；平衡区间为闭区间 `[1/3,2/3]`。不是在商核线性扩张或外部排列上取均匀分布。

1. 七点核：覆盖关系 `0<3; 1<2,4; 2<3,6; 3<5; 4<5`，正整数链权重按顺序为 `(u,a,b,c,t,d,v)`。只要 `d=1,v≥4`，或 `d=2,v≥10`，或 `d=3,v≥30`，便有平衡对，其余五个权重不受上限限制。对偶结论同样成立。更进一步，所有 `a=d=1` 的膨胀都被排除为反例，五个自由权重任意。
2. 八点核 C13：无平衡对的链膨胀必须至少有四个非单点链块，因此总阶至少 12。
3. 八点核 C08、C09、C11、C14、C15：无平衡对的链膨胀必须至少有两个非单点链块，因此总阶至少 10。

后两项是按具体同构类给出的必要支撑下界，不是对这些类任意权重的完全排除，也不说明达到下界时反例存在。它们不解决一般 1/3–2/3 猜想。

## 2. 七点核：条件分布、乘积障碍与完整五参数子族

阅读 `general-terminal-rank-bounds/GENERAL_TERMINAL_RANK_BOUNDS.md`，以及 `general-terminal-rank-independent-audit/AUDIT.md`。

在真实 order-polytope 体积模型中，条件于 C1、C2 的坐标，令 x 为 C3 顶点、z 为 C5 底点。恰当标准化后，x 的条件位置 H 是 `Beta(c+k,d+1)` 的正概率混合，`0≤k≤u+t`。C6 中位于 x 前的元素数在给定 H 后服从 Binomial(v,H)。这不假设外部纤维均匀。

通用内秩原子严格小于 1/3 的阈值为 `d=1,v≥5`、`d=2,v≥10`、`d=3,v≥30`。`d=1,v=4` 使用既有三概率三角形证书，并把它从 c=1 正确提升至任意正整数 c，不能套用错误的通用第三秩原子界。good-pair 定理强迫的端点方向与秩间隙共同给出平衡对；不声称某个固定顶点对对所有权重都平衡。

任何假想反例还必须满足

`3(c)_v < (c+d+1)_v`，等价于 `3∏(c+i) < ∏(c+v+i)`，乘积下标均为 `i=0,…,d`。

这里 `(x)_m=x(x+1)…(x+m−1)`。这是必要条件，不是反例的充分判定。对偶变换为 `(u,a,b,c,t,d,v)→(v,d,c,b,t,a,u)`。

当 a=d=1 时，端点与终端界先给出 `2≤u,v≤3`；乘积障碍给出 `b≤u≤3,c≤v≤3`。结合既有独立 PASS 的“四个脊柱权重 a,b,c,d≤3”普遍平衡定理，整个五参数子族被排除。该旧定理的证明与审计是实质依赖，已原样保留。

本包还完整重新核验这一推论的 41 个剩余向量，而不是只给出摘要：按 `(u,v)=(2,2),(2,3),(3,2),(3,3)` 分别为 7、7、7、20 个，最大阶 18。独立实际顶点理想态计数给出全部 1,760 个不可比对分子，共 429 个平衡对；作者的 41 个分母与 82 个见证逐项比对。完整输出见 `reduced_41_certificate.json`、`reduced_normal.json` 和 `author_comparison.json`。

若只假设 `a,d≤3`，本包得到的仅是必要有限区域：`u,v≤29,b,c≤90,t≤104,N≤348`。没有枚举或排除整个区域。更加精确的 `(u,b)` 上界随 a=1,2,3 分别为 `(3,3),(9,19),(29,90)`，d 给出相应的 `(v,c)` 上界。本包明确不收录更新的 `a,d≤2` 有界普查。

独立主核验还比较了 202 个权重向量的链前缀 DP 与精确单纯形积分、14,402 个全 α 最大值、7,500 个相邻比恒等式和 162 个正混合展开。有限核验检查实现；无界结论来自解析证明及明确列出的已审计依赖。d≥4 的通用原子方法障碍不是偏序反例。

## 3. C13：使用纠正版的四块下界

阅读 `C13-four-block-theorem-v2/THEOREM.md`、`CORRECTION.md` 及 `eight-core-support-independent-audit/C13-v2/AUDIT.md`。

既有必要条件强迫块 0、3 非单点，并要求支撑同时碰到 `{1,2,4,6}` 与 `{4,5,6,7}`。若支撑至多三个块，只剩 `{0,3,4}` 与 `{0,3,6}`。三条严格整数不等式及非负逆矩阵给出精确乘积 `A⁻¹(2,2,1)=(5/2,5/2,3)`，整数上界为 `(2,2,3)`；再代回不等式仅剩三个权重全为 2。

两个候选均有 2,060 个完整线性扩张，`B0<B1` 的分子分别为 698 与 742，均在平衡区间。独立审计逐个枚举所有扩张，再用另一套占用状态递推核对全部 110 个无序对和 220 个定向计数。完整矩阵留在 `audit_results.json`。

旧版把上述精确矩阵乘积的末坐标误写为 7/2；它是较弱上界，但不是等号。v2 已改为 3，证书、整数界和结论均未变化。本包保留纠正说明，仅收录 v2 正文与其最终审计，不重复旧版错误等式。

## 4. 五个八点核：两个块的下界

阅读 `five-classes-two-block-theorem/THEOREM.md` 及 `eight-core-support-independent-audit/five-classes/AUDIT.md`。

五个类的 40 个“恰有一个非单点块”族逐一覆盖：36 个有固定顶点对的精确计数多项式证书，3 个由严格结构不等式缩为唯一有限候选，另 1 个是 C09/块1 的相邻秩跨越证书。五个全单点情形也全部重数。

删去变量链后，对每个外部线性扩张，合法插入窗含 h 个不可比元素，插入 t 元链的方案数为 `binomial(t+h,h)`。因此外部扩张的真实权重随窗口而变化。审计直接重建所有分母与分子多项式，再以精确 Newton 展开证明整个无限整数尾部上的非负性；不是从有限 t 网格外推。

34 个固定对族从 t=2 开始，另两个从 t=3 开始并补足 t=2。三个不等式族只有 t=2 需检查。C09/块1 的 t=2,…,9 有完整有限见证，t≥10 使用一般相邻秩间隙界 `M/(t+M)`，其中 M=5，并由端点概率跨越平衡区间，允许平衡对使用链内部秩。

审计核对了 37 个直接外部纤维多项式重建、74 个有理多项式恒等式、296 个精确网格实例、644 个定向计数、18 个有限或全单点见证，并保留 t=10,11,12,20,40,100 的全部相关秩分子。C11 全单点见证 `212/318=2/3` 正确包含在闭区间内。

## 6. 离线完整复现

需要 Python 3.10+，只用标准库，不联网、不安装依赖。在解压后的 S116 目录执行：

```sh
python3 reproduce.py --verify-only
python3 reproduce.py --receipt /tmp/S116-reproduction.json
python3 -O reproduce.py --receipt /tmp/S116-optimized-driver.json
```

驱动以独立新临时副本运行每条命令，并先删除该步骤应生成的输出，杜绝旧结果造成假通过。14 条计算命令包含 16 个完整输出比较；所有 JSON 数学字段、输入哈希、完整逐向量结果及作者文本输出均逐字节一致。没有忽略任何结果字段，也没有 elapsed 字段例外；驱动耗时只写入包外回执。

七点核作者和各独立脚本都分别运行普通与 `-O` 模式。两个八点核作者校验器使用 assert，故只在断言启用模式运行，其 `-O` 执行不作为证据。对应独立审计使用显式异常检查，在普通与 `-O` 下都完整核验。无论驱动自身是否优化，子进程环境均清除 PYTHONOPTIMIZE。

`FILE_LIST.txt` 列出所有交付文件；`SHA256SUMS` 覆盖除自身外的全部文件；`PROVENANCE.json` 区分冻结来源与包级新编文件。驱动在复现前后验证清单、来源、实际审计源哈希、源副本字节一致性、嵌套清单和历史依赖。可移植性守卫阻止意外读取原研究目录，不是安全沙箱。顶层复现不读取原工作区。
