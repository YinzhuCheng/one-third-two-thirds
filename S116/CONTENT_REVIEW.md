## Reproduction and optimization safety

The package driver and all independent audit verifiers use explicit exceptions. Each computation receives a fresh disposable copy; outputs to be compared are removed first. Every generated JSON or declared text output is compared byte-for-byte. No result field, timing field, input hash, or vector record is omitted from comparison. Driver receipt timings are external run metadata only.

The two eight-core author verifiers use assert. They are run only in normal Python with PYTHONOPTIMIZE cleared, including when the driver itself runs with -O. Their optimized execution is not presented as evidence. Both corresponding independent auditors have explicit optimization-safe checks and run in normal and -O modes. This limitation is stated rather than editing the frozen source or silently disabling checks.

The fresh-copy driver verifies all package files, provenance classifications, nested audit hashes, source snapshot equalities and historical dependencies before and after execution. A portability guard blocks accidental reads of original research directories; it is not a security sandbox. Standalone audit verify_snapshot.py scripts additionally supply normal/-O corruption rejection; the private package validation records their runs and package integrity negative controls.
