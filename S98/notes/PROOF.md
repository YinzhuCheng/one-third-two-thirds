## 1. 来源与真正要移植的部分

外部来源：[OpenAI, Exact Uniform Sampling of Contingency Tables with Arbitrary Margins](https://github.com/openai/math/blob/adc7f1241b42e322a6451854ab7e4b4c146bf78a/preprints/Exact-Uniform-Sampling-of-Contingency-Tables-with-Arbitrary-Margins-September-24-2026/build/sections/signatures.tex)，固定版本adc7f1241b42e322a6451854ab7e4b4c146bf78a，`Pair summation`引理及`eq:pair-one`。已逐式检查正方向投影、二次展开和端点求和。这里借用的是这段可单独证明的线性代数，不是把偏序未经计数证明地改成列联表。

本稿基底来自[Chan–Pak, Correlation inequalities for linear extensions, arXiv:2211.16637v2](https://arxiv.org/html/2211.16637v2)，§6.1 Proposition6.1、公式(6.1)及Lemma6.2。该命题在原文以CP24 Prop14.9为背景输入；本轮核对其准确陈述，不重新证明全部组合atlas。

### 1.1 需要小心的三件事

任意一正特征值矩阵之和未必仍只有一个正特征值；任意删点坐标也未必产生这样的矩阵；即使总计数有某种凹性，也不能自动认定固定标签方向分子有同样性质。下面同时给出正确矩阵、共享关系和原律方向解释。

## 2. 一般入口模型与真实首两步矩阵

P为有限偏序，Z={z1,...,zm}包含m≥2个不同极小元。假设

    B=P\(⋃_{z∈Z} ↑z)=(b1<...<bR), R≥1，

其中↑z含z自身。B是下理想，且B的每个点与Z的每个点不可比。宽度≤m+1且|Z|=m时B自动成链；本定理更一般地只假定B成链。除这些条件外，P的大小、后继结构、放行阈值均任意。

B_j={b1,...,bj}，P_j=P−B_j。定义

    E_j=e(P_j),
    C_j^z=e(P_j−z),      0≤j≤R。

C_j是列向量，约定C_(R+1)=0，E_(R+1)=E_(R+2)=0。

固定有序前缀B_j再接z时，剩余扩张数恰为C_j^z。于是

    E_j−E_(j+1)=1^T C_j，
    s_z:=Σ_(j=0)^R C_j^z
       =#{σ∈L(P):z是Z中首个出现者}，
    Σ_z s_z=E_0。                                      (2.1)

此后概率均取原P完整线性扩张的均匀律；仅在明确给定B_j有序前缀时使用P_j的均匀条件律。

### 2.1 Chan–Pak基底的准确专门化

对任意至少二点偏序R0，其极小元集合M上的矩阵A(R0)定义为

    A_zw=e(R0−z−w),                      z≠w∈M；
    A_zz=Σ_{v∈min(R0−z), z<v}e(R0−z−v)。

其对角线计数“第一点是z、第二点是z的后继”的完整扩张；不是删去同一个标签两次。按第二点分解，行和是e(R0−z)，全部项之和是e(R0)。

A(R0)至多有一个正特征值。这是CP Proposition6.1的直接推论：给R0添加一个孤立标记a，取k=2，再取原极小元的主子矩阵。标记a在第三位；非对角和对角恰化为上述计数。只有二点时也可直接算出。

### 2.2 保留私有放行对角线

对P_j，定义m×m矩阵V_j：

    (V_j)_zw=e(P_j−z−w),                            z≠w；
    (V_j)_zz=Σ_{v∈min(P_j−z), z<v}e(P_j−z−v)。      (2.2)

j<R时，P_j的极小元恰为Z和b_(j+1)。删b_(j+1)后，新放行的后继只可能是下一个B点，因为P\B中的每个点仍被至少一个Z入口阻挡。因此首两步矩阵是

           [ V_j          C_(j+1) ]
    A_j =  [                       ]，
           [ C_(j+1)^T    E_(j+2) ]               (2.3)

且

    V_j 1 + C_(j+1)=C_j。                           (2.4)

j=R时附加的b行列为零，结论仍成立。CP输入保证每个A_j至多一正特征值。

把A_j按“m个入口坐标、全部极小元之和、b坐标”作合同压缩，可得

          [ V_(t−1)    C_(t−1)    C_t     ]
    M_t = [ C_(t−1)^T E_(t−1)    E_t     ]，       (2.5)
          [ C_t^T     E_t        E_(t+1) ]

1≤t≤R+1。合同压缩不增加正惯性指数，所以M_t至多一正特征值。这一步识别了115所需的共享相邻块，而不是只验证每条标量序列。

## 3. 局部成对消元：独立证明并保留余项

### 引理3.1

若对称矩阵M至多一正特征值，且e^TMe>0，则

    v^TMv ≤ (v^TMe)^2/(e^TMe)。                    (3.1)

证明：v减去其M正交投影到e后的向量与e正交；若平方为正就产生二维正定子空间，矛盾。

取实向量h∈R^m满足h^Ts=0，令

    g_0=0，
    g_t=[Σ_(l=0)^(t−1) h^T C_l]/E_t，1≤t≤R，
    g_(R+1)=g_(R+2)=0。

所有分母E_t均正。末端的累计分子因h^Ts=0而消失。每步有

    h^TC_(t−1)=E_t g_t−E_(t−1)g_(t−1)。           (3.2)

对M_t取v=(h,g_t,−g_t)。令e_a,e_b为两个附加方向，则

    v^TM_t e_a=E_(t−1)(g_t−g_(t−1))，
    v^TM_t e_b=E_(t+1)(g_(t+1)−g_t)。

E_(t−1)>0，始终可使用(3.1)的e_a方向。设A_t=E_tg_t²，精确展开给出

    −h^TV_(t−1)h ≥ 2A_t−A_(t−1)−A_(t+1)
                      +E_(t+1)(g_t−g_(t+1))²。   (3.3)

若E_(t+1)>0，也可改用e_b方向，把最后的非负余项换成

    E_(t−1)(g_t−g_(t−1))²。                       (3.4)

这与115的Pair summation使用同一二次差分恒等式。区别是本模型E_0不为零，但g_0=0，故A_0=0；不能把它伪装成原来源的u_0=0假设。非负余项在本稿不被丢弃。

## 4. 主定理：整条链消去以后仍有一正特征值

定义

    W=Σ_(j=0)^R (j+1)V_j。                         (4.1)

则

    W 1=s，   1^TW1=E_0，                         (4.2)

并且W至多有一个正特征值。更精确地，对每个h^Ts=0，

    −h^TWh ≥ Σ_(t=1)^(R−1) t E_(t+1)
                         (g_t−g_(t+1))² ≥0。      (4.3)

证明：(2.4)的加权求和给行和(4.2)。将(3.3)乘t后对t=1,...,R+1求和。由于A_0=A_(R+1)=A_(R+2)=0，二次差分的加权和为0。得到(4.3)。h^Ts=0是一余维子空间，所以W正惯性指数至多1。

**范围。** 这是任意m、任意R与任意兼容后端的定理，不要求每个V_j任意求和都会保持性质。本结论依赖的是同一原偏序的(2.3)–(2.5)，以及恰当权重j+1。没有生成或采样列联表；没有重新证明全部宽度三。

## 5. 两入口：共享部分、偏差与固定方向能量

取Z={x,y}。写

    D_j=e(P_j−x−y)，
    H=Σ_(j=0)^R(j+1)D_j，
    R_x=Σ_(j=0)^R(j+1)(V_j)_xx，
    R_y=Σ_(j=0)^R(j+1)(V_j)_yy。

于是

    W=[R_x H; H R_y]，
    E=2H+R_x+R_y，
    p:=Pr_P(x先于y)=(H+R_x)/E。                   (5.1)

这些与S97双极小元插回的共享/私有分解一致。主定理给出一个新的本项目联合约束：

    R_x R_y ≤ H²。                                (5.2)

它不是原猜想本身。两个入口完全可以非常不平衡而仍满足(5.2)。未完成该精确消元表述的穷尽查新，不以“新相关不等式”发布。

令

    T_t=E_t/E，
    q_t=Pr_P(x先于y | 完整扩张以B_t开头)
       =[Σ_(j=t)^R C_j^x]/E_t，q_0=p，
    Δ=H/E−p(1−p)≥0。                              (5.3)

h=(1−p,−p)满足h^Ts=0，且g_t=p−q_t。将(4.3)除E，得到

    Δ ≥ Σ_(t=1)^(R−1)t T_(t+1)(q_(t+1)−q_t)²。     (5.4)

这是同一固定入口对在真实前缀条件化下的漂移能量界。Δ与S53的排序缺陷ρ不是同一个量，尚未证明两者的比较。它也不保证Δ普遍小。

### 5.1 同时控制第一步的版本

R≥2时，在t=1,...,R−1取(3.3)、(3.4)平均，在剩余两步只取(3.3)，得到

    Δ ≥ Σ_(s=0)^(R−1) β_s(q_(s+1)−q_s)²，          (5.5)

其中

    β_0=1/2，
    β_s=[s T_(s+1)+(s+1)T_s]/2， 1≤s≤R−2，
    β_(R−1)=(R−1)T_R/2。

每个β均正。Cauchy–Schwarz进而给0≤a<b≤R时

    |q_b−q_a|² ≤ Δ Σ_(s=a)^(b−1)1/β_s。            (5.6)

若某前缀中同一标签对具有足够平衡余量，并另外能证明右侧误差足够小，便可传回原律。这里没有无条件删点传递：罕见前缀的T小，误差允许很大；Δ本身也含原方向，实际应用需要额外结构上界，不能把计算Δ称成免费的选点算法。

### 5.2 一个完成数有限证书，以及不夸大其收益

把(3.3)不加权求和，二次差分之和变成A_1。记

    a=C_0^x，b=C_0^y，s=a+b，G=ΣD_j，α=a/s。

整理为

    (p−α)² ≤ (E−s)/(sE) · [G−ab/s]。              (5.7)

S96的经典Stanley对数凹给D_j对数凹。若D_0>D_1，G≤D_0²/(D_0−D_1)。因此五个实际数E,a,b,D_0,D_1即可给一个充分平衡区间。它是条件证书，不一定比S96证书强。

探索阶段4000个随机三链对象的12000个入口配置中，该五数区间通过339次，没有出现它通过而原S96五数判据不通过的实例。因此本轮没有依据把它宣传成计算性能改进，主结果是共享矩阵与能量连接。该探索非完整同构类枚举，统计独立于第7节最终检查器。

## 6. 具体校准与准确失败路线

### 6.1 S96的21点例：这次核对的是新的矩阵

B_12、X_4、Y_5三链，另加b3<x3、b5<y3。两个入口为x1,y1。既有对象的E=24172740，本轮重新计算得到

    W=[4504665 7214375; 7214375 5239325]，
    s=(11719040,12453700)，
    p=585952/1208637。

Δ=284458026895/5843213591076，约0.0486818。条件方向q_t从约0.484804逐渐变成4/9；(5.5)左侧对应的加权能量约0.000232301，小于Δ。

这不是新发现的21点偏序，也不声称它给能量界取等。对这个对象，把(5.6)跨到极罕见末端的误差界很松，不能冒充高精度传递。

### 6.2 不能把任意链坐标删除数组当成CP矩阵

取四点偏序(0<1)⊔(2<3)，使用坐标链(0,1)、(3)、(2)。删除两个坐标前缀点，非下理想删除记0，得到

    N=[1 0 2; 0 0 1; 2 1 0]。

它有两个正方向：v=(1,0,0)、w=(−2,3,1)满足

    v^TNv=1，v^TNw=0，w^TNw=2。

因此N在它们的张成空间上正定，不能满足一正特征值假设。这个小例只否定未经证明的朴素数组映射；正确的CP矩阵保留“删去入口后新放行后继”的对角项，二者不同。将该例与任意有限偏序作上方序和，全部有效完成数同乘其扩张数，得到任意规模的同类映射障碍；序和保持本身是标准背景。
