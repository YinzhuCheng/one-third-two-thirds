## 实际完成的本轮复算

发布侧在独立的本目录暂存副本上运行以下三个标准库 Python 程序，全部正常退出：

1. `python audit_general_square_exact.py`
2. `python audit_universal_conditioning_exact.py`
3. `python logconcave-audit/check_logconcave_exact.py`

运行生成的三个 JSON 文件与独立审查提供的结果逐字节一致；前两个程序的标准输出也分别与随附 `.log` 一致。

- 共同下集：5,230 个自然标号偏序（2–6 点）、16,502 个不可比对、116,882 个删除纤维；包括 6,428 个共同不可比集非链的元素对。
- 单次条件化：2–5 点中 2,369 个有向元素对实例，核对完整扩张集合和原事件计数。
- 双条件化：406 个自然标号偏序（2–5 点）、2,126 个任意不可比对；逐项核对两个条件集合、上下集保持、对偶映射及四格计数。
- 解析校准：5,000 个有理向下凸多边形、5,000 个齐次分段线性势、961 个多项式存活函数实例，以及所列精确校准公式。

自然标号枚举利用重标号不变性，不能表述为枚举了全部冗余数值标号。上述检查不证明任意规模结论，也没有增加枚举规模。
