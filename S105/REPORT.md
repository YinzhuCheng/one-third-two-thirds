# S105：MC3 固定五对菜单的真实宽三反例

日期：2026-10-10。与 S104 一并发布，保留先前推理和发现记录。

## 结论与准确否定范围

**MC3 固定菜单，包括两步版本：REFUTED。MAIN33、WIDTH3、TEN40：OPEN。U58：UNDER_AUDIT。**

被否定的准确命题是：P 为有限宽度≤3偏序，x,y 是极小元，包含根的主上集之外恰有两点链

    P\(up(x)∪up(y))={a<b}，

且 Pr(a<x)>2/3、Pr(a<y)>2/3 时，五个固定对 (a,x),(a,y),(b,x),(b,y),(x,y) 至少一个应平衡。反例甚至满足额外的 Pr(x<y)>2/3。

这里所有概率属于同一个原 P 的均匀完整线性扩张律。五对菜单之外仍有实际平衡对。因此被否定的是固定菜单的充分性，**不是所有宽三偏序存在平衡对，更不是 1/3–2/3 主猜想**。S104 的 HALF/L 反例只否定更强的单边不等式；S105 进一步否定了菜单本身。S104 中 MC3 OPEN 的文字保留为较早阶段记录，现由本报告更新。

## 1. 54 点主证书

标签为 x,t；y,z₁,…,z₇；a,b,c₁,…,c₄₂。取以下三条链及两条跨链关系的传递闭包：

    x<t
    y<z₁<…<z₇
    a<b<c₁<…<c₄₂
    a<z₁，x<c₁。

不存在其他生成关系。三链覆盖证明宽度≤3，极小元 a,x,y 构成三元反链，故宽度恰三。除 a,b 外，每点在 x 或 y 的主上集中；a,b 均不在其中。因此避入口集精确为 {a<b}。五个菜单对全部不可比。

总扩张数和固定顺序 (a<x),(a<y),(b<x),(b<y),(x<y) 的方向计数为

    E=132985636140
    K=(88749332490,110858517420,43864612610,88731398700,99534804600)。

准确严格差为

    3K_ax−2E=276725190>0
    3K_ay−2E=66604279980>0
    3K_xy−2E=32633141520>0
    E−3K_bx=1391798310>0
    3K_by−2E=222923820>0。

因此 a<x、a<y、x<y、b<y 的概率均严格大于 2/3，而 b<x 严格小于 1/3。反向概率同样不在闭区间 [1/3,2/3]，五个无序菜单对全部失败。没有声称 54 是全体偏序中的最小反例点数。

输入：[shrunk_0.json](mc3_coupled_search/shrunk_0.json)。完整结构及加边计数输出：[verified_shrunk_0.json](mc3_coupled_search/verified_shrunk_0.json)。[独立全对审查](mc3_counterexample_n54_audit.txt)枚举 816 个理想、1930 条转移，核对全部 1431 个互补对，得到 64 个实际平衡无序对。例如 Pr(y<c₁)=689761/1464535，约 0.471，已经落在平衡区间内。

## 2. 72 点发现记录

原例三条链为 x<t、y<z₁<…<z₁₃、a<b<c₁<…<c₅₄；跨链关系 a<z₁、x<c₁、c₅₀<z₈。其总数与五计数为

    E=137477769300297
    K=(91743653083395,117303434549811,45491483154535,97129099799325,106960274991892)。

对应五个严格差为 (275420649591,76954765048839,45925286375082,1003319836692,16431760797381)，全部为正。完整理想 DAG 的独立全对计数发现 81 个平衡无序对。一个菜单外例为 (c₁,y)，其方向计数 79885668970800，概率约 0.581。这直接展示主猜想没有被此证书否定。

输入：[原 72 点证书](mc3_coupled_search/MC3_COUNTEREXAMPLE_high.json)，[独立审查](mc3_counterexample_audit.txt)。这个例保留为发现记录；不因后续缩小而覆盖历史数据。

此外，[自含二项式计数证明](mc3_coupled_proof.txt)及[独立审读](mc3_binomial_proof_audit.txt)直接分解门约束下的前缀、后缀和 x 后继的插入位置，独立复现全部六个整数及菜单外 (c₁,y) 见证。这个有限反例证明无需 Chan–Pak、XYZ、S103 平方或渐近输入；[公式检查程序](verify_gated_family_binomial.py)与[完整二项式证书](gated_family_binomial_certificate.json)随附。

## 3. 计数方法与证据纪律

- 搜索使用真实三链覆盖偏序，所有判定由整数计数作出；浮点只用于选择搜索方向。
- 独立顶点位集理想 DP 对每个比较单独添加先后约束，并核对反方向补集之和等于 E；不导入搜索代码。
- 另一独立实现沿原偏序全部理想的合法转移做前后向完成数，计算所有实际标签对，并核对逐秩总质量与比较关系。
- 发布侧复跑核心验证和独立的原始生成关系递归计数；精确日志随附。程序证书不被说成外部数学审稿或形式化认证。

## 4. 仍成立的两尾特殊族定理

[两尾救援证明](two_tail_mc3_rescue.txt)及[独立审查](two_tail_mc3_rescue_audit.txt)处理准确生成关系 a<b<c₁<…<c_m、y<z₁<…<z_r、a<z₁、x<z_s、x<c₁，其中 m,r≥1、1≤s≤r，且 x 是单点链。该子类在双多数前提下必有 (b,x) 或 (b,y) 平衡，无需入口方向多数。

计数耦合及二项式比给出全参数自含证明，不是网格外推。54 点反例带实际 x 后继 t，且没有 x<z_s 的生成条件，属于不同结构；不与子类定理冲突。这个正面结果也不恢复一般 MC3 固定菜单。

## 5. 后续研究

停止以证明这个固定菜单为目标。要保留主猜想的研究方向，必须允许候选实际标签越出 {a,b,x,y}，并在原律下说明选择规则或迁移为何有效；不能仅凭每个条件分支内有某个好对就回传一个统一好对。

S104 的双侧平方、严格联合生存界、固定释放标签分解仍各按其原假设成立。有限菜单反例不否定这些已证辅助命题，也没有解决一般 WIDTH3。完整有类型失效/保留图见 [DEPENDENCIES.md](DEPENDENCIES.md)。
