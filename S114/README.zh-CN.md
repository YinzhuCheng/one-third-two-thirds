## 1. 七点核：完整权重混洗与有限悬挂锥

七点商核覆盖关系为 `0<3; 1<2,4; 2<3,6; 3<5; 4<5`，正整数链权重按 `(u,a,b,c,t,d,v)` 排列。B_i、T_i 是第 i 块的底、顶点；概率始终取实际膨胀偏序全部线性扩张上的均匀分布。

阅读 `generalized-seven-core-shuffle/GENERALIZED_SHUFFLE_BOUND.md` 及 `generalized-seven-core-shuffle-independent-audit/AUDIT.md`。全权重严格上界为

- Pr(B2<B4) < (b+c+v)/(b+c+v+t)
- Pr(T4<T3) < (b+c+u)/(b+c+u+t)

结合既有结构性强迫方向，假想反例必须满足 `2t<b+c+min(u,v)`。连同旧端口不等式，可得到精确整数锥。设 `s=b+c`、`α=a+b−1`、`β=c+d−1`，并设

`U=⌊(2α+β)/3⌋`、`V=⌊(α+2β)/3⌋`、`T=s−1+min(U,V)`。

固定四个脊柱权重 `(a,b,c,d)` 后，剩余全部必要候选恰为

- `1≤t≤T`，`L=max(2,2t−s+1)`
- `L≤u≤t+U`
- `max(L,2u−t−α)≤v≤⌊(u+t+β)/2⌋`

这是固定脊柱后的有限显式范围，不是全局阶数 n 上界。锐利性仅针对这个必要不等式松弛；锥中的点不等于反例。完整前缀/后缀纤维条件、严格性、对偶与新计数分子均有独立证明。

## 2. 七点核：两个无限族排除与剩余约束

`single-outer-spine-exclusion/TWO_SINGLETON_INNER_BLOCKS_EXCLUSION.md` 证明每个正权重 `(u,a,1,1,t,d,v)` 都有平衡对。单外脊柱结论是其较早特例。对应审计单列为 `generalized-seven-core-shuffle-independent-audit/RANK_AND_INNER_SINGLETON_AUDIT.md`，不是主混洗审计的一部分。该补充还证明更强的秩链方向及二项式必要条件。

`single-inner-spine-exclusion/SINGLE_INNER_SPINE_RESULT.md` 给出积分证明。当 `c=d=1` 且 `v≥t+1` 时，最终独立审计进一步将作者原文的弱不等式加强为

`Pr(B3<T6)+2 Pr(T6<T5)<2`。

两个结构性强迫方向使该族不可能成为反例；特别排除所有 `(u,a,b,1,1,1,v)`。积分证明依照实际 order-polytope 条件分布进行，不用有限枚举代替无限论证。最终复核见 `single-inner-spine-independent-audit/`。对偶结论同样成立。结合完整混洗界，所研究的 `(u,1,b,1,t,1,v)` 家族仍可能落在 `2≤v≤t≤b`；不能宣称整个单内脊柱家族已排除。

结合已审计的依赖，任意该七点核上的假想反例必须同时满足：

1. 端口 `u,v≥2`
2. 内脊柱 `b≥2` 或 `c≥2`
3. 七个块中至少四个非单点
4. 四个脊柱权重 `(a,b,c,d)` 中至少一个≥4，依据下一节的完整有限证书

这些是该商核链膨胀类的必要条件，不能直接升级为所有偏序反例的全局结论。

## 3. 七点核：81 个固定脊柱的完整精确证书

阅读 `weighted-seven-core-census/ANALYSIS.md` 及其独立审计目录。对 `a,b,c,d∈{1,2,3}` 的全部 81 个脊柱，上一节锥范围恰有 2,767 个权重向量；不是任取悬挂权重截断的盒子。每个向量均被结构性强迫方向筛除，且另有实际标号顶点平衡对的精确检查。故任意悬挂权重下，这 81 个固定脊柱均被排除。

较短的旧四方向菜单留下 21 个；加入两个中间方向后归零。在这 18 个方向的有限集合覆盖问题中，最小菜单为五项且恰有两个。其最小性只限此有限候选集合。

纯二项式解析筛选仍留下 185 个锥内向量，所以不能把解析界本身说成已清空该区域。原文的作者异实现验证与本包另行冻结的独立审计是两个层次。全部计算为整数或有理数；耗时不属于数学证书。

## 4. 八点核：按类的额外非单点要求

阅读 `eight-core-weight-filters/RESULT.md` 及 `eight-core-weight-independent-audit/`。范围仅为冻结的 C02–C18 共 17 类，标签以 `input_cores.json` 为准。

一般插入窗口界产生 57 条必要线性不等式。结合旧端口强迫非单点集合 F，四条最小额外单点禁集出现于 C06、C10、C13。对其余所有块都为单点的族，精确逆矩阵给出有限上界，只剩 22 个权重向量，再以实际顶点计数逐个排除。因此每类都必须有至少一个 F 外的非单点块，即至少 `|F|+1` 个非单点块。

这个数随类变化：C07 至少 4；C03、C05、C12、C13、C16、C18 至少 3；C02、C04、C06、C10、C17 至少 2；C08、C09、C11、C14、C15 至少 1。不能写成“所有八点核至少三个非单点块”。这些下界没有被断言对真正反例可达。

全部 17 个全局线性锥仍可行，统一见证为全 2 权重；没有整个核被任意权重排除。4,352 个 `{1,2}^8` 实例是有限实现检验，和先证明有限化、再检查 22 个候选的无限族排除须分开理解。
