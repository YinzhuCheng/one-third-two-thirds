# S99 探索用途与失败边界

本轮程序用于校准真实计数、发现可解析族和检查交换映射。一般结论以 notes 中的证明为依据，有限无反例不是证明。只保留对接续有用的结果，不为扫描数量增加研究状态。

## 已转化为解析论证

1. 三链门点族扫描引出 notes/EARLY_JUMP_FAMILY.md 中的真实参数族。其数学证据是三种根序的插回计数和全部 m 的公式，不是扫描范围。
2. 固定极小锚点的上移测试引出五点双分叉例。e(P)=20 的完整计数已自含写出。
3. 非极小点平方上界的反例 C9⊔{y} 由十个插回槽直接证明；前驱修正下界在此取等。

## 未闭合的探索

- 随机小偏序对 dU≤p² 的试探没有找到反例。抽样分布不是同构类均匀，也没有覆盖全部有限偏序；本轮没有据此把候选提升为已证。其有效产物仅为“条件前驱就绪事件后，转为相同严格下集模型”的准确重述。
- 双极小入口更一般避入口形状的平方上界试探也未构成范围扩展。S99已证陈述沿用S98的避入口链假设，宽度三自动满足；不将有限试探作为一般非链版本证明。
- 在已解析门点族上添加兼容跨链边，没有得到真正 MC3 反例；不能把精确1/3或2/3边界点当成严格失败，也不继续扩大同一参数扫描。
- 将每条后端扩张固定为链后，对入口窗口做任意凸组合，在 R=2、3 的松弛中可以制造菜单失败。问题是某些分量让同一入口无后继，另一些分量让它有后继；这不可能是同一个固定 P 的不同扩张。该失败提醒保留实际共同后端结构，不能冒充真实偏序反例。

## 可复跑的有限诊断

`../src/check_s99.py` 汇总两份标准库检查器，输出到 `../evidence`。MC3边界检查包括明确R1模型、无限族的若干参数、独立全排列小例。后继检查包括真实交换单射、五点分叉和链反例。精确对象、数量和返回状态以本轮 JSON 实际输出为准。

这些程序不是自动证明框架，不要求新会话先运行，也没有重新验证所有旧轮程序。保留解析论证、准确反例范围和剩余接口，比增加测试规模更重要。
