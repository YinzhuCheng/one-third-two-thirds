# S72 研究报告：一般模块选对定理与十参数六个无限区域

日期：2026-09-30。完整论证：[notes/PROOF.md](notes/PROOF.md)。本稿未经过外部独立审查，也未完成穷尽的新颖性调查。

## 这轮推进

不再固定六个主链点为单点。先在任意有限偏序中证明一个定量选对接口，再应用到全部十个模块都可增长的模板。

设不可比点 x,y 有相同严格下集。令 A={x}∪(U(x)\U(y))，L=|A|；B=(y=y1<...<yb) 是自治链模块。对每个 k<=b：

    p(x,y_k) <= 1 - binom(b,k)/binom(L+b,k).

A 可以不是链，另一侧排他上部也不必是链。证明使用完整扩张的真实交错权重、合法交换注入和均匀二色词的正相关，绝不将删除后的投影重新均匀化。

若完整排他上部 Y={y}∪(U(y)\U(x)) 还是链，则其位置质量递减。结合 S70 分位数引理，得到：

- L>=2、b>=2L 时，原 P 中有一个 (x,z)，z∈Y，为 2/5 平衡对。
- 精确充分条件：b>=2 且 3b²-(4L+3)b-2L²+2L>=0。
- delta(P)>=b/[2(L+b)]，因此 b/L→∞ 时趋于 1/2，外部结构允许任意共增长。
- 此一般结构类的 2/5 常数尖锐：不交的二点链与四点链有 delta=2/5。这不是十点模板的尖锐性结论。

## 六个真正混合的十参数区域

主链长度 s1,...,s6，链外长度 a,b,c,d 对应 U,V,W,Z。置 T=s2+s3+s4+s5、H=b+c。

下列任一条件都保证 2/5：

    b>=2T; c>=2T; s2>=2H; s5>=2H;
    a>=2(s1+s2+b); d>=2(s6+s5+c).

其余参数不必固定。例如 b=c=t、s2=4t 时，其他七个参数可任意共同增长。这是解析定理，不是有限盒中的经验外推。

还得到内部副本概率的双侧超几何包络；它本身尚未产生覆盖所有中间比例的共同标签选择。对每个固定主链长度，未被六区域覆盖的外部参数有明确有限上界，但本轮没有计算那些一般切片的全部剩余核。

## 对方法的整理与失败边界

S22/S26 已有合法二色交换、FKG 和全秩概率包络。Zaguia 已有 good-pair 的链位置单调性。本轮不重新认领这些工具；新增的是将排他闭包、自治前缀、完整链分位数连接成定量定理，并得到上述混合参数域。

自治条件不能删掉：四点 x,y,t,z，仅 y<z、t<z，x 孤立，有 p(x,y)=3/8；把非自治链 y<z 当作模块会错误地预测 <=1/3。

链替换也不使 delta 单调增加：只有 C2 从长度 2 增到 3、其余模块单点时，delta 从 165/331 降到 237/524。故不能靠逐点膨胀的单调性来延伸有限例子。

## 计算与证据组成

完整主证明不依赖任何计算核。附带算术检查包括：2–6 点的 5,230 个自然标号偏序、37,916 个秩概率界，以及六区域各 12 个混合十参数实例，共 72 项。全部检查通过；范围和局限见证明 §7。完整检查代码与数值 CSV 保存在本轮 S72 交接 ZIP，GitHub 先保存研究主稿与结果摘要。这些检查不是外部数学审稿，也不是继续研究的门槛。

## 仍未解决

全部十参数 2/5、全部宽度三、原猜想均未闭合。S71 四链外全域定理继续有效，并在单点主链切片上强于本轮一般界；本轮使用 GitHub 中 399 项有限核心的较新 S71 修订，不覆盖或改写旧历史稿。

优先继续：用双侧内部秩包络处理同阶参数；或把完整排他链 Y 改为有分叉的宽度二结构，研究保留原律的共同候选。这比继续扩大已关闭四参数族的枚举更接近主猜想。
