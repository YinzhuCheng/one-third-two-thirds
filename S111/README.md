# S111：真实纤维结构、MTP2 反例与可实现性障碍

2026-10-10。本包只收录已完成独立数学研究审查的真实纤维结构及证明路线障碍；不包含后续条件全局、宽度或自适应局部化材料。

## 当前结论

- **一般维数尖锐界 `(n−1)EH ≥ nFG` 仍 OPEN。** `E` 为完整线性扩张数，`F,G` 为两个方向计数，`H` 为正方向中可作字面交换的扩张数，`Ru=F−H`、`Ry=G−H`。S109 的一般共同下集平方及有限严格性按原范围保留。本包没有反驳主猜想，也没有证明其全局选点步骤。
- **真实纤维有精确核表示。** 删除两标签后的完整扩张给一个共享整数秩数组 `C[p,q]`，纤维是其嵌套次序统计量核的精确和。两个三角形上的 Bernstein 系数是该同一数组的累计尾和，不能替换成任意非负系数或混合权重。见 [原稿 §§1–2](actual_fiber/REPORT.md)。
- **一般真实纤维 MTP2 为假，最小反例点数为 8。** 严格前驱掩码 `[0,0,3,3,1,2,23,43]`，标签 `u=2,y=3` 给真实连续纤维的负二阶小行列式；独立审查还给严格内部方形 `[1/10000,1/100]²` 的精确负值。它的 `E=200,F=G=100,H=74,Ru=Ry=26`，普通平方余量为 `4800`，维数尖锐余量为 `23600`，两者都为正。见 [独立核心审查](independent_audit/INDEPENDENT_AUDIT.md)。
- **最小性是明确有限范围的精确计算结论。** 对所有 `n≤7` 的可实现共同下集纤维，两侧完整多项式系数均非负；覆盖性、跨对角线导数跳跃及端点单独核查。不同生成器复核 858 个多极大共同前驱配置及另外 39,829 个空下集／唯一极大前驱配置；相同上集的全部情形有直接解析证明。全系数证书随附，不用粗网格无反例来代替证明。
- **共同前驱递推成立。** 非空共同下集下，首坐标递推和最后共同前驱标记理想递推保留真实纤维、前缀完成数和原 `E,F,G,H`。独立检查覆盖 `n≤7` 的全部 94,368 个有序配置、64,216 个标记理想分支及 2,277,476 次字面交换继承检查。空下集是终止恒等情形，不能读成空的最后前驱和。见 [§5 专门审查](recurrence_audit/SECTION5_AUDIT.md)。
- **抽象混合仍不足以证明尖锐界。** `g=(5/6)(1−s)²(1−t)³+(1/6)(1−s)(1−t)³` 同时满足指定凹性、MTP2、边界、全局多项式、非负 Bernstein 系数及整数核直方图条件；乘以 `7!` 后为 `(E*,F*,G*,H*)=(455,185,270,128)`，尖锐余量 `−210`。这些是混合函数的整数积分量，**不是实际偏序扩张计数**。固定七点时连整个正比例射线都不可实现：若实际纤维为 `λg`，则 `λ=9F−13H` 是正整数，同时 `λ=f(0,0)≤1`，故只能 `λ=1`，再由反链删除偏序的边界幂律排除。见 [障碍原稿](barrier_audit/source_snapshot/fixed_poset_realizability_barrier.txt)与[独立证明](barrier_audit/AUDIT_REPORT.txt)。
- **单侧不可交换计数为零时，尖锐界及等号分类成立。** 注入证明给 `G≤(n−1)F` 和对称式；若 `Ru=0`，等号当且仅当 `u` 孤立且 `P−u` 以 `y` 为唯一极小点，对称情形交换标签。一般结论由全尺寸证明承担，`n≤6` 枚举仅作补充。仅有两个极小点的 Fishburn 等号条件明确归于 Chan–Pak 的已知结果。见 [精确来源节选 §§1、7](barrier_audit/source_snapshot/proof_route_audited_excerpt.txt)。

## 不能跨越的边界

共同前驱递推中的原完整扩张权重是 `e(I−d)E(P−I)/E(P)`，删除体积权重是 `e(I−d)e(Q−I)/e(Q)`，两者通常不同。分支方向比率也会变化；逐支成立的二次不等式不能直接相加或任意正混合。

MAIN33、WIDTH3、TEN40 仍 OPEN；MC3 固定菜单仍 REFUTED；U58 仍 UNDER_AUDIT。MTP2 的真实反例与尖锐界的抽象解析障碍是不同结论，均不构成主猜想反例。

## 文献与证据等级

MTP2 的边缘封闭性使用 [Karlin–Rinott（1980）](https://doi.org/10.1016/0047-259X(80)90065-2) 的经典输入；本轮核对所需陈述，不重审其外部完整证明。仅两极小点的等号条件沿用 [Chan–Pak，arXiv:2607.06275v1，Theorem 4.5](https://arxiv.org/html/2607.06275v1#S4.SS3)。不主张新颖性。

独立研究审查、精确有限证书、发布侧复算及 Git 提交是不同证据层级；均不等同于外部同行评审或形式化认证。核心审查明确不覆盖 §5，§5 另有专门审查，不能混用通过范围。
