# S93：从自治块到任意放行阈值的下理想链

## 数学增量

1. **S93-RELEASE。** P的下理想链A长度L，Q=P−A，F=Q中aL的全部后继，I=Q\F大小d。假设I有唯一极小元x且x与A全不可比。允许任意多个a_h<v放行阈值。原律K=#{a_i<x}的全部非末端原子均≤d/(L+d)，而且这些原子非增。末端theta=e(Q)/e(P)必须另行保留。证明固定Q扩张后，在弱增槽位格使用经典FKG；不同纤维按真实完成数混合。
2. **S93-PREFIX/QUANTILE。** E_i=e(P−A前i点)给精确p(x<a_i)=1−E_i/E_0。gamma=e(Q−x)/e(Q)满足theta≤1/(1+L gamma)。L≥d且theta≤1/2时可选bal≥L/[2(L+d)]；故L≥2d且L gamma≥1足够得到1/3伙伴。不是无偏删除近似。
3. **S93-DICHOTOMY。** L≥2d时，若x与A都无平衡对，则theta>2/3；同一原P的Q投影精确含theta倍均匀Q分量，TV≤1−theta。因此若Q有一个1/2固定对，转移后给另一个平衡对。此式不能把任意Q的1/3对当成1/2对，不认证S53 rho的等同。
4. **S93-MULTIRELEASE。** S92双门夹层中，任意增加a_(h_j)<c_j（j=2,...,r，0≤h_j≤L−1）。整条A通常不自治，旧H(z)闭式不能直接沿用；但gamma≥1/3未变。因此全部L≥max(3,2r)、任意q/M/右块形状和任意阈值向量，都有bal(c1,a_i)≥L/[2(L+r)]≥1/3。右块宽度二时可得宽度恰三。17点、7000扩张例给43/100。
