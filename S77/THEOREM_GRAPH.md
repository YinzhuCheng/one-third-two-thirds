## 读图规则

USE=实际证明输入；SCOPE=范围扩大；MOTIVE=启发；OPEN=尚缺的连接；REFUTE=反驳准确加强版；KNOWN=文献已覆盖。轮次相邻不自动产生USE边。

## A. 最底层资产：同一原律的真实完成数

```
原P的均匀完整扩张
  ├─理想截面：Pr(prefix-set=I)=e(I)e(P\I)/e(P)
  ├─删除纤维：原律投影按合法插回槽位数长度偏置
  ├─固定完整前后缀／外部实际位置，证明可唯一拼回
  └─明确固定标签事件，再求和／混合
       ├─R18/R28/R32/R44：单标记秩、包含耦合、分布几何
       ├─S22/S26/S29–30：闭包交换、二色输运、秩偏移、容量
       ├─S31–37：条件信息与Markov化的能力／不足
       └─S49–53：稳定排序、正事件下界、近等号局部律
```

这些工具没有给出任意多标记边缘的共同可实现性。单标记能分别实现，不等于所有标记同源实现；一组任意正完成权重也不一定来自同一个偏序。

OPEN：近等号的一维窗口形状 + 全局无平衡对假设 -> 多窗口不能同时极端，或从近极端提取真实固定好对。

## C. 主猜想最直接的结构覆盖链

```
真实完成数/局部输运
  ├─S59方向兼容菜单 -> S60补全情境 -> S61部分比较
  │     -> S62：width≤3且参考跨度≤5，原律固定前沿1/3
  └─S63–64长链与删除比 -> S65局部不可比区间原子界
        -> 固定κ=n-height的O(κ³)有限核
        -> κ≤3的5/14、κ≤4的6/17（去掉已知1/3等号族）

S62短前沿  +  S65长区间
     - - OPEN - -> 一般宽度三的覆盖／终止／联合预算
```

S62与S65互不包含；固定κ不同于固定宽度或不可比度。S62完整树终止只证明当前跨度，不是任意跨度都终止。S62单个情境能补全，也不等于任意情境权重组合都能真实实现。

原问题反例假设产生同一个>2/3方向全序，方向菜单必须兼容它。S63已反驳无跨度约束的恒定长度初始候选；S74又反驳固定排他集合内的全部候选。

## G. 猜想及方法目标的逻辑位置

| 目标 | 准确范围 | 关系/状态 |
|---|---|---|
| MAIN33 | 所有有限非链δ≥1/3 | 未由项目闭合 |
| WIDTH3 | 宽度≤3的MAIN33 | MAIN33的真子任务；其证明不自动给全部宽度 |
| THIN-D | 对每个固定D处理π≤D的全部有限对象 | 采用前沿全局π定理后，这条“所有D”程序足够MAIN33；困难没有消失 |
| Q-TEN40 | 十点模板任意非全一正长度，δ≥2/5 | 更强常数但特殊范围；一般MAIN33既不保证2/5，Q-TEN40也不保证MAIN33 |
| 前沿真实权重封闭族 | 找可归纳保持且足以抽取固定见证的约束 | 方法目标；可能强于所需存在性，未证，不要求刻画完整边缘锥 |
| 联合窗口缺陷预算 | 无好对时多个近极端窗口不能同时发生 | OPEN；单点矩界不能代替联合约束 |
| 近Gamma/NB形状→好对 | 加真实poset结构和低平衡假设的稳定性 | 研究目标，尚未给可用的一般模量 |
| 离散NB凸序 | Y≤cx 2+NegBin(2,2/μ) | S58未证加强；母函数界不蕴含它，非U58必要输入 |
| 每个最近平均秩对都好 | H_near强选择器 | 比存在性强；不优先作为必经步骤 |
| 全部多标记边缘锥刻画 | 任意规模均匀扩张的完整可实现性 | 可能比原问题复杂得多；暂搁置完整版本 |
| 指定模块无条件近半 | 只要两链都长，无差异限制 | S76真实反例否定 |
