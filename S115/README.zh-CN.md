# S115：七点核中 c=d=1、v≥4 的两个无界子族排除

日期：2026-10-10。本包只在本地整理，未进行远程发布。它是 S114 之后的有限范围增量包，不改写任何既有冻结文件。

## 1. 精确结论与尚未解决的范围

商核覆盖关系为 `0<3; 1<2,4; 2<3,6; 3<5; 4<5`，按顺序以非空链膨胀，权重记为 `(u,a,b,c,t,d,v)`。概率始终是在实际膨胀偏序的全部完整线性扩张上的均匀概率。平衡区间为闭区间 `[1/3,2/3]`。

本包收录并分别独立复核两个无界结论：

1. `residual-rank-obstruction/`：对任意正整数 u,a,b,t，权重 `(u,a,b,1,t,1,v)` 在 v≥5 时有平衡对。
2. `four-tail-rank-certificate/`：对任意正整数 u,a,b,t，权重 `(u,a,b,1,t,1,4)` 有平衡对。

所以 c=d=1 且 v≥4 的整个子族被排除。这里“无界”指 u,a,b,t 没有上限；证明不依赖有限搜索盒子、必要锥截断、最小反例假设或商核的均匀分布。

连同既有的 v≥t+1 排除和 v=1 的结构性矛盾，c=d=1 的剩余候选只能满足 v∈{2,3} 且 v≤t。v=2、v=3 是本包未解决的无界切片；本包明确不收录其后续探索或推广，也没有排除全部七权重、全部宽三偏序或解决一般 1/3–2/3 猜想。本包范围仅反映所收录的冻结证明，不是对后续研究状态的动态总览。

## 2. v≥5：秩原子的统一上界

令 x 为单点 C3，C6 为 F1<⋯<Fv。在真实 order-polytope 均匀体积模型中，条件于 C1、C2 的全部坐标，再积掉 C0、C4，得到 x,z 的密度正比于 `x^u(z−r)^t`，区域为 `s<x<z<1`。C6 在这个条件纤维内是独立的排序均匀样本。

标准化 x 后，其密度为 `(1−h)P(h)`，其中 P 的系数非负。因此 C6 中位于 x 之前的顶点数 R 是 Beta(k+1,2)–Binomial(v,h) 分布的概率混合。作者证明每个内秩原子都严格小于 1/3；独立审计还给出统一上界 `30/91=1/3−1/273`。

若结构性端点方向 `Pr(F1<x)>2/3` 与 `Pr(x<Fv)>2/3` 同时成立，秩累积概率必经过平衡区间，并在内部 F_i 上得到平衡对。若某个端点方向失败，good-pair 定理给出偏序中某处的平衡对。不能声称无论权重如何，总能在 x 与 C6 之间找到平衡对；审计包含反驳这种更强说法的精确例子。

阅读 `residual-rank-obstruction/RANK_OBSTRUCTION.md` 及 `residual-rank-independent-audit/AUDIT.md`。独立实现核对 1,034 个实际权重向量的理想态 DP 与单纯形精确积分，检查 2,068 条实际顶点端点方向、433,524 个 beta 公式/界及 324 个条件混合实例。有限计算是实现核验，全部权重上的证明来自原文和审计中的解析论证。

## 3. v=4：三概率精确证书

v=4 的第三秩原子不能沿用上述通用小于 1/3 的结论。例如通用混合分布有 `p(4,3,5)=56/165>1/3`，这不是偏序反例。

令 `A=Pr(F3<x)`、`B=Pr(x<F4)`、`C=Pr(F4<z)`。正确的条件密度是三角区域上非负单项式 `h^k y^ell` 的混合。作者用精确多项式恒等式、五个小 k 的二次式正性，以及 k≥5 的非负系数平移展开，证明所有这样的混合满足

`12A+15B+C<56/3`。

第一、第二秩原子分别至多 4/15、9/35。无平衡对假设下，good-pair 强迫方向与这两个秩间隙进一步使 A、B、C 全部大于 2/3，与证书矛盾。因此 v=4 整个无界子族被排除，且没有宣称某个固定顶点对对所有权重都平衡。

阅读 `four-tail-rank-certificate/FOUR_TAIL_CERTIFICATE.md` 及 `four-tail-independent-audit/PROOF_REVIEW.md`。独立审计以稀疏多项式形式核对恒等式，另以反序标签理想态 DP 和无条件有理积分检查 640 个向量、4,480 个事件积分。作者实现作为第三套结果进行交叉比较；独立 DP 与积分的计算本身不依赖作者算法。

```sh
python3 reproduce.py --verify-only
python3 reproduce.py --receipt /tmp/S115-reproduction-receipt.json
```
