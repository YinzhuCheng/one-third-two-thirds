## 1. 为什么远端外点不能漏进中段

记 `u=|U|`、`k=|K|`、`a=u+D`、`b=u+2D+k+D`。同点秩位移至多 `D` 给出：

1. 每个 `U` 标签的最大可能输出秩不超过 `a`；每个 `K` 标签的最小可能输出秩至少 `a+1`。因此第 `a` 个输出后，已输出标签恰为 `U∪s`，`s⊆L`、`|s|=D`。
2. 每个 `U∪L∪K` 标签的最大可能输出秩不超过 `b`；每个 `V` 标签的最小可能输出秩至少 `b+1`。因此第 `b` 个输出后，已输出标签恰为 `U∪L∪K∪t`，`t⊆R`、`|t|=D`。

所以中段恰含 `(L\s)∪K∪t`。远端 `U` 可以与左端口交错，但这种交错全部处于前缀；远端 `V` 与右端口的交错全部处于后缀。它们不可能插在本接口计数的中段 port trace 内。不能把此结论推广到没有足够缓冲或没有指定切口的“只记端口排列”接口。

`I_s` 合法性仅由共同外部决定：核心位于所有 `L` 之后，不可能是 `U∪s` 的缺失前驱。`J_t` 合法性也仅由共同外部决定：核心已全部包含，参考序在它之后的未选右端口和 `V` 不可能是它的前驱。相同端口子集给出真正相同的输入/输出状态，而非任意同维矩阵的行列匹配。

所有跨边均已覆盖：`K` 与中段端口的关系在诱导中段中原样计数；与已输出左端口、未输出右端口的关系由理想端点和拼接方向保证；`U`、`V` 无额外的未知交错。因而此场景无需再增加独立时间戳或远端跨边字段。`(s,t)` 本身就是切口 mask；若采用带完整标签的 `τ`，它的支撑还能恢复 `s=L\supp(τ)`、`t=R∩supp(τ)`，但不能在换编码时默默丢掉这项信息。

## 2. 每条真实外部 LE 的纤维与归一化

固定一个外部完整次序 `η`。删除核心后，原来两切口之间总共只剩 `2D` 个外部标签。因此无论 `k` 多大：

- `η` 的前 `a` 个标签就是原前缀，确定 `s` 及完整前缀次序；
- 紧接的 `2D` 个标签就是 `τ`，确定 `t`；
- 其余标签就是完整后缀次序。

给定这三段外部次序，完整 LE 的自由选择恰是具有该 trace 的中段 LE。由于 `I_s⊂J_t` 均是理想，每个合法中段可与给定前后缀合法拼接，且不重计。因此

    # {ω∈LE(P): ω|E=η} = H_K(s,t,τ)。

若形状或合法性不符，纤维及相应坐标均为零。对 `P′` 同理，虽然其第二输出秩切口随 `|K′|` 改变，删除后的外部切口位置仍是同样的 `a` 和 `a+2D`。所以核心长度不同不会带来遗漏的二项式交错因子或阶乘因子；它们已经全部包含在真实整数 `H` 中。

若每个坐标 `H_K=cH_K′`，逐外部序列求和即得 `e(P)=c e(P′)`。随后逐纤维除以各自的总计数，得到相同外部概率。这里始终使用真实完整 LE 计数，没有把前缀、删除结果或中段视作均匀随机对象。

## 3. 完整联合标记为何足够

取保留集 `F=E∪M`。原来的中段删除非保留标签后，留下恰好 `2D+|M|` 个标签。于是固定 `F` 上完整次序仍唯一确定前缀、联合 trace 以及后缀，上一节的纤维论证逐字适用。

与 `P′=P[F]` 比较时，`P′` 的中段已经没有非标记核心标签。故其完整联合 trace 计数每坐标只能为 `0` 或 `1`。正比例恒等式因此迫使每个可实现保留完整次序在原 `P` 中有同一个正整数 `c` 个提升。这比仅保留各标记与 ports 的边际严格得多。

所有 `P′` 中的 pair 都是原 `P` 的同名实际 pair，诱导偏序没有改变这些标签之间的可比关系。故保留非链且严格变小时，确可传递反例性质。若创造新标签，则仍需要额外的原实际 pair 对应证明；外部接口不会自动提供它。

## 4. pair-only 新补充的逐类核验

令 `α_s`、`β_t` 是共同外部的前缀、后缀完整 LE 数；`A_st` 是整个中段 LE 数。分母为

    Z = Σ_(s,t) α_s A_st β_t。

固定一个保留 pair `(x,y)`，对每个 `(s,t)`，它们各自处于前、中、后哪一段已被 mask 唯一确定。其 `x<y` 分子的该状态贡献恰为：

- 同在前段：`α_s^{x<y} A_st β_t`；标记前缀数只依赖共同外部。
- 同在中段：`α_s B_st^{x<y} β_t`。
- 同在后段：`α_s A_st β_t^{x<y}`；标记后缀数只依赖共同外部。
- 处于不同段：按段次序为 `α_s A_st β_t` 或 `0`。

若储存方向与查询相反，使用 `A_st−B_st^{y<x}`。这包括远端点、port、保留标记及任意两类之间的 pair。所有 `A`、全部所需 `B` 与零坐标同乘同一个 `c`，便使所有事件分子及总分母同时乘 `c`。结论严格成立。

这里不需要知道中段更高阶联合次序；同时它也没有推出这种联合次序相同。特别地，本节不能据此断言每个保留 LE 的提升数都是 `c`，不能把 `c` 解释成整数纤维数。正文目前正确区分了这两个命题。
