# 原问题的最小反例图谱：必要表示、已覆盖范围与剩余核心

日期：2026-10-19。只读既有研究及公开原始文献；本稿只写本地。原猜想仍 OPEN，本轮没有构造反例，也不作首创或正式发表主张。旧入口中的“35/55”是历史台账，本稿没有重建其对象与当前覆盖，故不作现行统计。

全文固定实际有限偏序的**全部有标签完整线性扩张上的均匀律**：
\[
p_P(x,y)=\Pr_{L\sim\operatorname{UnifLE}(P)}[x<_L y],\qquad
\delta(P)=\max_{x\parallel_Py}\min\{p_P(x,y),1-p_P(x,y)\}.
\]
链约定 \(\delta=0\)。主猜想是每个非链 \(P\) 有 \(\delta(P)\ge1/3\)；反例须严格 \(\delta(P)<1/3\)。下面三大类是**可交叠的证据层和研究机制**，不是互斥的全体偏序分类。唯一声称完备的主分解是第1类的必要表示定理。

## 1. 精确结构层：真正完备的是“最小反例必为带正整数链权的素商”

**定理 M（已证必要表示，S112 基线）。** 如果主猜想存在反例，则对**每个按总点数最小的非链反例** \(P\)，其极大链自主模块构成唯一分划 \(M_1,\ldots,M_r\)，且
\[
P\cong Q[(C_{n_i})_{i=1}^r],\qquad n_i=|M_i|\ge1,
\]
其中 \(Q\) 为素偏序（没有大小介于2与 \(|Q|-1\) 的自主模块）。进一步：

- \(P,Q\) 的可比图与不可比图都连通，\(r\ge4\)。\(P\) 无全可比点、无最小元或最大元，至少有两个极小点及两个极大点。
- \(P\) 每个真非平凡自主模块都是链。**整体 \(P\) 本身的平凡模块不在排除范围内。**
- \(P\) 存在唯一概率全序 \(v_1\prec\cdots\prec v_N\)，对全部 \(i<j\) 有 \(p_P(v_i,v_j)>2/3\)；该全序扩张原偏序。因此 \(P\) 刚性，\(Q\) 没有非平凡的保权自同构。\(Q\) 本身未必刚性，概率全序中的链块也未必连续。
- 精确有
\[
\operatorname{width}(P)=\operatorname{width}(Q),\qquad
\pi(P)=\max_i\sum_{j\parallel_Qi}n_j,
\tag{1}
\]
其中 \(\pi\) 是最大不可比度。若另知 \(\pi(P)\le D\)，则每个 \(n_i\le D\)；这**没有**限制商点数 \(r\)。

**承重短证及依赖。**

1. 自主模块 \(M\) 的内部均匀律确实保留：固定外部标签顺序及 \(M\) 占据的槽集，可以任意替换内部 LE，合法性不变，且每个内部 LE 的纤维相同。所以 \(p_P|_{M\times M}=p_M\)。若真模块 \(M\) 非链，最小性在 \(M\) 自己的均匀律下给出的平衡对原样提升，矛盾。这一步只用更小**诱导非链偏序**均有平衡对；“只检验单点删除”不是足够前提。
2. 不可比图的各连通分量按比较方向全序排列，故原偏序是其**精确序和**；LE 是各因子 LE 的笛卡尔积，\(\delta(P_1\oplus\cdots\oplus P_s)=\max_h\delta(P_h)\)。所以非平凡序和分解被最小性排除。可比图不连通时是精确不交并；各分量及其并集仍有均匀内部限制。若一个分量非链，用最小性；否则全部是链，而两条非空链的均匀 shuffle 有平衡跨对。该最后一步的初等首元素概率 crossing 证明见 S112 §2.3，不能省掉。
3. 相交链模块的并仍是模块，且仍是链：公共点使外部关系一致；两块各有而对方没有的元素，由模块性和公共点迫使可比。故极大链模块唯一成分划。商的真非平凡模块提升为 \(P\) 的真模块；若非链违反第1点，若是链则违反极大链块性。故商素。这是对全部最小反例的必要表示，**不是**对任意偏序都宣称其链商素。
4. 若 \(p(x,y),p(y,z)>2/3\)，并集界给 \(p(x,z)>1/3\)。无闭带平衡对迫使 \(p(x,z)>2/3\)，故强多数方向传递并成为唯一全序。自同构必须保留该全序，因而恒等。式(1)由反链每块至多取一点和整块不可比直接得到。

**仍可叠加的已有全权重结构筛选。** Zaguia good-pair 定理给出强制方向：对不可比 \(a,b\)，若 \(D(a)\subseteq D(b)\) 且 \(U(b)\setminus U(a)\) 为链，则反例必须有 \(p(a,b)>2/3\)；另有对偶规则。在 \(Q\) 的底/顶端口上提升这些箭头，连同原序及块内底到顶箭头，若成环就排除相应权向量；保留两形式端口得到的环更可排除全部正权。特别地，商有 very-good pair 时全部正权被排除。**不允许无条件合并一个非单点块的底/顶端口。** 这些筛选只是必要非充分，与式(1)、模块筛选可同时使用。来源与端口充要压缩见 S112 §10 及其独审 §3。

**概率模型不能再压掉的一层。** 对上面的 \(P\)，均匀 LE 精确等同于满足外商比较的所有重标签词上的均匀分布：符号 \(i\) 出现 \(n_i\) 次，\(i<_Qj\) 时全部 \(i\) 在全部 \(j\) 前。它**不是** \(\operatorname{UnifLE}(Q)\)。收缩一个长为 \(m\) 的链模块，若外 LE \(\sigma\) 的可插窗口含 \(k(\sigma)\) 个点，其实际权为
\[
W_m(k)=\binom{m+k}{k},\qquad W_1(k)=k+1.
\tag{2}
\]
所以商的无权均匀律与原律通常不同。即使随机代表给均匀商，商的平衡跨对也可能是多个失衡实际对的平均：\(C_2\sqcup C_3\) 中，短链两点先于长链中点的概率是 \(7/10,3/10\)，收缩后为 \(1/2\)。外部 pair 也会改变：\((a<m_1<m_2)\sqcup\{b\}\) 中 \(p(a,b)=3/4\)，收缩后为 \(2/3\)。二例都有其他平衡对，仅否定其指定回传论证。

## 2. 已覆盖机制层：参数端点、链列和局部矩，不能冒充整个候选核心已被排除

**已有文献的真正全局排除。**

- 非链 width 2 已有 \(\delta\ge1/3\)；可用 Sah 的 [width-two 原论文记录及其加强](https://arxiv.org/abs/1811.01500v2) 定位。因此反例必须 width \(\ge3\)。
- [Peczarski 2008，6-thin 原出版页](https://link.springer.com/article/10.1007/s11083-008-9081-9)明确陈述：最大不可比度 \(\pi\le6\) 时 Gold Partition Conjecture 成立，且该猜想蕴涵本题。因此反例必须 \(\pi\ge7\)。本轮核对的是出版社摘要的准确结论，未重新审查其计算机证明。
- [Aires–Kahn，2510.26134v1，定理1.6](https://arxiv.org/html/2510.26134v1#S1.Thmthm6)：对每个固定 \(W\) 与 \(\varepsilon>0\)，存在 \(T(W,\varepsilon)\)，对**所有** width \(\le W\)、\(\pi\ge T\) 的偏序，\(\delta>1/2-\varepsilon\)。取 \(0<\varepsilon<1/6\)，剩余反例在固定宽度内满足 \(7\le\pi<T(W,\varepsilon)\)。这是一个整类排除，不限商固定；外商改变但宽度共同有界也在其中。未给出跨全部宽度的统一结论。

**固定商链膨胀：大活跃块和有限盒已经有定性覆盖。** 由(1)，每个活跃块 \(n_i\le\pi(P)\)，且 width 保持，故固定非链 \(Q\) 的最大活跃块趋无穷时 \(\delta\to1/2\)，低平衡活跃长度落入有限盒。这是上项文献的直接推论；`bounded-block-limits` 的自含几何证明和序和骨架二分可保留为机制证明，不能再当新适用范围。非活跃块是精确序和骨架，删除它们保留 \(\delta\)；最小反例因第1类本就没有这些块。

`active-threshold-certificates` 进一步给固定商的理论终止有限证书算法 \(M_A(Q,\varepsilon)\)：先在混合短块/长块模型算阈值，再展开短块并作有限深截断树。它不是一般删点保均匀；依赖短块保留全部真实坐标、混合维密度和良基递归。本轮材料**未实际执行量词消去、未计算具体 \(M_A\)、未列举有限盒**。其有效化新颖性也未认证。即使实际完成固定商有限盒，仍不能有限枚举全部素商 \(Q\)。

**链列已真正闭合的部分。** `general-chain-interlacing` 对任意实际外环境、任意不可比外点数 \(t\)，证明
\[
Q_{i,x}(m+1)>Q_{i,x}(m)>Q_{i+1,x}(m+1),\quad Q_{i,x}(m)=p_{P_m}(c_i,x).
\tag{3}
\]
依赖是合法新点的正向 gap 体积倾斜、Shepp 差坐标 FKG、切片回归及严格端点论证；不是一般删除后旧 LE 均匀。其推论只无条件保持**旧整列同侧**时的任意缩短。若 \(m\ge2t\)，跳幅 \(\le t/(m+t)\le1/3\) 保证无平衡整列同侧；\(t=2\) 有更强专用结果，全部长度可缩短。一般 \(t\) 仅“旧整列避带”不够：\(C_2\sqcup C_5\) 对长链中点的列是 \((5/7,2/7)\)，缩至 \(C_1\) 为 \(1/2\)。该偏序本身仍有其他平衡对。

**一般 ideal-run / slot T 已证，但对象是辅助统计。** `ideal-deletion-coupling` 证明实际删除 ideal 后残余坐标按递增纤维体积倾斜；精确合法 prefix word 条件化后，剩余 LE 才均匀。结合 FKG 和尾和，得到一般 ideal runs 的有限 \(n\) 协方差/二阶矩界，并闭合一般 slot T。它已帮助覆盖全部 \(t=2\) 链列；仍未保证完全外部 pairs 在同一短长度全部安全，未证明 \(\delta\) 缩链单调。

**这一层的覆盖缺口。** (3)控制含链点列，不控制同一次改长后全部纯外部 pair；逐 pair 各有一个安全长度，不等于共同安全长度存在。有限盒依赖固定商；固定宽度大 \(\pi\) 定理不控制固定宽度、 bounded \(\pi\)、无界商点数的全部候选。局部矩界没有给出全局 actual witness。这些边界可以交叠，不能把一个辅助 gap 的闭合计成另一个核心区域已排除。

## 3. 真正剩余核心与下一条值得证明的全局命题

**剩余对象是实际的带权素核心，而非一串未用完的变换。** 必须同时容纳：

- **链块全长1的素偏序。** 这里没有非平凡链可缩，链交错与长块渐近均没有可动参数。bounded \(\pi\) 也不意味着素商大小有界。
- **至少一个长链块的素商膨胀。** 需要在同一个实际均匀词模型内寻找某个实际平衡对；不能把商的平衡对固定提升，也不能仅控制一列。
- **参数改变时的两端。** 每个固定宽度 \(W\) 的候选已被文献压到 \(7\le\pi<T(W,\varepsilon)\)，但这一区域内的商数仍未有限化；没有共同宽度上界的素商也仍在目标内。不能把“变化外商都开放”说得过宽，也不能说“只剩宽度无界”。

这三条是剩余区域的重叠描述，并未宣称一个有限的互斥分类，更没有完成原历史分类台账。

**下一条承重全局归约目标 G（未证）。**

> 每个按总点数最小的非链反例都没有大小 \(\ge2\) 的真链自主模块；等价地，在定理 M 的唯一极大链块表示中全部 \(n_i=1\)。

其真实收益是把**所有最小反例候选**从“正整数链权的素商”压到“实际无权素偏序”。它不解决后者，也不应被宣布为主猜想已近完成。一条足够但更强的可攻击版本是
\[
\forall Q\ \forall\mathbf n\in\mathbb N_{>0}^{Q},\quad
\delta(Q)\ge1/3\Longrightarrow
\delta\bigl(Q[(C_{n_i})]\bigr)\ge1/3.
\tag{G+}
\]
若 G+ 成立，则假想最小反例的较小非链商已有平衡对，整个膨胀亦应有平衡对，故 G 成立。**G+不要求指定商 pair 回传，不要求一条固定短路径，不要求 \(\delta\) 单调。** 第1类的两个指定-pair反控和第2类交叉列反控均未否定 G 或 G+。它们也不由现有交错/矩界推出，必须把全体实际 pairs 与共同扩张 law 一起处理。

**与刚性 bounded-\(\pi\) 素核心前沿的选择。** G 能跨越链权瓶颈，却对 \(\mathbf n\equiv1\) 无帮助；bounded-\(\pi\) 的原律全局平衡/可认证前沿能触及这个盲点，但必须保留全局完成数，不能以bounded带宽或有限状态个数直接假设概率权只有有限种。两条路线应按能否给出上述真正归约或整类定理选择，不预设 WIDTH3 是唯一主攻。WIDTH3 可作可测子目标；小样本、追加变换公式及证书数量都不是选择依据。
