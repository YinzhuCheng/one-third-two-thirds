## 1. 最小反例表示与文献覆盖

### 1.1 量词与最小性

定理 M 的量词正确：若存在反例，则**每一个按总点数最小的非链反例**都有其唯一极大链自主模块分划，得到带正整数链权的素商。不能将该表示宣称为任意偏序的素链商，也不能将“每个单点删除已有平衡对”冒充所有更小诱导非链偏序的最小性前提。

本轮短证准确保留以下方向：自主模块内部原均匀律提升；非链真模块由最小性排除；相交链模块的并仍是链模块；商的真非平凡模块提升后分别违反最小性或极大性。由此得到的是 **weighted prime Q**，不是 unweighted Q 自己也是反例。

强多数全序的论证成立；它约束实际标签，不自动把链块排成连续商块。P 刚性只推出 Q 无非平凡保权自同构，并不推出无权 Q 刚性。

### 1.2 参数与 G+ ⇒ G

width 保持及 π(P)=max_i Σ_{j∥i} n_j 的公式准确。π≤D 和不可比图连通给每块 n_i≤D，但没有给商点数上界。

G+ 全称量词涵盖所有 Q 和正整数链权，且只要求某个实际平衡对存在，不指定商 pair 的固定提升。若最小反例有长块，则其非链素商 Q 严格更小，最小性给 δ(Q)≥1/3；G+ 将导出膨胀也 balanced，矛盾。所以 G+ ⇒ G 正确。旧指定 pair 的实际反控没有否定 G 或 G+。

独立核对 [Aires–Kahn v1，Theorem 1.6](https://arxiv.org/html/2510.26134v1#S1.Thmthm6)：其固定宽度下 π→∞ 的结论对整个 width≤W 类一致，而不限固定商。因此剩余固定宽度候选确须落在 bounded π 区域；不能称“只剩宽度无界”。6-thin 排除使用出版页明确陈述的 π≤6 定理，本轮没有重审其计算机证明。

另独立核对 [lexicographic-sum 论文 v2 的末节](https://arxiv.org/html/2410.12494v2#S3)：其中保留 indecomposable 外层的非平凡链膨胀情形。不能只处理无权 prime Q 就视为覆盖全部最小反例。

## 2. GCC1–GCC4：完整 pair 覆盖已正确写出，充分条件仍须支付

### GCC1 / GCC1-R

给定外部实际 LE 后，链在窗口中的均匀 shuffle 是准确条件律。D⊆Pred(x) 时 x 不可能在窗口左侧；在窗口内，x<c_1 蕴含首符号为外点，概率≤K/(m+K)。这给 Pr(c_1<x)≥m/(m+t)，对偶端点界同样成立。逐 σ 的界在其真实重加权混合下仍成立，无需假定外部投影均匀。

由 m≥2t 和整列同侧，可推出每个活跃多数侧确实非链，因而 P_0 也非链。最小性于是对**全部** 0≤k<m 给 balanced；k≥1 时链相关 pair 已安全，所有短见证完全外部。这是全部短长度覆盖要求，不是指定一次删除的单 pair 结论。

### GCC2

反序事件包含于两端点失败事件之并，含交集扣项的 (3.2) 正确。一端属于 D/U 时失效事件为空，自动排除 D–U、D–I+、I−–U 的新生平衡；唯一剩余跨侧类型是 I−–I+。

等号边界处理有效：对不可比 a∈I−、b∈I+，添加 b<C_k<a 不成环。这里实质使用了不存在 a<b，以及禁止 I<D、U<I。故两失效事件交集有实际正质量，ε_L+ε_R≤1/3 仍给反序概率严格小于 1/3。不能删去这个正重叠论证后把闭边界当成安全。

### GCC3

真实窗口层内条件律不随链长变化，故共同 TV 等于层质量 TV；单调似然比给一次变号及累计质量差公式。所有同侧 pair 共用同一个 TV，不需乘 pair 数。

完整 pair 清单无遗漏：链内、链–D/U 可比；链–I 保侧；L–R 由 GCC2；两侧内部由 V(k,m)<η_same(m)。严格小于不可改成小于等于。层中性是另一明确充分条件，但未证明一般自动成立。η>0 本身不等于存在能够支付它的整数缩短步。

**另核的单落点推论。** 令 S_bar={1≤k<m: ε_L(k)+ε_R(k)≤1/3}。它是初始整数段；对每个 r，窗口层累计质量 F_r(k) 随 k 增大不增，故 V(k,m)=max_r[F_r(k)−F_r(m)] 也不增。若 S_bar 非空，取 k*=max S_bar，则存在某个 k 同时支付 GCC3 双预算，当且仅当 V(k*,m)<η_same(m)。这只把条件检查压到一个边界落点，不证明 barrier 非空或预算必命中；该推论由作者另提，本审查已核，不要求生产稿为此再变版。

### GCC4

规范加边确给 P[L]⊕C_s⊕P[R]；相容强多数 LE 保证无环，侧诱导关系没有暗中改变。切口事件的真实条件律是该序和的均匀 LE，质量为 e(P[L])e(P[R])/e(P_s)，正确。

安全核 1/(3f)≤α≤1−1/(3f)、f≥2/3 是对未知补事件概率 β∈[0,1] 的准确充分条件。t=1 时 f>2/3，但一般侧 balanced 只给 α∈[1/3,2/3]，没有自动给中央性。

新增 full-gate 无界类也成立：m≥4，s=10m+1 为奇数；侧 C_s⊔{a} 有 α=1/2，且 3(s+1)^2−2[(s+m+1)^2+m+1]=58m²+30m+2>0。故安全核有真实非空无限子类。它不覆盖一般侧 witness 选择。

旧九点例中的自主对是 {a,b}，不应称整个 diamond 自主。该例父有其他 balanced；其局部菜单失败不能否定上述全局存在性命题。

## 3. RBC1–RBC4：有限结构入口不等于有限概率或规模

不可比端点之间的每个中间标签至少与一端不可比，给任意 LE 的边长≤2D−1。任意两 LE 的同点秩差只是至多 D 个不可比邻点的前后指标差之和，给更强的秩位移≤D。

于是每个秩层的理想被一个 2D 窗口确定，层宽≤binom(2D,D)。按最早遗漏标签分类的总理想数≤1+n2^D 也正确。精确 DP 的整数权、前后完成数和 pair 插入 numerator 均保留原均匀律。

inc 图连通时，真模块 M 有一个外点 z 与全 M 不可比，因此 |M|≤D；所有 M 标签距 z≤2D−1，故其参考跨度≤4D−2。局部模块检查成立，但 M=P 及极小 n 必须作为边界情形；该界没有限制素核心总长。

路径族 A_n 的边界说明准确：它是无界 n 的 prime、rigid、两图连通、D=2 族；LE 对应不重叠相邻交换，e(A_n)=F_{n+1}，Pr(2≺1)=F_{n−1}/F_{n+1} 为无限多个不同值。该族有 very-good pair，已在已知正例内；它只否定“这些较弱结构条件/有限转移类型自动给有限概率状态或统一有界精确代表”的推断，不能当完整必要筛选后幸存反例。

## 4. RBC5–RBC6：完整 trace 接口确实没有漏掉远端 gap 权

这是本轮重点核查的高承重接口。

参考分割为 U|L|K|R|V，左右端口各 2D。a=|U|+D 时的真实理想必为 U∪s，|s|=D；b=|U|+3D+|K| 时必为 U∪L∪K∪t，|t|=D。

因此固定任意外部完整标签次序 η 后：

1. η 的前 a 个标签唯一给出 U∪s 及其真实前缀次序。
2. 随后恰有 2D 个外部标签，且只能是 (L\s)∪t；它们的次序就是 τ。
3. 其余标签是 (R\t)∪V 的后缀。

**所有 U 标签已在第一切口前，所有 V 标签只能在第二切口后。** 远端点不能再插入中段 ports 之间，故不存在被相对 trace 漏掉的额外外部 gap multiplicity。K 与 ports 的全部交织已由 H_K(s,t,τ) 计入。

合法理想切口使前缀、中段、后缀能任意拼合为完整 LE；前后部分由共同 P[E] 决定。参考次序也保证切口合法性的额外缺失前驱不可能来自中段 K。由此 η 的删除纤维正是 H，而非仅与 H 有关的粗统计。所有坐标同一正比例确给每条 η 同比例纤维，因而保留 E 的完整诱导 LE law，并给 e(P)=c e(P′)。

扩大 trace 保留实际标签 M 后，同一分割证明适用于 E∪M。与诱导偏序 P′=P[E∪M] 比较时，比例恒等式确使删除推前为 UnifLE(P′)，所以 P′ 的全部 pair 均是原 P 中同一实际 pair。较小且非链时才能与最小性矛盾。

**关键未证项仍在：** 没有证明任意长核心具有这种较短真实实现。RBC5 只保外部 law，不保新标签的内部/跨界 pair；RBC6 正是为补足这一步而要求保留实际标记。有限维 H 也不等于 H 只有有限多个射影值。

### 4.1 新增 RBC5P / RBC6P：仅保全部 pair 的二次接口

新增降维正确。对每个相同标识 (s,t)，只存中段总计数 A 及中段端口集合 T=(L\s)∪t 上全部无序 pair 的一种共同方向计数 B。给定状态后：两目标在中段的贡献为 αBβ；同在前缀或后缀的贡献为共同标记前/后缀计数乘 A；在不同段则先后固定，贡献为 0 或 αAβ。所有状态的同一个比例 c 因而使总分母及全部外部 pair 分子同比。维数上界 S²[1+binom(2D,2)] 成立。

加入保留标记 M 后，它们在两对象中全在中段；加入 T∪M 的全部所需 pair 坐标，维数变成 S²[1+binom(2D+|M|,2)]。与 P′=P[E∪M] 比较可保全部同名实际 pair 概率，已足以作最小反例递降。此处不需要、也没有从 pair-only 数据推出完整诱导 LE law。跨状态必须是一个共同 c；非法状态、方向标识、M 内部及 M—port pair 不能遗漏。任意长核心有较短真实实现仍未证明。

## 5. RBC7：有限证书的正确性成立，证书存在性没有证明

前后消息锥包含端向量并对所有合法转移不变，足以用归纳包住任意长真实消息。对每对生成射线检查双线性不等式，再作非负组合，能传给实际 α、β；实际分母 e(P)>0。

若参考编码是反例唯一强多数 LE，则每个正向不可比 pair 要求 α(3B−2A)β>0。因此只证明 α(2A−3B)β≥0 已足以排除这个反例编码，不必再证明平衡下界；若同时有 α(3B−A)β≥0，则得到直接 balanced pair。有限模式自动机的全词覆盖条件若有精确证书，就真正覆盖所有长度。

但没有给出一般 D≥7 的适用锥、全词覆盖或程序终止性。找不到这种有限多面体锥也不反驳主猜想。结构状态重复不意味着概率消息重复；无统一 margin 时，近似射影截断同样不能冒充精确压缩。Fibonacci 两射线证书只作为已知正例的真实无限长演示。

已由作者落实的三个微澄清不影响数学结论：单状态序和重置限于 0<t<n；线性算术复杂度针对全部不可比 pair，可比 pair 为 0/1；加入 M 后的 trace 维数依赖 D+|M|，不能仍称只依赖 D。

## 6. 实验与 full-gate 解析诊断

644 个冻结相邻控制中，13 个满足整列同侧，16 个跨侧不可比 pair 实例，但**短对象跨侧 balanced 输入为 0**；XP 核心蕴涵全部真空。m≥2t 的结构前件亦 0 命中。这些数字不能称为非空 XP 支持。最终实验稿已明确这一点。

full-gate 架构的公式成立：

- T_m=(d+m+1)(u+m+1)+(m+1)。
- 反序槽计数为 (m+1)(m+2)/2。
- q_(m−1)−q_m=(m+1)[2du+m(d+u)]/(2T_m T_(m−1))≥0。

同侧列给父 q_m>1/3，再结合短 q≤2/3 及该单调性，确证此明确子类的 XP。对称 d=u=s、m≥2 时 S⇔s≥2m 的整数根判定也正确。它不证明一般 partial-gate 或多标记 XP。

独立复核只使用既有 F1-s6、m=2→1 一个固定模型，直接遍历全部 LE：84→66；同侧 d3<a 为 57/84=19/28→42/66=7/11，父完整 balanced 对为 6 条。证据为本目录 `independent-fixed-witness.json`。这核实同侧宽模板现象，不追加模型，也不改变 XP 核心前件 0 命中的结论。
