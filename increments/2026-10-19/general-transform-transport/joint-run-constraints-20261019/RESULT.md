# 嵌套 ideal runs 的真实 marker 通道与联合矩约束

日期：2026-10-19。只本地研究。本文的一般结论是本轮从已有单变量 run 定理与 single-center 界推导的结果，不声称文献首创。没有使用多变量 LC、MTP2 或把任意混合当作真实均匀 LE。

## 0. 结果与尚未跨越的边界

设 P 为任意有限偏序，K⊆L 为两个 ideals。对同一条均匀随机线性扩张，令

X=R_K，Y=R_L，h=|K|，g=|L|，r=EX，s=EY。

逐扩张 X≤Y。所有期望若无下标均针对原 P 的均匀 LE。

本轮证明三组联合必要条件：

1. **任意数量 marker 的真实 run 通道。** 对每个整数 m≥0，序列
   t_i^(m)=E[1_{X≥i} binom(Y−i+m,m)]，0≤i≤h，
   归一化后恰为某个明确增广偏序的均匀 LE 中 initial-K run 的尾。因此 t^(m) 及其整条二项阶乘矩变换均 LC。m=0 回收旧 X 边际；m≥1 则真正使用联合 law。
2. **双 marker 的两个投影和高阶混合矩。**
   a_i=E[(Y−i+1)1_{X≥i}]，
   b_j=E[(min(X,j)+1)1_{Y≥j}]
   都为 LC。由此得到两条显式混合二项矩序列 A、B 的全阶 LC。
3. **双 marker 的协方差矩证书。** 对四个明确非负计数多项式 w,u,d,v，总有
   (Ew)(Ev)≤(Eu)(Ed)。
   它来自增广模型中的 Cov(I,J−I)≤0，而不声称原 Cov(X,Y−X)≤0。

这些约束**严格补充**已保存的单变量尾/全阶矩 LC 和 slot T：一个明确非 actual 的有序联合 law 满足全部这些旧边际条件和 T，却违反新 a-LC。本文没有证明一般 slot T，也没有给出 T 的 actual 反例。实际三点嵌套例否定了 survival TP2/MTP2；所以不能把下面正确的投影 LC 擅自升级成整个联合 array 的 MTP2。

## 1. 定理 MC：任意 m-marker 链的真实尾通道

对 m≥1，在 P 外加入一条 m 点链 V_m；令每个新点都小于 P\L 的每个点，与 L 不可比，除这些关系外仅取传递闭包。记增广偏序为 P_m；m=0 时 P_0=P。

因为 L 为 ideal，P\L 是 upset。这些关系无环，也不会使某个新点低于 L 内元素。特别地，原 K 在 P_m 中仍是 ideal。

置

Z_m=E binom(Y+m,m)>0，

t_i^(m)=Σ_{x≥i,y} P(X=x,Y=y) binom(y−i+m,m)，0≤i≤h。

这里显式只在 x≥i（因而 y≥i）上求和，避免负上标二项式歧义。令 X_m 是 P_m 的均匀 LE 中 initial-K run，则

**(MC1)**  e(P_m)=e(P) Z_m，

**(MC2)**  P(X_m≥i)=t_i^(m)/Z_m。

### 证明：精确计算每一个原扩张纤维

固定 P 的一条 LE，其 initial-K、initial-L run 分别为 x≤y。V_m 的链点必须全插在首次 P\L 元素之前。沿原扩张的 y+1 个槽，给 m 个有固定顺序的链点选择弱递增槽，恰有 binom(y+m,m) 种。

要使新扩张的前 i 个元素全来自 K，首先须有 x≥i；此时 V_m 的所有点还必须避开前 i 个原点之前的槽。可用槽是 i,i+1,…,y，共 y−i+1 个，恰给 binom(y−i+m,m) 种。不存在其他约束，也不存在多重计数。对所有原 LE 相加并归一化，得到 MC1–MC2。

若改加 m 个互不可比且同样低于 P\L 的标记点，每一纤维和每个尾事件的计数都额外乘 m!，所以 MC2 不变。这不是假定独立插入。

L=P 时 y=n，仍是通常的 n+1 槽链插入；K=∅ 时 X_m=0；空 P 亦由同一计数成立。m=0 的公式直接给原尾。

### 联合尾与全阶矩约束

由 P_m 是真实偏序、K 是其 ideal，继承的单变量定理立即给出

**(MC3)**  (t_i^(m))²≥t_{i−1}^(m)t_{i+1}^(m)。

定义 T_0^(m)=Z_m，并对 a≥1 定义

T_a^(m)=Σ_{i=a}^h binom(i−1,a−1)t_i^(m)
        =E[Σ_{i=a}^X binom(i−1,a−1)binom(Y−i+m,m)]。

则 T_a^(m)/Z_m=E binom(X_m,a)，因而

**(MC4)**  (T_a^(m))²≥T_{a−1}^(m)T_{a+1}^(m)。

支持外的项置0。h>0 时，1≤a≤h 的 MC4 实际严格，直接继承有限真实 run 的严格矩 LC。对所有 m 的量词是一般定理，并非把有限个 m 的数值核验当作证明。

m=1 时 Z_1=s+1，t_i^(1)=a_i，故 a_i/(s+1) 本身具有明确的真实 run 实现。

## 2. 定理 DM：双 marker 的联合尾投影

令 q_{i,j}=P(X≥i,Y≥j)。加新点 u<v，并令

u<a 对每个 a∈P\K，v<b 对每个 b∈P\L，

得到偏序 Q。K⊆L 保证 P\L⊆P\K，关系无环。

对 0≤i≤j，固定 Q 中的秩

rank(u)=i+1，rank(v)=j+2。

从 Q-LE 删除 u,v，得到原 P-LE。反向对每条原扩张，把 u 插在 i 个原点之后、v 插在 j 个原点之后（i=j 时 u 先于 v），恰一个候选。它合法当且仅当 X≥i、Y≥j。因此

**(DM1)**  # {Q-LE: rank(u)=i+1,rank(v)=j+2}=e(P) q_{i,j}。

这个固定秩计数没有额外权重。分别对另一坐标求和，得到

a_i=Σ_{j=i}^g q_{i,j}=E[(Y−i+1)1_{X≥i}]，0≤i≤h；

b_j=Σ_{i=0}^j q_{i,j}=E[(min(X,j)+1)1_{Y≥j}]，0≤j≤g。

它们恰分别为 u、v 的秩计数除以 e(P)。所以 Stanley **单点**秩 LC 已足够得到

**(DM2)**  a_i²≥a_{i−1}a_{i+1}，b_j²≥b_{j−1}b_{j+1}。

a_0=s+1；b_0=1。b 通常会增长，本文不把它称作 run 尾。

### 必须保留的重加权警告

均匀 Q-LE 删除 u,v 后，一条原扩张的权重正比于

w(X,Y)=(X+1)(Y+1)−binom(X+1,2)。

因此，删除后的原扩张**不均匀**。DM1 仅对固定两秩的计数成立；它不赋予原 q 数组未经证明的二维 LC/MTP2。

## 3. 两条显式混合二项矩序列

定义

A_0=s+1，
A_a=E[(Y+1)binom(X,a)−a binom(X+1,a+1)]，a≥1；

B_0=1，
B_a=E[(X+1)binom(Y,a)−binom(X,a+1)]，a≥1。

则

**(JM1)**  A_a²≥A_{a−1}A_{a+1}，B_a²≥B_{a−1}B_{a+1}。

对 A，这正是 MC4 的 m=1。精确展开用

Σ_{i=a}^X binom(i−1,a−1)=binom(X,a)，
Σ_{i=a}^X i binom(i−1,a−1)=a binom(X+1,a+1)。

对 B，先注意

Σ_{j=a}^Y binom(j−1,a−1)(min(X,j)+1)
=(X+1)binom(Y,a)−binom(X,a+1)。

减项来自 Σ_{j=a}^{X−1}(X−j)binom(j−1,a−1)=binom(X,a+1)。

最后应用一个仅需 LC 的代数版本：若 c_0=1，c 有有限无缺口正支持且 LC，不要求 c 递减，令 C_0=1、C_a=Σ_{j≥a}binom(j−1,a−1)c_j，则 C 亦 LC。a≥2 由已有平移引理；a=1 则 LC 的相邻比值递减给 c_{i+j}≤c_i c_j，故 C_2=Σ_{i,j≥1}c_{i+j}≤C_1²。将 c=b 代入即得 B-LC。

例如第一条实质三次混合矩不等式是

**(JM2)**
(E[XY−binom(X,2)])²
≥(s+1)E[(Y−1)binom(X,2)−2binom(X,3)]。

B 的对应式为

**(JM3)**
(E[(X+1)Y−binom(X,2)])²
≥E[(X+1)binom(Y,2)−binom(X,3)]。

这些是含实际联合矩的必要条件，不是从两个边际分别应用 FM-LC 的重述。

## 4. 定理 JC：倾斜双 marker law 的协方差证书

对非负整数 x≤y，定义四个计数多项式：

w(x,y)=Σ_{i=0}^x(y−i+1)
      =(x+1)(y+1)−binom(x+1,2)；

u(x,y)=Σ_{i=0}^x i(y−i+1)
      =y binom(x+1,2)−2binom(x+1,3)；

d(x,y)=Σ_{i=0}^x binom(y−i+1,2)
      =binom(y+2,3)−binom(y−x+1,3)；

v(x,y)=Σ_{i=0}^x i binom(y−i+1,2)
      =binom(y,2)binom(x+1,2)−2(y−1)binom(x+1,3)+3binom(x+1,4)。

每个量的非负性由其求和形式可见。则

**(JC)**  (Ew(X,Y))(Ev(X,Y))≤(Eu(X,Y))(Ed(X,Y))。

### 证明

在第2节 Q 的均匀 LE 中置 I=rank(u)−1、J=rank(v)−2。由 DM1，

P_Q(I=i,J=j)=q_{i,j}/Ew，0≤i≤j。

故 E_Q I=Eu/Ew、E_Q(J−I)=Ed/Ew、E_Q[I(J−I)]=Ev/Ew。

继承 single-center 精确式，对 Q 中两个点的秩 A=rank(u)、B=rank(v) 应用

E_Q[AB+min(A,B)]−E_QA E_QB≤Var_QA+E_QA。

由于 u<v，min(A,B)=A，式子恰化成 Cov_Q(A,B)≤Var_QA。因此

Cov_Q(I,J−I)≤0。

代入三个均值，即得 JC。这里没有使用 Chan–Pak 二次粗化，也不依赖 general slot T。

JC 控制的是明确倾斜并经过双槽插入的 law。原 X,Y 上 Cov(X,Y−X)≤0 实际错误，不能从 JC 去掉 w 等计数权重。

## 5. 严格补充旧单变量界与 T：一个非 actual 强度对照

下列只是抽象联合概率表，不是偏序反例：

(X,Y)=(0,2),(0,3),(1,1),(2,2),(2,3)，
概率依次为 3/8,1/8,1/4,1/8,1/8。

它满足 X≤Y，h=2<g=3，且所有 0≤i≤h、i≤j≤g 的三角联合尾 q_{i,j} 都为正。边际为

q^X=(1,1/2,1/4)，q^Y=(1,1,3/4,1/4)，

M^X=(1,3/4,1/4)，M^Y=(1,2,5/4,1/4)。

两条尾和两条全阶二项矩序列全部 LC。又有

r=3/4，s=2，E[XY+X]=9/4，

rs+r²+2r−E[XY+X]=21/16>0。

因为 r≤s，这就是 general slot T 所取较小侧的余量；所以 T 也通过。

但新联合投影为

a=(3,7/8,3/8)，
a_1²−a_0a_2=−23/64<0。

故此有序联合 law 不能由任何嵌套 ideals 的真实均匀 LE 实现。这个例子只证明 **新联合必要条件不是旧边际 LC/FM-LC 加 T 的推论**；不主张两个给定边际各自有独立的偏序实现，也不以它作为 actual 反例。

## 6. 最小实际反例：不能把联合尾升级为 TP2/MTP2

令 P={a<b}⊔{c}，K={a}，L={a,c}。三个均匀 LE 是 abc、acb、cab，分别给

(X,Y)=(1,1),(1,2),(0,2)，每个概率1/3。

因此

q_{0,1}=1，q_{0,2}=2/3，q_{1,1}=2/3，q_{1,2}=1/3，

q_{0,1}q_{1,2}−q_{0,2}q_{1,1}=−1/9<0。

上述2×2矩形完全位于 i≤j 的三角域内。因此即使 K⊆L，实际联合 survival array 也非 TP2/MTP2；对应联合质量2×2 minor 同样为−1/9。单变量 LC 或上述正确 marker 投影 LC 都不允许填上这一步。

这是点数最小的反例：至多两点时，嵌套 ideals 要么一侧为空或全 P，给常数坐标；要么 K=L，给对角 law。这些情况的二维2×2 minors 均非负。

同一个三点偏序另取 K={a}、L={a,b} 时，joint 为(1,2),(1,1),(0,0)各1/3，Cov(X,Y)=1/3>2/9=Var X。此处只保留为旧强协方差路线的边界警告，不把已有类型的三点例当作本轮新一般成果。

## 8. 当前最窄后续问题

新增 marker 通道把真正的联合可实现性限制显式化，但未给出原均值层面的 Cov(X,Y)≤r(r+1)。下一步应直接研究这些全 m、全阶的合法 marker 约束能否压住赢家混合报告的精确缺口 Δ≤g_X+epsilon_bar，或者构造满足这些约束仍违反该均值目标的抽象 law，以划清其逻辑强度。

不能用 JC 的倾斜协方差替代原协方差，也不能用有限结构的联合切片LC检查宣称一般切片LC。本文交付到上述已证一般约束及一个最小actual MTP2反例为止。
