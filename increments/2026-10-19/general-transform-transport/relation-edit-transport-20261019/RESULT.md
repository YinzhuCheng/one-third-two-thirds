# 添加一个不可比关系：全 pair 传递、刚性分类与关联结构

日期：2026-10-19。研究范围仅为有限偏序上添加一个不可比关系 `x<y` 并取传递闭包；所有概率始终取真实均匀线性扩张。本文不解 1/3–2/3 猜想，不声称下面使用的 FKG/XYZ 工具或两链关联性质具有文献原创性。

## 0. 本轮确立的东西

1. **R1，完整保持的刚性分类（一般 P）。** 添加 `x<y` 后，除编辑对 `{x,y}` 外的全部 pair 概率原样保持，当且仅当 `P=D⊕A₂(x,y)⊕U`。也就是只能在一个二点反链序和块内部选择方向。只保持一对或只检查不含端点的 pair 不满足这个结论的前提。
2. **R2，两链类的同时单调传递。** 固定不相交链划分 `P=A∪B`。添加一个 `A→B` 关系后，所有 `A→B` 比较概率同时不减，所有反向概率同时不增，链内概率不变；更强地，整个 interleaving 格的分布具有随机序单调性。同向迭代保持这套前提。
3. **R3，一般 P 的端点影响。** 经典 Shepp–FKG 机制给出 `Δ(x,z)≥0≥Δ(y,z)`。两个端点相对 z 的总绝对漂移，恰由 z 落在 x,y 之间的两种概率决定，见 (B)。
4. **R4，同时扰动预算。** 全部比较指示变量的协方差矩阵满足一个精确秩一分解 (M)。它约束所有线性比较统计量的共同变化，不只是一个 Bayes 公式。
5. **精确失败边界。** 一个与编辑端点完全不交的已平衡 pair，可以从 `1/3` 变成 `1/4`，而编辑后偏序仍非链；外部 pair 的协方差可正、可负、可零。四点是“编辑端点与目标端点完全不交”所需的最小点数。

R1、R2 的首个承重证明已发送独立审稿；实验仅为预先冻结的九个 proof controls，至多 6 点，见 PLAN.md。一般证明不依赖这些有限控制。

## 1. 变换、闭包和完整 pair 记账

设 P 是有限偏序，`x∥_P y`。记

- `P⁺=tc(P∪{x<y})`，`P⁻=tc(P∪{y<x})`；
- `L` 为均匀 `LE(P)`，`E={x≺_L y}`，`p=Pr(E)`；
- 对任意不同 `u,v`，`F_uv={u≺_L v}`，`q_uv=Pr(F_uv)`；
- `q⁺_uv` 为均匀 `LE(P⁺)` 下的概率，`Δ_uv=q⁺_uv−q_uv`。

由于 x,y 不可比，两个方向都可延拓，所以 `0<p<1`，两个后继均定义。任何 LE(P) 恰位于 E、Eᶜ 之一，因此

`LE(P⁺)={L∈LE(P):E}`，`LE(P⁻)={L∈LE(P):Eᶜ}`。

这不仅是集合关系：条件化后的每条扩张仍同权，故确实得到两个后继的真实均匀律。

令 `D_x={u:u≤_P x}`、`U_y={v:y≤_P v}`，新关系恰为

`<_P⁺ = <_P ∪ (D_x×U_y)`。

理由是每条新增有向路径只需经过新边一次；反复经过会产生环，与 x∥y 矛盾。原可比 pair 始终为 0/1；新增可比 pair 必须记录其变为 1 的概率，不能从账本中删掉。除此闭包矩形之外的 pair 也可能漂移，包括与 x,y 完全不交的 pair。

### 1.1 所有 pair 的精确变化和判定

对一个固定 F=F_uv，令四格 LE 计数为

`a=#(E∩F), b=#(E∩Fᶜ), c=#(Eᶜ∩F), d=#(Eᶜ∩Fᶜ)`，`N=a+b+c+d`。

则

`q⁺=a/(a+b)`，`q=(a+c)/N`，

`Δ=(ad−bc)/((a+b)N)=Cov(1_E,1_F)/p`。                     (D)

所以保留、增加、减少的充要条件分别是 `ad=bc`、`ad≥bc`、`ad≤bc`。这是任意 pair 的精确判定，不声称从两个边际 q,p 就能决定符号。下文成果是把这个判定提升成可识别的结构类、全局刚性和矩阵控制。

单个 F 的普适尖锐范围为

`−min(q,(1−p)(1−q)/p) ≤ Δ ≤ min(1−q,(1−p)q/p)`。

这是 Fréchet 交事件界；其尖锐性是仅给定两个事件边际时的概率论尖锐性，不额外声称每个端点都能由具有指定 p,q 的偏序比较事件实现。若想从该编辑传回或保留一个指定的平衡证书，必须逐 pair 检查 `1/3≤q+Δ≤2/3`；对一种方向的单调性不能代替这两个门槛。

## 2. R1：除编辑对外全概率保持的完整分类

### 定理 R1

以下条件等价：

(i) 对所有无序 pair `{u,v}≠{x,y}`，选任一方向后均有 `q⁺_uv=q_uv`。

(ii) 只检查 incident pair 就已经全部保持：对每个 `z≠x,y`，`Δ_xz=Δ_yz=0`。

(iii) 每个 `z≠x,y` 要么同时小于 x,y，要么同时大于 x,y。

(iv) 存在允许为空的偏序 D,U，使

`P = D ⊕ A₂(x,y) ⊕ U`。

这里的“全部 pair”包括与编辑端点相交的 pair、编辑后新变可比的 pair，以及所有外部 pair。若只要求“编辑后仍不可比的 pair”保持，则本定理不适用。

### 2.1 核心精确恒等式

固定 `z≠x,y`，写

`r_z=Pr(x≺z≺y)`，`s_z=Pr(y≺z≺x)`。

逐条线性扩张上有

`1_{x≺z}−1_{y≺z}=1_{x≺z≺y}−1_{y≺z≺x}`，

`1_E(1_{x≺z}−1_{y≺z})=1_{x≺z≺y}`。

条件化并相减，得到

`Δ_xz−Δ_yz = ((1−p)/p) r_z + s_z ≥0`。                  (B)

两项系数严格为正。这把“编辑端点对第三点的共同影响”与线性扩张中真正发生的 between 位置联系起来；没有假设任何协方差符号。

### 2.2 (ii)⇒(iii)：不存在 between 扩张的结构含义

若 incident pair 全保持，(B) 使每个 z 的 `r_z=s_z=0`。有限均匀律下这表示两种 between 次序均无合法扩张。

一个诱导子偏序的任意线性扩张，都可延拓成整个 P 的线性扩张：把该子集的线序加进 P；若出现环，把环上的原 P 路径压缩到子集端点，会得到子集线序与其诱导序矛盾。因此新增关系无环，可作拓扑排序。

因为已知 x∥y，诱导三点中

- `x≺z≺y` 可实现，当且仅当既没有 `z<_P x`，也没有 `y<_P z`；
- `y≺z≺x` 可实现，当且仅当既没有 `z<_P y`，也没有 `x<_P z`。

两者均不可实现，等价于

`(z<x 或 y<z) 且 (z<y 或 x<z)`。

排除 `z<x<z`、`y<z<y` 两种环后，只剩 `z<x,y` 或 `x,y<z`。这就是 (iii)。

### 2.3 其余方向

(i)⇒(ii) 直接。

(iii)⇒(iv)：令 D 为共同前驱，U 为共同后继。它们分割其余元素；任何 `d∈D,u∈U` 都有 `d<x<u`，故 D<U，没有遗漏跨块关系。

(iv)⇒(i)：线性扩张唯一分解为

`L_D · (xy 或 yx) · L_U`。

均匀 LE(P) 恰是均匀 LE(D)、公平的二点方向、均匀 LE(U) 的独立乘积。条件 E 只固定中间块的方向；所有其他 pair 原样保持。证毕。

### 2.4 直接传递意义

- 对每个并非共同前驱或共同后继的 z，至少有一个 incident pair 严格改变。这是逐 z 的刚性结论。
- 全矩阵保持型的编辑归约只有上述退化序和块情形；不可把一对外部 witness 保持推广成其余 pair 保持。
- 若一个假设对象所有 pair 都避开 `[1/3,2/3]`，它不可能包含上述 A₂ 序和块，因为该块内部概率为 1/2。因此在这样的假设对象上，每一次不可比关系添加都必然改变至少一个未编辑 pair。这个结论是对一种归约机制的障碍，不是原猜想的证明或反例。

## 3. R3：一般偏序的端点单调性及精确影响量

### 3.1 借用已经审过的经典机制

既有研究 `/workspace/shared/principal-filter-slot-bound-20261018/RESULT.md` §2 和对应独立审稿，已从 Shepp 的差坐标有限分配格给出了下述机制。这里使用的是同一个 FKG 工具，应用到比较事件指示函数；没有把连续随机变量协方差未经论证地替换成事件协方差。

令 F 在 order polytope `O(P)` 中均匀。每个 LE 的严格坐标序单纯形体积均为 `1/|P|!`，所以由坐标排序得到真实均匀 LE。固定中心 b，坐标取 `t=−F(b)`、`d_i=F(i)−F(b)`。有限网格合法域由差值不等式刻画，对 min/max 封闭，均匀权满足有限 FKG；网格极限给任意有界单调函数的关联。此处比较指示函数的不连续集位于有限超平面，零测，Riemann 极限合法。

中心 x 时，`E={d_y>0}` 与 `{x≺z}={d_z>0}` 同为递增事件，故协方差非负。

中心 y 时，`E={d_x<0}` 递减，而 `{y≺z}={d_z>0}` 递增，故协方差非正。

于是对任意 P、任意 `z≠x,y`，

`Δ_xz≥0`，`Δ_yz≤0`，以及反向等式 `Δ_zx=−Δ_xz`、`Δ_zy=−Δ_yz`。       (S)

这就是经典 XYZ/Shepp 关联结构的编辑推论，不是本轮新文献定理。原始文献：L. A. Shepp, The XYZ Conjecture and the FKG Inequality, Ann. Probab. 10(3) (1982), 824–827, DOI https://doi.org/10.1214/aop/1176993791 。本稿承重依据是上述已有本地展开证明和审稿，不依赖尚未核验的更强猜想。

### 3.2 与 R1 合并

将 (S) 与 (B) 合并，得到精确端点影响预算

`|Δ_xz|+|Δ_yz|=((1−p)/p)r_z+s_z`。                      (I)

特别地，右端为零当且仅当 z 同时低于 x,y 或同时高于它们；否则至少一个 incident pair 严格漂移。R1 本身不依赖 Shepp，故即使不调用本节经典工具，完整保持分类仍然独立成立。

注意：这些端点方向不能推广成“所有外部比较均正相关”。§6 的四点例给出外部 covariance 的两种严格符号。

## 4. R2：两链 interleaving 格给出全 pair 同时单调

### 定理 R2

设 P 的全体元素被两条**不相交**链划分：

`A=(a1<…<am)`，`B=(b1<…<bn)`，`m,n≥1`。

允许 P 有任意额外跨链关系。设 `ar∥bs`，编辑为添加 `ar<bs`。则

- 所有 i,j 都有 `Pr_{P⁺}(ai≺bj) ≥ Pr_P(ai≺bj)`；
- 所有反向 pair 概率同时不增；
- A、B 链内所有 pair 的确定概率保持。

因此这确实覆盖对象的全部 pair，但不是“全部 pair 数值保持”。

### 4.1 编码、均匀律与格闭合

对一个 LE 令

`t_i=# {B 元素排在 ai 之前}`。

则 `0≤t1≤…≤tm≤n`。原偏序的跨链关系给出坐标界

`ℓ_i=max({0}∪{j:bj<_P ai})`，

`u_i=min({n}∪{j−1:ai<_P bj})`，

并要求 `ℓ_i≤t_i≤u_i`。

反过来，每个满足这些界的弱增整数向量，唯一指定一个 interleaving：将 ai 放在恰好 t_i 个 B 元素之后；相同 t 值的 A 元素按链序排列。该词满足 P 的全部关系。故 LE 与合法整数向量一一对应，真实均匀 LE 恰对应合法向量的均匀分布。

合法集合 `T(P)` 对逐坐标 min 和 max 封闭：坐标上下界保持，弱增约束也保持。它是有限分配格。均匀权的 log-supermodularity 是等号，有限 FKG 因而适用。

事件 `E_ij={ai≺bj}={t_i<j}` 全部是同向递减事件。故

`Cov(1_{E_ij},1_{E_rs})≥0` 对所有 i,j,r,s 成立。

对编辑事件 E_rs 条件化，(D) 给出全部跨链概率同时不减。反向是补事件，链内恒定，定理得证。

### 4.2 强化：整个比较统计量的随机序

若 f 是 `T(P)` 上任意递减实函数，有限 FKG 给出

`E[f(t)|t_r<s] ≥ E[f(t)]`。

因此不仅单个比较，任何逐坐标递增的 A→B 比较向量统计量，其期望也不减。等价地，t 在编辑后按乘积序随机变小。这是分布级结论，并非仅知道一个 pair 的 covariance。

### 4.3 同向迭代合法，但不平衡不随之单调

添加 `ar<bs` 只是增加一个上界 `t_r≤s−1`；后继仍属于相同的两链划分类。因此可在每一步仍不可比时连续添加 A→B 关系，整个概率向量逐步按同一方向移动。逆向 B→A 编辑给相反方向；混合两种方向时没有同向最终漂移承诺。

但是 `min(q,1−q)` 不随 q 单调。特别地，P 为 `a1<a2` 与单点 b 的不交并，添加 `a1<b`：剩余 pair `(a2,b)` 从 `1/3` 到 `1/2`。完整对象的最大 pair 平衡值也从 `1/3` 到 `1/2`。所以此结构类中的全 pair 概率方向性，也不能推出平衡值不增，更不能由此建立避带反例保持归约。这个例子本来已有边界平衡 pair，绝不是原猜想反例。

## 5. R4：条件协方差的全矩阵秩一预算

选定一个完整无序 pair 清单，每个 pair 固定一个方向。令 Z 为对应的 0/1 比较向量。可包含或排除编辑 pair；以下恒等式对任意这样的固定子清单都成立。

写

`q=E Z`，`q⁺=E[Z|E]`，`q⁻=E[Z|Eᶜ]`，`Δ=q⁺−q`，

`C=Cov(Z)`，`C⁺=Cov(Z|E)`，`C⁻=Cov(Z|Eᶜ)`。

全协方差公式给出

`C = p C⁺+(1−p)C⁻ + p(1−p)(q⁺−q⁻)(q⁺−q⁻)^T`。

由于 `Δ=(1−p)(q⁺−q⁻)`，所以

`C − [p/(1−p)] ΔΔ^T = p C⁺+(1−p)C⁻ ⪰ 0`。            (M)

这是精确等式加半正定结论；不要求全局正关联。对任意实权向量 w，得到

`|w·Δ| ≤ sqrt(((1−p)/p) w^T C w)`。                    (W)

用途和限制：

- 所有 pair 不能各自独立地取其最坏漂移；它们共享同一个 rank-one explained-covariance 预算。
- 任何在 C 的核中的线性比较统计量，其均值必保持。
- 迭代编辑若想使用 (W)，必须携带当步的协方差矩阵和 p；不能冻结最初 C 或假定逐步误差自动抵消。
- 该等式是条件协方差的结构记账工具，不直接给出 `[1/3,2/3]` 证书。R1 给精确零漂移的全局结构，R2 给特殊类的共同符号；三者作用不同。

### 5.1 一个真正的局部独立充分条件

若已有序和分解 `P=P1⊕…⊕Pk`，编辑发生在某一个块 Pi 内，则均匀 LE 的块内扩张相互独立，条件化只改变 Pi。其他块内部全部 pair 保持，块间 pair 恒为确定顺序。故位于另一块的平衡 witness 确实可以传过此次编辑。

这只是带明确分解的局部保持，不能推广到一般自治块或一般外部 pair。R1 描述了“连编辑块内部其他 pair 也全保持”的严格边界。

## 6. 九个冻结控制及最小精确失败

唯一实验设计在 PLAN.md 先写后运行：九个固定带标号偏序、至多六点，不生成或搜索新偏序。程序 `verify_fixed_cases.py` 逐一枚举全部排列，筛原 LE，再按 E 筛后继；所有概率和矩阵等式均用 Fraction 精确运算。完整 pair 账本在 verification.json，运行摘要在 CHECKS.txt。

### 6.1 指定外部平衡 witness 可以丢失

取四点 `{x,y,z,w}`，P 只有关系 `y<z`。编辑添加 `x<y`。

- `e(P)=12`，`p=Pr(x≺y)=1/3`；
- P⁺ 为链 `x<y<z` 与单点 w 的不交并，`e(P⁺)=4`，仍非链；
- 目标 pair `{z,w}` 与编辑端点完全不交，且始终不可比；
- `Pr_P(z≺w)=1/3`，`Pr_{P⁺}(z≺w)=1/4`。

四格计数 `(a,b,c,d)=(1,3,3,5)`，故 covariance 为 `−1/36`，漂移为 `−1/12`。旧 witness 不能作为同一 pair 的后继证书；后继仍有其他平衡 pair，原猜想完全未被反驳。

这是“两个 pair 的端点完全不交”条件下最少四点的精确失败，因为该条件本身要求四个不同元素。没有据此声称它是任何更强失败性质的全局最小例。

### 6.2 同一外部方向的协方差可正可负

仍取 edit `x<y`、target `z<w`。

- P 只有 `x<z`：`N=12,N⁺=8`，target 从 `1/3` 到 `3/8`，covariance `+1/36`。
- P 只有 `x<w`：`N=12,N⁺=8`，target 从 `2/3` 到 `5/8`，covariance `−1/36`。
- 四点反链：target 从 `1/2` 到 `1/2`，covariance 0；但例如 incident pair `x,z` 从 `1/2` 到 `2/3`。所以保留一个外部 pair 绝不表示全矩阵保持。

这些例子的 width 为 3 或 4，未否定 R2 的固定两链假设。

### 6.3 完整保持与两链 controls

- `D=A₂, U=A₂`，`P=D⊕A₂(x,y)⊕U`：`N=8,N⁺=4`，全部未编辑 pair 原样保持，符合 R1；编辑后仍非链。
- 两条无跨边链 `A₂,B₃`，添加 `a1<b2`：`N=10,N⁺=7`，全部 A→B drift 非负。
- 两条链 `A₃,B₃`，另有 `a1<b2,b1<a3`，添加 `a2<b2`：`N=15,N⁺=9`，全部 A→B drift 非负。
- `A₂⊔B₁` control：`N=3,N⁺=2`，`(a2,b)` 从 `1/3` 到 `1/2`。

程序还对九个对象的每个第三点核验 (B)，对全部 pair 坐标的每两个坐标核验 (M) 的等式部分。没有以这些控制代替 PSD 或一般 FKG 的证明。

这次编辑提供了一套明确的传递接口：
