# 任意 ideal runs 与一般 slot T：单调删除纤维、自含有限 n 协方差界

日期：2026-10-19。本报告只作本地数学研究，不外写。证明只需输入中已经使用的 ordinary FKG；通过取 Y=X 自含闭合二阶矩，不需要尾 LC 或先用 run 方差定理；不依赖 general slot T，也不把 marker 倾斜协方差误读为原协方差，不声称文献首创。

## 0. 已证结果

设 P 是 n 点有限偏序，K,L 是 ideals，均匀随机 LE 中 X=R_K、Y=R_L，r=EX、s=EY，并记

    M2 = E binom(X,2),
    a = (n−s)/(n+1),
    g_X = r(r+1)−Var(X) = 2(r²−M2).

本轮得到如下原分布界；**不要求 K⊆L**：

    Cov(X,Y) ≤ a E[X(X+1)/2] = a(r+M2).                 (C1)

若 K⊆L，则直接得到所要求的准确缺项控制：

    Cov(X,Y−X)
      ≤ (r²−M2) − (s+1)(r+M2)/(n+1)
      = g_X/2 − (s+1)(r+M2)/(n+1)
      ≤ g_X.                                           (C2)

令 M=r+M2=E[X(X+1)/2]。把 C1 本身取 Y=X，得到完全自含的有限 n 二阶矩界与其协方差推论：

    M ≤ (n+1)r(r+1)/(n+r+2),                           (C3a)

    Var(X) ≤ (n−r)r(r+1)/(n+r+2),                     (C3b)

    Cov(X,Y) ≤ (n−s)r(r+1)/(n+r+2) ≤ r(r+1).          (C3)

交换 X,Y 还可取相应对称界的最小值。C3a 立即给 M2≤r²，所以 C2 最后一项所用 g_X≥0 也不需要继承尾 LC。

因此任意两个非空上理想的**一般 slot T 已由明确删除/FKG机制证明**，见第4节的精确0起点映射；嵌套目标只是其特例。结论仅涉及该辅助 slot 不等式，不涉及原全局猜想。C1 保留实际二阶矩，在任意反链及任意嵌套 K⊆L 上精确取等号；C3a–C3 也在该反链族同时取等号。Cov(X,Y)≤r 这一更强猜想对一般 K 不成立；8 点反链中 |K|=6、|L|=7 已有 r=2、Cov=9/4。

证明中的两种删除严格分开：

- 从连续均匀 order polytope 删除一般 ideal 后，残余坐标确实按合法纤维体积倾斜，通常不均匀。
- 条件化某一个**精确合法 prefix word**后，残余离散 LE 与剩余偏序的全部 LE 一一对应，因而确实均匀。

关键是连续倾斜的同向 FKG 比较对每个同长度 prefix ideal 给出同一个上界；于是再对 prefix words 混合，不会引入尚未控制的协方差缺项。

## 1. 一般 ideal 删除的精确连续纤维

采用 order polytope 约定

    O(P) = {t∈[0,1]^P : t_x≤t_y whenever x≤_P y}.

给定 ideal A⊆P，|A|=i，令 Q=P\A。对 u∈O(Q)，定义合法删除纤维

    F_A(u) = {z∈[0,1]^A :
      z_a≤z_b whenever a≤_P b in A,
      z_a≤u_q whenever a∈A, q∈Q, a≤_P q},

以及 i 维 Lebesgue 体积

    W_A(u)=vol_i F_A(u).

A 是 ideal，故不存在 q∈Q、a∈A 的 q<_P a；上式已经包含全部跨边约束，没有遗漏来自 Q 的下界。因此

    O(P) = {(z,u): u∈O(Q), z∈F_A(u)},                   (D1)

且若 u≤v（逐坐标），则 F_A(u)⊆F_A(v)，从而

    W_A(u)≤W_A(v).                                    (D2)

这证明了**实际体积权的坐标递增性**。没有把它替换为某一条 LE 上的离散插入数。

设 ν_Q 为 O(Q) 的均匀概率分布。由 Fubini，均匀 O(P) 删除 A 后的 u 边缘分布为

    dν_{P→Q}(u) = W_A(u) dν_Q(u) / E_{ν_Q}W_A,         (D3)

其中分母为

    E_{ν_Q}W_A = vol O(P)/vol O(Q)
                = (n−i)! e(P)/(n! e(Q)) >0.

这一归一化保留了实际维数与全部扩张数因子。

### FKG 比较

O(Q) 对逐坐标 min、max 封闭。有限等距格点上的均匀指标权满足 log-supermodularity，因而有限 FKG 给任意两个坐标递增函数的非负协方差。令格距趋零，Riemann 和收敛到 O(Q) 上的均匀积分。这里使用的 H 是有限个坐标之 min，连续；W_A 是移动线性上界切出的有限维体积函数，也连续（坐标变动只可能改变有限个薄片的体积）。因此对下文 H 与 W_A，得到

    E_{ν_Q}[H W_A] ≥ E_{ν_Q}H · E_{ν_Q}W_A.

结合 D3：

    E_{ν_P}H ≥ E_{ν_Q}H.                              (D4)

D4 是均匀 O(P) 残余坐标相对均匀 O(Q) 的递增比较；它不是残余坐标均匀的断言。

## 2. 对 L-run 的逐 ideal 删除比较

先假设 L≠P，且 A⊆L 是 ideal，|A|=i。于是 P\L 非空且完全保留在 Q 中。令

    H(u) = min_{v∈P\L} u_v,
    μ_A = E_{Unif LE(Q)} R_{L\A}.

H 坐标递增，因此 D4 可用。

对任意 m 点偏序 S，均匀 O(S) 可按其 LE 分割成 m! 个顺序单形中的 e(S) 个；这些单形体积均为 1/m!。先选均匀 LE，再选独立的 m 个均匀[0,1]点的次序统计量，恰生成均匀 O(S)。因此若首次离开某个 ideal 的秩是 R+1，则对应最小外点坐标的均值为 E(R+1)/(m+1)。应用于 P 和 Q：

    E_{ν_P}H = (s+1)/(n+1),
    E_{ν_Q}H = (μ_A+1)/(n−i+1).

D4 遂给

    (μ_A+1)/(n−i+1) ≤ (s+1)/(n+1),

即

    μ_A ≤ s − i(s+1)/(n+1).                           (D5)

i=0 时等号；若 L=P 则直接 μ_A=n−i、s=n，同一 D5 仍是等号，不需定义空集的 min。所有大小为 i 且包含于 L 的 ideals A 都满足**同一个**上界。

## 3. 精确 prefix word 条件化与混合

固定 i≥1 和一个能够作为 P-LE 前 i 项出现的精确 word

    w=(a_1,…,a_i),  A={a_1,…,a_i}⊆K.

A 自动是 ideal。将 w 固定后，删除这 i 项与 LE(P\A) 之间存在双射：任意剩余 LE 接在 w 后均合法，因为 A 为 ideal；反向显然唯一。故

    law(剩余 LE | prefix=w) = Unif LE(P\A).            (P1)

这才是此证明中所用的均匀残余法则，其纤维恰为一，而非一般无条件删除。

### 嵌套情形

若 K⊆L，则 A⊆L。逐扩张 Y=i+R_{L\A}，所以由 D5

    E[Y|prefix=w] = i+μ_A
       ≤ s+i(n−s)/(n+1).                              (P2)

事件 {X≥i} 是所有长度 i、全部字母位于 K 的合法精确 prefix words 的不交并。各 word 的真实条件混合权可以不同；P2 的右侧只依赖 i，不依赖 word 或 A，所以直接混合得到

    E[Y|X≥i]−s ≤ i(n−s)/(n+1).                        (P3)

没有假定不同 A 的权相等，没有把整个条件混合误当某个均匀剩余偏序。

### 任意 K,L 的额外扩展

P2 实际对无需嵌套的 ideals K,L 也成立。若该 word 的 A⊆L，沿上面证明。若 A⊄L，则 word 内已经出现 P\L 元素，Y 已由 w 完全确定且 Y≤i−1。另一方面

    s+i(n−s)/(n+1)−(i−1)
      = (s+1)(n+1−i)/(n+1) >0                         (1≤i≤n).

因此 P2、P3 在这一分支也成立。这一步不尝试对删除了外点的 A 使用 H；只利用该 prefix 已经截断 Y。

## 4. 尾和、原协方差及准确缺项

令 q_i=P(X≥i)。X 是非负整数，故

    Cov(X,Y)
      = Σ_{i=1}^{|K|} Cov(1_{X≥i},Y)
      = Σ_{i=1}^{|K|} q_i(E[Y|X≥i]−s).

把 P3 逐项代入，得

    Cov(X,Y)
      ≤ (n−s)/(n+1) Σ_{i≥1} i q_i
      = (n−s)/(n+1) E[X(X+1)/2]
      = a(r+M2).

这就是 C1。交换 X,Y 还给对称的另一个界，因此可取

    Cov(X,Y) ≤ min{
      (n−s)(r+E binom(X,2))/(n+1),
      (n−r)(s+E binom(Y,2))/(n+1)}.                    (C1sym)

### 嵌套情形的精确 FKG 余量

对每个长度 i 的合法 K-prefix word w，记 A=A(w)，并定义

    d_A = Cov_{ν_Q}(H,W_A)/E_{ν_Q}W_A
        = (s+1)/(n+1) − (μ_A+1)/(n−i+1) ≥0.

L=P 时把 d_A 定义为0。由上述所有等式，在嵌套情形有准确恒等式

    a(r+M2)−Cov(X,Y)
      = Σ_{i=1}^{|K|} q_i (n−i+1)
          E[d_{A(w)} | X≥i].                          (C1slack)

右侧使用真实 prefix 条件权。该式把全部删除倾斜误差保留为显式非负 FKG 余量；C1 并非从某个倾斜协方差“约去权重”。它还给出 C1 取等号的精确条件：每个正概率 prefix word 对应的 d_A 都为0。反链的常数 W_A 显然满足它。

### 用 Y=X 自含闭合二阶矩

C1 已经对所有两个 ideal runs 成立，也允许 K=L。令 M=r+M2，则

    Var(X)=2M−r(r+1).

在 C1 中取 Y=X、s=r，得到

    2M−r(r+1) ≤ (n−r)M/(n+1).

移项得

    (n+r+2)M/(n+1) ≤ r(r+1),

即 C3a。代入 Var(X)=2M−r(r+1) 得 C3b；代回一般 C1 得 C3。这一步没有循环：C1 只用了删除/FKG与精确 prefix 条件化，尚未使用任何方差或二阶矩界。

因为 (n+1)/(n+r+2)≤1，C3a 给 M≤r(r+1)，即 M2≤r²。因此 g_X=2(r²−M2)≥0 也已在本论证内证明。输入的尾 LC 可独立给同一个较弱 M2≤r²，但这里不再需要它。

由 Var(X)=2M2+r−r²，C1 等价推出

    Cov(X,Y−X)
      = Cov(X,Y)−Var(X)
      ≤ (r²−M2)−(1−a)(r+M2),

即 C2。特别地此论证**没有**声称 Cov(X,Y−X)≤0；右侧可正，实际三点例也可正。

### 与既存 slot T 定义的精确映射及一般目标

已逐项核对输入 `../principal-filter-slot-bound-20261018/RESULT.md` 的结论段及第5–6节，以及 `../nonprincipal-slot-mixture-20261018/RESULT.md` 的结论段：旧槽变量均为**0起点的首次出现前元素数**，不是首次出现秩本身。

具体地，在旧报告任意 n 点偏序 U 中，对两个非空上理想 S_y,S_z 设

    K=U\S_y, L=U\S_z,
    R_y=min_{v∈S_y}f(v)−1,
    R_z=min_{v∈S_z}f(v)−1.

K,L 是 ideals，而且逐扩张有

    P=U, X=R_K=R_y, Y=R_L=R_z,
    r=EX=ER_y, s=EY=ER_z,
    N=E[R_yR_z+min(R_y,R_z)]=E[XY+min(X,Y)].

若 S_y=↑x 是 principal，则 min_{S_y}f=f(x)，所以 X=f(x)−1，恰回收旧 principal 报告的槽变量；旧报告用于中间转换的秩 A=f(x) 则是 X+1。两者未混用。连续公式 H 的均值为 (s+1)/(n+1)，其中 +1 来自 Y+1 的首次外点秩；从头到尾没有把它替换成 s/(n+1)。

由 E min(X,Y)≤r 及 C3，得到新的单侧有限 n 界

    N−rs ≤ r + (n−s)r(r+1)/(n+r+2).

交换 X,Y 后可取两侧最小值：

    N−rs ≤ min{
      r+(n−s)r(r+1)/(n+r+2),
      s+(n−r)s(s+1)/(n+s+2)}.                         (T-finite)

特别地 (n−s)/(n+r+2)≤1，所以

    N ≤ rs+min{r²+2r,s²+2s}.                          (T)

这正是旧稿的 general slot T，**无需 principal 或两上理想嵌套**。对于嵌套 K⊆L，min(X,Y)=X，使它恰包含用户所指定的 Cov(X,Y)≤r(r+1)。

旧赢家分解的准确式 g_X+epsilon_bar−Delta=r²+2r−(N−rs) 因而也得到统一非负预算；更精确地，本证明给

    g_X+epsilon_bar−Delta
      ≥ r(r+1)(r+s+2)/(n+r+2) ≥0.                    (T-gap)

这里只是把新的 T-finite 代入旧稿既证的恒等式；不重新假设赢家混合项 Delta 非正，不影响旧正号控制。

## 5. 锐性、结构解释与过强猜想的边界

### 5.1 反链上的 C1 等号

P 为 n 点反链，K⊆L，|K|=h、|L|=g<n。任意 A⊆K 的删除纤维都是完整 [0,1]^A，所以 W_A≡1，D4、D5 逐 A 等号，进而 P3、C1 也全部等号。其参数为

    r=h/(n−h+1),
    s=g/(n−g+1),
    M2=h(h−1)/[(n−h+1)(n−h+2)],
    Cov(X,Y)=(n−g)/(n−g+1) · (r+M2).                  (A1)

此外由 A1 可直接核对 M=(n+1)r(r+1)/(n+r+2)，所以 C3a、C3b、C3 也全部取等号。

这证明该有限 n 上界有无界的 actual 锐性族，不能普遍缩小系数；不声称对每个连续指定的不可实现均值参数都存在取等号偏序。

### 5.2 Cov≤r 对一般 K 为假

8 点反链，取 |K|=6、|L|=7 且 K⊂L：

    r=2, s=7/2, M2=5/2,
    Cov(X,Y)=9/4>2=r.

这是实际均匀 LE，非抽象 law；一般 singleton 的 Cov≤r 不能原样推广。C1 仍为等号。

### 5.3 准确缺项可正

P={a<b}⊔{c}，K={a}，L={a,b}。三个均匀 LE 依次为 abc、acb、cab，给

    (X,Y)=(1,2),(1,1),(0,0), each 1/3.

于是 r=2/3、s=1、M2=0，Cov(X,Y)=1/3，VarX=2/9，故

    Cov(X,Y−X)=1/9>0.

C1、C2 同时取等号。本例清楚表明证明支付的是预算，不是错误的负关联强化。
