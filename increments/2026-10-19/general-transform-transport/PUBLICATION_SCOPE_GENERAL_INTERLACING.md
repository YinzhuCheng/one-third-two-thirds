# 发布范围与可复现来源：任意 t 自治链交错增量

本包只保存本轮两份完整新证明、两份最终独立审查、定向文献比对，以及必要的自有脚本和精确控制摘要。概率均为实际有限偏序的均匀有标签完整线性扩张；有限实验通过不承担一般定理证明。

## 实验保存范围

冻结预算：28 个结构族、336 个实际有标签外偏序、2016 次相邻长度比较、3,084,480 条严格不等式。独立控制为84个 tiny full-bitmask 核对、16个有二点反链 clone 块的重数核对，以及最小 gap 证书的5个完整有标签 ideal-DP 计数。这里不声称336个实例两两非同构。

包内保留冻结预算、结果说明、总摘要、最小 gap 原始证书及独立核对、三个生成/验证程序。未附约10 MB 的完整关系表、约42 MB 的全部精确分子计数压缩表，以及可再生成的中间 manifest、逐实例扫描表和运行日志。原结果说明中列出的这些完整文件仍在本轮本地来源目录，而非本小包附件。

本地完整来源目录是 `/workspace/shared/general-interlacing-tests-20261019/`。其中 `all_actual_relations.json` 保存全部336个字面有标签传递闭包；`all_exact_counts.jsonl.gz` 保存全部2016次比较的总数和完整 i×x 分子数组。它们是数据证书，不是证明一般定理的替代物。

## 从包内脚本再生成完整实验

进入 `general-interlacing-tests-20261019`，依次执行：

```bash
python3 test_actual.py
python3 write_certificates.py
python3 verify_minimum_independently.py
```

程序只依赖 Python 标准库，路径基于各脚本自身目录。第一步生成冻结的336参数实例、逐长度结果和摘要，第二步生成完整关系表、全部精确计数及最小 gap 证书，第三步独立核对该证书的5个实际计数。重运行会覆盖同名生成结果；应在可写副本内执行。机器时间和浮点展示值可能变化，数学判定使用精确整数/有理数。本次三端同步没有重跑这些实验。

独立 transport 小控制可在 `review-general-insertion-20261019` 内执行 `python3 independent_transport_check.py`；它只核对一族固定实际 t=3 对象的18条记录及归一化，不是扩大搜索。
