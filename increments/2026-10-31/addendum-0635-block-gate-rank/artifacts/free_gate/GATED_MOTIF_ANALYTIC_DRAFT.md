# 门控上层 motif：实际 good pair 的解析证明草稿

**状态：作者推导完成，解析积分由符号多项式核验；尚待另一代理独立逐行审查。** 不以先前8序/73系数的扩张诊断作为本证明。无文献优先权声明。

## 1. 精确且有限的环境接口

取任意有限外部偏序 O，其中有四个不同门点 `v,c,b,d`，满足 `v<b,d`。除此之外 O 可任意；这里 `c` 对应原例 c1。

向 O 添入11个新点
`x,s,e,h,r,z,t0,f0,y,q,w`，仅加入以下生成边，再取传递闭包：

```
c<x,s,h,r;
v<s;
d<e,h;
b<h,z,y;
e<r,z,t0,f0;
s<z,y;
x<f0,y;
h<t0,q;
r<y;
f0<q;
y<q;
t0<w;
q<w.
```

对应原15点例：`x=c2,h=a1,r=a3,z=a2,t0=a4,y=f1,q=f2,w=f3`。

**禁止额外上层接口**：除以上生成边外，不添加 O 与这11点之间的边，也不改变11点内部关系。特别没有新核心指向 O 的边。外界可通过四门的外部前驱产生传递关系，但这正是上述生成构造允许的关系。不能将本结论用于任意附加上层连边。

**候选结论**：原 P 的均匀线性扩张中
`Pr(z<y)<1/2`。
并且完整 `D(z)⊆D(y)`、`U(y)\U(z)={q<w}`；故 `(z,y)` 是实际 Zaguia good pair，应用既有定理得到 P 存在平衡对。这里不声称指定 `(z,y)` 本身一定≥1/3。

## 2. 为什么固定门坐标足够且保留真实权重

在 P 的序多面体中固定 O 的全部坐标。核心只看到四门实数坐标 `V,C,B,D`，其中 `V<B,D`；公共上限为1，其他外部坐标不直接约束核心。合法门域在零测边界外有

```
M=max(B,C,D)<1,  S0=max(V,C)≤M.
```

证明每个非退化门纤维上 `vol(y<z)−vol(z<y)>0`，然后对真实外部坐标测度积分。绝不将外部线性扩张/门纤维等权化。

## 3. 不依赖线性扩张枚举的三重积分

用同名小写字母表示核心坐标。固定 `y=f1`、`E=e`、`Q=q=f2`。
令

```
J(E,y)=(y−S0)(1−2y)+(y²−S0²)/2+((max(B,E)−S0)_+)²/2,
K(Q,E,y)=(y−C)Q−(y²−C²)/2−((E−C)_+)²/2.
```

直接积分各坐标，得到有符号体积差

```
Δ = 1/2 ∫[y=M..1] ∫[E=D..y]
      (y−max(E,C)) J(E,y)
      ∫[Q=y..1] (1−Q)
        [(Q−M)(1−M)−(E−M)_+²] K(Q,E,y) dQ dE dy.
```

推导逐项如下。

1. `r=a3` 在 `[max(E,C),y]`，给因子 `y−max(E,C)`。
2. `z=a2` 在 `[L,1]`，`L=max(B,E,s)`；因 `y≥L`，积分符号 `1_{y<z}−1_{z<y}` 得 `1+L−2y`。再对 `s∈[S0,y]` 积分就是 J。
3. `x=c2∈[C,y]`。给定 x，`f0∈[max(E,x),Q]`；对 x 积分长度 `Q−max(E,x)` 就是 K。
4. `h=a1∈[M,Q]`，`t0=a4∈[max(E,h),w]`，`w=f3∈[Q,1]`。因为 `E≤y≤Q` 且 `M≤y`，先积分 h,t0,w，结果恰为
   `(1−Q)/2 * [(Q−M)(1−M)−(E−M)_+²]`。
5. y 同时在 `B,C,E,s,x,r` 之后，且 E≥D，所以 y≥M；其余所有边已编码。不存在遗漏的前驱或额外独立权重。

这给出纯多项式积分证明入口；J 可正可负，所以还需以下收尾，不能直接说“积分因子均非负”。

## 4. 正间隔变量及统一解析收尾

平移 M 至0，公共上限变为 `T=1−M>0`。定义

```
α=M−C≥0, β=M−D≥0, γ=M−S0≥0.
```

有 `γ≤α`。若 `α≤β`，则 `C≥D>V`，故 `γ=α`；若 `α≥β`，则 `β≤γ≤α`。

按**最后开门者**分三类，不枚举8个底层全序。

### c 门最后：C=M

此时 α=γ=0，直接积分得到

`11! Δ = T^10 (4950β+929T)>0`。

### d 门最后：D=M

此时 β=0，直接积分得到

`11! Δ = T^9 [2750αγ+3058γT+3608(α−γ)T+929T²]>0`。

已把原式中的负项 `−550γT` 与 `3608αT` 合并成非负间隔表达式，不能漏掉 `α≥γ`。

### b 门最后：B=M

令

```
ℓ=min(α,β), u=(γ−β)_+, z0=α−γ, w0=(β−α)_+.
```

这些均非负。若 α≥β，则 `(α,β,γ)=(ℓ+u+z0,ℓ,ℓ+u)`；若 α≤β，则 `(α,β,γ)=(ℓ,ℓ+w0,ℓ)`。

定义以下正系数多项式：

```
A(ℓ,T)=221760ℓ³+194040ℓ²T+15840ℓT²+2750T³;
B0(ℓ,T)=360360ℓ⁴+434280ℓ³T+112860ℓ²T²+22330ℓT³+3058T⁴;
C0(ℓ,T)=138600ℓ⁵+219450ℓ⁴T+89760ℓ³T²+28985ℓ²T³+8008ℓT⁴+929T⁵;
D0(ℓ,T)=221760ℓ⁴+249480ℓ³T+85140ℓ²T²+27500ℓT³+3608T⁴;
E0(ℓ,T)=332640ℓ⁴+443520ℓ³T+156420ℓ²T²+35640ℓT³+4950T⁴.
```

直接积分的统一形式为

`11! Δ = T^6 [C0+u B0+u² A+z0(D0+u A)+w0 E0]>0`。

全部项非负且 `C0≥929T⁵>0`，故收尾无需扩张表或有限样本。三类还统一给出 `Δ≥929T^11/11!>0`。

## 5. 积分公式可手工复核的短分段

把门坐标平移后，E 的正区间 `[0,y]` 对三类都相同；设α、γ保留，则

```
J+=(y+γ)(T−2y)+(y²+E²)/2+Eγ,
K+=(y+α)Q−(y²+E²)/2−Eα.
```

对
`(y−E) J+ (T−Q)(QT−E²) K+ /2`
依次积分 `Q∈[y,T], E∈[0,y], y∈[0,T]`，结果为

`T^9(2750αγ+3608αT−550γT+929T²)/11!`。

- c 最后：E∈[−β,0] 的附加贡献为 `4950βT^10/11!`（此时α=γ=0）。
- d 最后：没有负 E 区间。
- b 最后：E≤0 时 J 不再依赖 E，
  `J−=(y+γ)(T−2y)+y²/2`。
  若 E≤−α，则 r 长度为 `y+α`，K 为 `(y+α)Q−(y²−α²)/2`；
  若 E≥−α，则 r 长度为 `y−E`，K 仍为 K+。
  因此只在 E=−α 分一次区间，按 β≥α 或 β≤α 使用端点−β、−α、0；普通多项式积分即得第4节统一正式。

`verify_analytic_integrals.py` 只执行这些符号积分及恒等式检查，不计算任何线性扩张。它是核验工具，不取代以上完整积分设置与精确接口。

## 6. 范围与待审问题

- 本结果是一个固定11点上层结构、任意合法底部环境的门控 motif 引理；不是任意自由门单缺陷 C2 分类。
- 不允许通过“模块化缩商”偷换原测度；没有使用这种假设。
- 基例确在此域，故一旦此稿独审通过，可解析解释其实际 good pair，而不再仅依赖88349/201453的精确计数。
- 任意额外上层边、外部后继、独立截止上限都可能改变积分。需另证后才能扩大接口。
- 尚待独审的重点：完整生成集/积分上下限是否等价；max 的分段是否正确；三类正式与原积分是否完全一致；从序多面体回到原扩张测度是否保留权重。

## 7. 可脱离软件复核的纸面算术证书（独审建议补充）

第5节被积式完全展开为单项式后，使用以下两个恒等式即可逐项计算；i,j,k 是非负整数：

```
∫[y=0..T] ∫[E=0..y] ∫[Q=y..T] y^i E^j Q^k dQ dE dy
 = T^(i+j+k+3)/[(j+1)(i+j+2)(i+j+k+3)],

∫[y=0..T] ∫[Q=y..T] y^i Q^k dQ dy
 = T^(i+k+2)/[(i+1)(i+k+2)].
```

第一式可交换积分顺序为 `0≤E≤y≤Q≤T`，先 E 再 y 再 Q；第二式同理。负 E 区间另用
`∫[-β..0] E^j dE=(-1)^j β^(j+1)/(j+1)`。

为明确给出 b 最后分支的所有中间算术，令 `R(β)` 表示 E∈[−β,0] 且按 E≥−α 公式积分的附加贡献；在 `0≤β≤α` 中：

```
11! R(β)/T^6 =
 β (15840αγT²+24750αT³−7920γT³+4950T⁴)
 +β²(194040αγT+69300αT²+11880γT²+9405T³)
 +β³(221760αγ+55440αT−9240γT−7260T²)
 −β⁴(83160γ+20790T).
```

若 β≥α，真实负 E 贡献为 `R(α)+(β−α)L`，其中

```
11! L/T^6 =
 332640α³γ+83160α³T+360360α²γT+116820α²T²
 +39600αγT²+43560αT³−7920γT³+4950T⁴.
```

L 是 E≤−α 区间的恒定 E 截面在 y,Q 上的积分。将其与第5节正 E 积分相加，再分别代入
`(α,β,γ)=(ℓ+u+z0,ℓ,ℓ+u)` 或 `(ℓ,ℓ+w0,ℓ)`，逐项合并即得到第4节统一正式。由此多项式系数不是依赖线性扩张表或未展示的软件黑箱。
