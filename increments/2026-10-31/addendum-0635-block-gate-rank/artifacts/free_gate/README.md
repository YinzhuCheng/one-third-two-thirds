## 一个可解析的无界障碍族

对任意 t≥0，令 `P_t=P⊕C_t`，在基例之上作序和添加 t 点链。每个扩张必为原 P 扩张接上固定链，故所有原对概率不变。新增点在 F 中且与旧点全可比，因此 A、T、S、b∥s、e<F 与 Δ9 保持。旧不可比对的 D/U 差集及链判定不变，新点不引入不可比对，因此无 VG 与无混合环保持。

这给任意大 F 的菜单障碍族；t>0 的全族**不能称模块素**，因为序和添加了模块。只有15点基例经过模块素核验。
