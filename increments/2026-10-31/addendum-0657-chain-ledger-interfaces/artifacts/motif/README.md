# 门控 motif 第二轮：接口定理与方向障碍

**冻结状态：2026-10-31，本阶段数学探索已收束。仅本地归档，无远端改写。**

## 已内部独审通过

1. **全11核公共上下界安全**：有效门坐标作max截断、公共上界仿射变换，保持严格概率方向；不允许偷偷弱化成仅目标两点公共上界。
2. **方向安全的矩形补边**：原a≤y、z≤b时添a<b只删z<y词；满足精确排除条件时保持实际good-pair结构。
3. **顶部三种附件的准确区别**：只添z<w使分母减少e(P−z)；在w上接与z不比的链使分母线性增加；在整个P上接顶链不改概率。三项不是依次操作。
4. **私有上链的严格必要界**：仅给z添m点私链，则Pr(y<z)=Θ(m^{−(|D(y)\D(z)|+1)})，故不能无限制允许这种接口。未证明、也未声称随m单调。
5. **终端插槽余量**：统一上述方向变化为删早槽或晚槽，保留正确外词测度；添上界后使用计数定义，不误称z仍极大。

这些是接口机制和初等推论，不是新的Zaguia定理。原11核初始符号仍依赖第一轮已经独审的直接积分证明；本轮**没有**将11核本体缩成更小注入，也没有完成所有安全接口分类。未做文献优先权确认，不等于正式发表。
