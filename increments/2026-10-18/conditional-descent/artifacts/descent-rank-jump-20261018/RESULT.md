# 自治链相邻 rank 跳幅与平均删除的局部保持条件

日期：2026-10-18。接续：`/workspace/shared/descent-insertion-identity-20261018/RESULT.md` 的 AC-2 和第 4 节。

范围：只处理自治链缩短时的相邻 rank 插值障碍及其与既有重加权公式的连接。不解原猜想，不作全局分类；下述条件结论不声称一般的 δ 非增或一般反例递降，也不声称这些条件已被某个假想反例满足。

## 0. 结论与证明状态

**已证，覆盖全部实际有限偏序及下述全部参数：**

1. 设自治链 C 长 m≥2，外部与全链不可比的集合 I 大小 t≥1。对 y∈I、1≤i<m，

   0≤Pr(c_i<y)−Pr(c_{i+1}<y)≤t/(m+t)。

   这比候选界 t/(m+1) 强。t≥2 时，每个内部跳幅实际上严格小于 t/(m+t)；不声称这一无尺寸限制的常数对内部 rank 锐。

2. 若 m≥max{2,t}，有更锐且可由实际偏序达到的内部界

   Pr(c_i<y)−Pr(c_{i+1}<y)≤mt/[(m+t)(m+t−1)]≤1/3。

   因而若整个 C×{y} 没有概率落在闭区间 [1/3,2/3] 的配对，则所有 Pr(c_i<y) 都小于 1/3，或都大于 2/3。因此任意相邻凸插值也在同一侧。m≥t 只是充分条件，不声称必要；由第一条得到的 m≥2t 是更简单的充分基线。

3. 对链缩短 Q=P_{m−1}，还必须控制平均删除产生的窗口重加权。用已证平均权重比 R_av=(m+t)/(m+k₀)，若 P 非链、β=δ(P)<1/3、m≥max{2,t}，则

   δ(Q)≤R_av β/(1−β+R_av β)。

   特别地，额外的实际 slack 条件 R_av<(1−β)/(2β) 足够推出 δ(Q)<1/3。它不推出一般的 δ(Q)≤δ(P)，也不能从单独 β<1/3 自动得到。

4. 给出实际偏序上的边界例：两元链与三元链的不交并，在两元链与三元链中点之间，旧概率为 7/10、3/10；链缩短后的概率为 1/2。此时 K 恒定，只有相邻插值障碍，没有窗口重加权障碍。

有限整数控制另列于末节；它只核对局部 shuffle 公式，不承担普遍结论的证明。

## 1. 对象、窗口与准确跳幅

P 是有限偏序；C={c₁<⋯<c_m} 是自治链，m≥2。每个外部点或者在 C 的全体点之下，或者在其全体点之上，或者与其全体点不可比。分别记三类为 D、U、I，t=|I|≥1。

固定 y∈I，并记

q_i=Pr_P(c_i<y)，1≤i≤m。

P 的概率始终指均匀线性扩张。令 J 是 y 之前的 C 点数，则 q_i=Pr_P(J≥i)，因此内部跳幅为

Δ_i=q_i−q_{i+1}=Pr_P(J=i)，1≤i<m。

特别地 q₁≥⋯≥q_m。这一方向不能倒置。

固定完整外部偏序 R=P\C 的一个线性扩张 S。用最后一个 D 点和最早一个 U 点作为窗口边界；集合为空时，使用左、右端哨兵。窗口中的外部点均属于 I；记其数目为 K，0≤K≤t。条件于 S 后，C 与这 K 个外部点的所有合法 shuffle 等概率。

若 y 在窗口外，J 只能为 0 或 m，故每个内部 Δ_i 的条件贡献为 0。若 y 在窗口内，它在这些 K 个外部点中具有某个次序 r，1≤r≤K，此时对 0≤j≤m，

Pr_P(J=j | S)
= binom(j+r−1,r−1) binom(m−j+K−r,K−r) / binom(m+K,K)。

理由：y 前须有 r−1 个固定次序的外部点和 j 个 C 点，y 后须有 K−r 个外部点和 m−j 个 C 点。这里没有把 S 在 P 下的诱导分布误当成外部扩张的均匀分布；后续界对每个 S 分别成立，最后在其实际诱导分布下取期望。

## 2. RJ-1：全部参数的跳幅界

### 局部 shuffle 引理

对整数 m≥2、K≥1、1≤r≤K、0≤j≤m，上述条件概率满足

Pr(J=j | S)≤K/(m+K)。

证明一（均匀子集）：在长度 N=m+K 的 shuffle 中，K 个外部点的位置构成均匀的 K 元子集。J=j 等价于“第 r 个外部位置恰为 x=j+r”。此事件是“固定位置 x 属于外部位置集合”的子事件；后者概率恰为 K/N。

证明二（直接核对分子）：Vandermonde 恒等式中，

binom(j+r−1,r−1) binom(m−j+K−r,K−r)
≤ binom(m+K−1,K−1)，

因为两上参数之和为 m+K−1，两下参数之和为 K−1，左边只是求和中的一个非负项。再除以 binom(m+K,K) 即得 K/(m+K)。

若 K=1，J 在 {0,…,m} 上均匀，每个 j 都达到此界。若 K≥2 且 1≤j<m，界严格：在固定位置 x=j+r 被外部点占据的子集中，除其为第 r 个外部位置外，还存在另一种可能的外部次序。例如 r<K 时可令 x 为第 r+1 个外部位置（因为 j≥1，左侧有足够位置）；r=K 时可令 x 为第 K−1 个（因为 m−j≥1，右侧有足够位置）。因此内部事件是真子事件。

### 全实际 P 的结论

写 W_y={S:y 在窗口内}。对每个内部 i，

Δ_i
≤E_{S∼P}[1_{W_y} K(S)/(m+K(S))]
≤Pr_{S∼P}(W_y) · t/(m+t)
≤t/(m+t)。

第一项中的期望是实际均匀 P 扩张诱导的外部次序分布。函数 K↦K/(m+K) 单调，故此平均步骤不需要知道外部次序的权重、也不需要限制 D、U、I 内部的关系。

t≥2 时，每个 S 的内部条件贡献都严格小于 t/(m+t)：若 K=t，使用局部严格性；若 K<t，使用严格单调性（窗口外贡献为 0）。有限平均仍严格，故 Δ_i<t/(m+t)。t=1 时可达到等号：取 P=C 与孤立点 y 的不交并，此时 Δ_i=1/(m+1)=t/(m+t)。

因此 t/(m+t) 是已证界，不是实验猜测。较弱的 t/(m+1) 随即成立，因为 m+t≥m+1；它不需要另作 Beta 密度论证。

### RJ-1b：m≥t 域内的锐内部界

先固定 m≥K≥1、1≤r≤K、1≤j<m，记

l=r−1，k=K−r，A=j+l，B=m−j+k，N=m+K。

于是 A,B≥1，A+B=N−1，l+k=K−1。约定非法下指标的二项式为 0。证明

binom(A,l)binom(B,k)≤binom(N−2,K−1)。

以下两个条件至少有一个成立：j≥r；m−j≥K−r+1。否则整数性给 j≤r−1、m−j≤K−r，相加得 m≤K−1，矛盾。

- 若 j≥r，则 binom(A,l+1)≥binom(A,l)，因为两者之比为 j/r≥1。对第二因子作 Pascal 分解：

  binom(A,l)binom(B,k)
  =binom(A,l)binom(B−1,k)+binom(A,l)binom(B−1,k−1)
  ≤binom(A,l)binom(B−1,k)+binom(A,l+1)binom(B−1,k−1)
  ≤binom(N−2,K−1)。

  最后是 Vandermonde 求和中的两个项；k=0 时第二项为 0，仍成立。

- 若 m−j≥K−r+1，则 binom(B,k+1)≥binom(B,k)，因为比值为 (m−j)/(K−r+1)≥1。对第一因子作 Pascal 分解：

  binom(A,l)binom(B,k)
  =binom(A−1,l)binom(B,k)+binom(A−1,l−1)binom(B,k)
  ≤binom(A−1,l)binom(B,k)+binom(A−1,l−1)binom(B,k+1)
  ≤binom(N−2,K−1)。

  l=0 时第二项为 0，亦包含在证明中。

除以 binom(N,K) 得局部内部界

Pr(J=j|S)≤F_m(K):=mK/[(m+K)(m+K−1)]。

现在假定 m≥t≥1。对整数 1≤K<m，直接相减有

F_m(K+1)−F_m(K)
=m(m−K−1)/[(m+K−1)(m+K)(m+K+1)]≥0。

故对全部 1≤K≤t，F_m(K)≤F_m(t)。窗口外仍贡献 0，于实际 P 的外部次序分布下取平均便得

Δ_i≤mt/[(m+t)(m+t−1)]。

该上界≤1/3 的整数边界如下：t=1 时等于 1/(m+1)≤1/3；t≥2 时令 d=m−t≥0，则

(m+t)(m+t−1)−3mt=t(t−2)+d(t−1)+d²≥0。

上界等于 1/3 仅可能在 (m,t)=(2,1) 或 (2,2)，无需省略这些端点。

**域内锐性。** 取实际 P 为长度 m 的链 C 与长度 t 的外部链 I 的不交并，y 取外部链首点，i=1。外部次序唯一、K=t、r=1，由公式得到

Δ₁=binom(m+t−2,t−1)/binom(m+t,t)=mt/[(m+t)(m+t−1)]。

因此该内部统一界在整个参数域 m≥t≥1、m≥2 上逐参数可达。m<t 时本节的证明不适用，不能擅自延伸此锐界。

## 3. RJ-2：何时相邻插值不再跨入平衡区

称某个 C×{y} 配对平衡，是指其 q_i∈[1/3,2/3]，包含两个端点。

**列同侧引理。** 若 max_{1≤i<m}Δ_i≤1/3，且所有 q_i 均不在 [1/3,2/3]，则恰有以下一种情况：

- q_i<1/3 对每个 i 成立；
- q_i>2/3 对每个 i 成立。

证明：否则由 q_i 非增，可取相邻两项 q_i>2/3、q_{i+1}<1/3，从而 Δ_i>1/3，矛盾。严格大于号解释了为什么跳幅允许等于 1/3。

由 RJ-1，m≥2t 即保证 Δ_i≤t/(m+t)≤1/3；由 RJ-1b，尺寸前提可进一步放宽为 m≥t。也可以直接使用逐列的更细界 E[1_{W_y}K/(m+K)]≤1/3，或实际 Δ_i≤1/3。没有把充分整数阈值说成必要阈值。

在列同侧条件下，定义该列实际的最坏稀有概率

p_y=max_i min(q_i,1−q_i)
=q₁（整列在低侧），或 1−q_m（整列在高侧）。

于是 p_y<1/3，且列 margin η_y=1/3−p_y>0。对于每个 1≤r≤m−1，相邻插值

M_r=((m−r)/m)q_r+(r/m)q_{r+1}

仍在该列同一阈值侧，其同一稀有方向的概率 p_r 是 M_r 或 1−M_r，均满足 p_r≤p_y。**这只处理插值；尚未把 M_r 等同于缩短后均匀 Q 的概率。**

## 4. 与 AC-2 的精确接口：保留未知 slack

删去一个 C 点并规范重标，得到 Q=P_{m−1}，链记 c′₁<⋯<c′_{m−1}。依既有 AC-2，令

b_r=Pr_Q(c′_r<y)，
γ_r=Cov_Q(1_{c′_r<y},K)/(m+E_QK)，

则准确关系是

M_r=b_r+γ_r，亦即 b_r=M_r−γ_r。

为统一两个方向，令 F_r 是同侧引理所确定的稀有方向：低侧取 {c′_r<y}，高侧取 {y<c′_r}。记 b_r^rare=Pr_Q(F_r)，并令

κ_r=Cov_Q(1_{F_r},K)/(m+E_QK)。

平均 rank 删除产生的加权 Q 分布给 F_r 的概率恰为前节 p_r，故

p_r=b_r^rare+κ_r。

若 ε_r=1/3−p_r>0，则保持这个方向严格稀有的准确充要条件为

b_r^rare<1/3  ⇔  κ_r>−ε_r。

例如 |κ_r|<ε_r 足够，κ_r≥0 也足够。不能仅从 p_r<1/3 推出任何所需协方差符号。ε_r≥η_y 仅说明该列有实际正 margin，不说明存在跨偏序的统一下界。

也可引用前文已证的权重比界，免去逐对协方差估计。这里 k₀=min K 是外部窗口能够取得的最小 I 点数，0≤k₀≤t；其关系型定义与可达性见前文。平均 rank 的实际比为

R_av=(m+t)/(m+k₀)。

对该加权分布中的稀有事件概率 p_r，前文 odds 界给出

b_r^rare≤R_av p_r/(1−p_r+R_av p_r)。

所以以下任一明确的充分条件可逐列使用：

p_y<1/(1+2R_av)=(m+k₀)/(3m+k₀+2t)，

或等价地

η_y>2(t−k₀)/[3(3m+k₀+2t)]。

它们同时保留了插值所需的同侧前提与重加权所需的真实 margin。即使 m≥t，单独“整列没有平衡对”也没有提供后一数值条件；因此不能把 RJ-2 当成一般保持定理。

## 5. RJ-3：带实际 margin 的完整条件保持引理

为说明上述接口已经覆盖所有 Q 配对，给出一个严格限定的条件结论。定义有限非链偏序的

δ(P)=max_{u∥v} min(Pr_P(u<v),Pr_P(v<u))。

**命题。** 假定 P 非链、C 自治且 m≥2、t≥1、m≥t，并设 β=δ(P)<1/3。则对 Q=P_{m−1}，

δ(Q)≤R_av β/(1−β+R_av β)。

特别地，若还满足

R_av<(1−β)/(2β)，

则 δ(Q)<1/3。这里 Q 须非链；在当前 t≥1、m≥2 的设定下，任意 y∈I 与幸存链点仍不可比，因而这一点自动满足。若推广到没有 I 的设定，须单独保留 Q 非链要求。

证明：Q 的不可比对只有两种。

1. 完全外部配对。在 P 中选择其概率≤β 的稀有方向。该事件不受删哪一个链 rank 影响，所以其在平均删除加权 Q 分布中的概率仍≤β。
2. 幸存链点 c′_r 与 y∈I。因为 β<1/3，旧列整个 C×{y} 没有平衡对；由 m≥t、RJ-1b 与 RJ-2，旧列同侧。在这个共同稀有方向上，平均删除的概率 p_r 是两个旧稀有概率的凸插值，故 p_r≤β。

两个类型对每个 Q 不可比对都提供一个加权概率 p≤β 的方向。对每个方向引用第 4 节相同的 odds 界，并利用 p↦R_av p/(1−p+R_av p) 递增，即得所写 δ 上界。附加条件等价于该上界严格小于 1/3。

这里没有重证或更改全局权重恒等式，只对其原先缺失的“含链 rank 事件是否有同一稀有方向”补入了一个有参数限制的答案。

**边界。** R_av≥1，所给上界通常大于 β；所以此命题不是一般 δ 非增。附加条件可等价写为

(1−3β)m>2βt−(1−β)k₀，

或使用实际 ε=1/3−β>0 写为

ε>2(t−k₀)/[3(3m+k₀+2t)]。

β 是 P 本身的实际 δ，不能把“存在正 ε”当成已知统一正 ε。本文件未提供满足全部假想反例前提的实例或普遍 margin。

**仅作代数推论。** 如果存在按点数最小的非链偏序 P，满足 δ(P)=β<1/3，那么对其中一个满足 m≥t 的自治链（且 m≥2、Q 非链），必须有

(1−3β)m≤2βt−(1−β)k₀。

否则上一命题会给出更小的非链 Q 仍满足 δ(Q)<1/3，违反最小性。这是假想最小反例的必要不等式，不是其存在性、结构分类或一般大小界。β→1/3 时所能解出的 m 上界会退化；不能据此声称有统一核心上界。

## 6. 实际边界例：插值障碍可以独立出现

取 P 为两条链的不交并：

C={c₁<c₂}，另一条链为 a<y<b。

C 是自治链，m=2、I={a,y,b}、t=K=3，且只有一个完整外部次序 a,y,b，y 的窗内 rank 为 r=2。局部公式给出

Pr(J=0)=3/10，Pr(J=1)=4/10，Pr(J=2)=3/10。

因此

q₁=7/10，q₂=3/10，Δ₁=2/5>1/3。

旧的 C×{y} 没有平衡对。缩短 C 后，Q 中的一个幸存链点可以等概率插入 a<y<b 的四个位置，故

Pr_Q(c′₁<y)=1/2=(q₁+q₂)/2。

此处 K 恒定，全部相关协方差为零，进入平衡区完全由相邻 rank 插值造成。它说明不能不加替代条件就删去跳幅/同侧要求，也说明重加权障碍与插值障碍在逻辑上不同。该例不满足“P 的所有不可比对都不平衡”，不构成原猜想的反例。更强的充分条件 m≥t 在此亦不成立。

- 在 m≥t 的上述整数域核对 F_m(K) 的离散单调性、F_m(t) 的锐性实例与 1/3 等号端点。
- 在 m=2,…,7、K=1,…,7 直接枚举外部位置 K 元子集，独立核对每个概率公式。
- 核对上节实际边界例的全部分数。

运行结果在 `CHECKS.json`。这不是偏序或 δ 的分类实验；没有重复全局自治链 δ 单调性测试。有限检查不替代 RJ-1 至 RJ-3 的证明。
