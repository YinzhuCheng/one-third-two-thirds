# t=1 自治链缩 1：整列保持与严格外部反控

**结论。** 整列 `C×{y}` 的无平衡性无需 margin 即可随缩 1 保持；但它不能替代完全外部原标签对的安全性。下面给出精确窗口证明，以及对每个 `m≥2` 成立、C 为极大自治链的严格反控族。平衡一律指闭区间 `[1/3,2/3]`。

## 1. 精确窗口计数

固定长度 `m≥2` 的自治链 `C={c1<...<cm}`，唯一与全部 C 不可比的外部点 y；其余外部点分成下侧 D 与上侧 U。令 `R=P−C`。传递性强制 `D<U`，且不能有 `y<d` 或 `u<y`。

将 R 的线性扩张分三类，数量分别为 A、C0、B：

- A：y 后仍有 D 点。
- C0：所有 D 在 y 前，所有 U 在 y 后。
- B：y 前已有 U 点。

三类互斥穷尽。`D=∅` 时 A=0，`U=∅` 时 B=0；两侧都空时 `C0=1`。窗口类与任意 `LE(D),LE(U)` 一一对应，故

`c:=C0=e(D)e(U)>0`，其中 `e(∅)=1`。

A、B 类只有一种插 C 法，分别使全部 C 在 y 后、在 y 前；窗口类有 `m+1` 种，按放在 y 前的 C 点数 `k=0,...,m` 计。因此

`T_m=e(P_m)=A+B+(m+1)c`，

`q_i(m)=Pr(c_i<y)=[B+(m+1−i)c]/T_m`。

A、B、c 都只依赖固定的外部偏序 R。

## 2. 整列保持定理

`q_i` 单调递减，相邻差为 `c/T_m≤1/(m+1)≤1/3`。若整列避开闭区间，却有高于 `2/3` 与低于 `1/3` 的项，就必有相邻两项跨过整个闭区间，差严格大于 `1/3`，矛盾。所以整列只能全部低，或全部高。

检查两个最端点得到充要条件：

- 全部 `<1/3` iff `A>2B+(2m−1)c`。
- 全部 `>2/3` iff `B>2A+(2m−1)c`。

所以，整列有平衡 iff

`A≤2B+(2m−1)c` 且 `B≤2A+(2m−1)c`。

等号属于有平衡。删除 C 中任意一点后，原链按剩余顺序变成长 `m−1` 的链，外部标签不变；新整列的对应系数为 `2m−3`。原来的任一严格不等式自动蕴含新的严格不等式，故整列保持无平衡。`m=2→1` 也直接适用。无需额外 margin，亦不依赖全局无平衡假设。

固定 R 时，置 `L=max(A−2B,B−2A)`。在 `m≥2` 范围，整列进入平衡的准确链长条件是 `(2m−1)c≥L`，最小允许链长为 `max(2,ceil((L+c)/(2c)))`。

## 3. 完全外部原标签对：准确重加权条件

对固定外部事件 `E={x<z}`，记三类中的分子 `A_E,B_E,C_E`，并置 `K=A+B,H=A_E+B_E,f=C_E`。插 C 不改变外部次序，故

`p_m=[H+(m+1)f]/[K+(m+1)c]`，

`p_{m−1}=[H+m f]/[K+m c]`。

已有低侧配对仍在低侧的充要条件是

`K−3H+m(c−3f)>0`；

已有高侧配对仍在高侧的充要条件是

`3H−2K+m(3f−2c)>0`。

特别地，若 `f/c∈[1/3,2/3]`，两侧的已有无平衡配对均自动保持在原侧；若 `Hc=Kf`（包括各非空类别 E 比例相同），则概率完全不变。`K=0` 时也完全不变。这里 f 可为 0、c 或中间整数，并未把三类分子限成 0/1 事件。

精确的低阈值失守条带：必须 `d=c−3f>0`，并且

`−(m+1)d<K−3H≤−m d`。

高阈值对偶：必须 `d=3f−2c>0`，并且

`−(m+1)d<3H−2K≤−m d`。

右端等号表示缩后恰到阈值。这些是逐外部对的准确条件，不是粗全局权重比；整列不等式不能自动排除它们。

## 4. 极大自治链上的全 m 严格反控

对任意 `m≥2`，取

`D=(a1<...<a_{2m}) ⊔ {z}`，`U=∅`，所有 D 点都在 C 下方，y 与所有其他点不可比。缩 1 删除 `c_m`，保持全部外部原标签。

C 的唯一外部不可比邻点为 y，且 C 是包含极大的自治链：加入任何 `a_j` 时，外部 z 对它和 C 的关系不同；只加入 z 时，外部 `a_j` 对它和 C 的关系不同；不能同时加入 z 与 `a_j`，因为它们不成链。

z 在 a 链的 `2m+1` 个缝隙中自由插入，故

`c=2m+1, A=(2m+1)^2, B=0`，

`T_m=(2m+1)(3m+2), q_i=(m+1−i)/(3m+2)`。

原整列最大概率 `m/(3m+2)<1/3`，缩后最大概率 `(m−1)/(3m+1)<1/3`，所以明确满足整列安全的非空局部条件。

取完全外部原标签对 `E={y<a_m}`。窗口类 E 不发生。每个 D 扩张贡献 `rank_D(a_m)` 个使 y 在其前的插入位置。m 个 z 缝隙使该秩为 `m+1`，另 `m+1` 个使秩为 m。因此

`A_E=2m(m+1), B_E=C_E=0`。

分子不随缩 1 改变，而

`p_m=2m(m+1)/[(2m+1)(3m+2)]`，

`p_{m−1}=2m(m+1)/[(2m+1)(3m+1)]`。

令 `N=2m(m+1)`。有 `T_m−3N=m+2>0`、`3N−T_{m−1}=m−1>0`、`2T_{m−1}−3N=6m²+4m+2>0`。所以

**`p_m<1/3<p_{m−1}<2/3`，是严格进入内部。**

m=2 时只有 8 点：`A=25,B=0,c=5,T:40→35`；C/y 概率为 `1/4,1/8→1/7`；外部同一对 `{y<a2}` 为 **`3/10→12/35`**。同一族的外部对 `{z<a1}` 概率恒为 `1/(2m+1)<1/3`，提供上述完全不变条件的真实安全实例。

## 5. 逻辑边界与核验

该族原来已有平衡对 `{y<z}`，概率 `(m+1)/(3m+2)∈(1/3,2/3)`。因此它不是原猜想反例；它精确否定“t=1、C 极大且整列安全，便足以保证所有外部原标签对安全”。

真正剩余 gap 是：若希望整个偏序的缩链保持，须由额外已证结构排除第 3 节的外部危险条带。全局假设可能带来额外限制，本轮既未证明它足够，也未反驳它；不再改换机制或进行全局分类。

`verify.py` 对同一结构族 m=2,3,4,5 逐一生成全部实标签 LE，核验全部公式、目标对严格穿越、不变对与自治链极大性；结果在 `verification.json`。任意 m 的结论依据上面的证明。较长推导保留在 `DETAILS.md`，无需用于主稿阅读。
