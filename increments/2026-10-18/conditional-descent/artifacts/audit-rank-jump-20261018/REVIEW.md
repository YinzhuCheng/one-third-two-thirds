# 自治链缩短的 rank 跳幅：独立审阅

日期：2026-10-18。仅审自治链条件化分布、内部 rank 跳幅、同侧插值及有实际 slack 的条件保持。没有研究原猜想的证明或分类，没有声称一般反例递降，没有外部写入。

## 结论

1. 待核界 `p_j≤K/(m+K)` 对全部参数成立，而且作为全 `j` 的界是锐的。证明来自均匀子集的单点包含概率。
2. 内部可显著加强：若 `m≥K`，则对 `1≤j<m` 有

   `p_j≤mK/[(m+K)(m+K−1)]≤1/3`。

   第一界对每个适用 `(m,K)` 均由 `(r,j)=(1,1)` 达到。
3. 因而实际自治链只须 `m≥max{2,t}`，即可对每个外部不可比点得到全部实际 rank 的跳幅至多 `1/3`。这把原拟条件 `m≥2t` 改善为 `m≥t`，没有丢掉 `m≥2`。
4. 在 `β=δ(P)<1/3` 下，同侧结论及平均 rank 插值成立。但插值本身仍不是均匀 `Q` 的概率，必须恢复倾斜密度。
5. 完整条件保持定理成立：若 `Q` 非链，且 `R_av=(m+t)/(m+k₀)<(1−β)/(2β)`，则 `δ(Q)<1/3`。此定理只需上述改善后的 `m≥t`。它既不是 `δ(Q)≤β`，也不保证任意假想反例满足这些条件。

## 1. 全 j 锐界与等号

设 `N=m+K`，`m≥2,K≥1,1≤r≤K,0≤j≤m`，

`p_j=C(j+r−1,r−1)C(m−j+K−r,K−r)/C(N,K)`。

在 `[N]` 中均匀选一个 `K` 元子集，把其元素按升序记作 `X₁<⋯<X_K`。事件 `X_r=j+r` 的概率正是上式：指定该位置被选，再在其前选 `r−1` 个、其后选 `K−r` 个。于是

`p_j=Pr(X_r=j+r)≤Pr(j+r 被选)=K/N`。

等号完整分类：

- `K=1`：全部 `j` 等号，分布均匀。
- `K≥2`：仅 `(r,j)=(1,0)` 或 `(K,m)` 等号。

对后一断言，条件于 `x=j+r` 被选，剩下 `K−1` 个点是 `[N]\{x}` 的均匀子集。若 `x` 前后均有点，挑一个前点和一个后点，通过一次交换即可改变前方被选数，故“恰有 `r−1` 个前方被选点”不可能条件概率为 1。只有两端情形例外。因为 `m≥2`，所需交换始终可选。故内部 `j` 在 `K≥2` 时严格小于 `K/N`；`K=1` 时内部也可等号。

## 2. m≥K 时的内部锐界

约定越界二项式系数为 0。固定 `1≤j<m`，令

`A=j+r−1`，`B=m−j+K−r`，`q=K−r`。

要证的分子界是

`C(A,r−1)C(B,q)≤C(N−2,K−1)`。

`m≥K` 保证以下两条件至少一个成立：

- `j≥r`；
- `m−j≥q+1`。

否则 `j≤r−1` 且 `m−j≤q`，相加得 `m≤K−1`，矛盾。

### 情形一：j≥r

由 `C(A,r)/C(A,r−1)=j/r≥1`，以及 Pascal 恒等式，

`C(A,r−1)C(B,q)`

`=C(A,r−1)C(B−1,q)+C(A,r−1)C(B−1,q−1)`

`≤C(A,r−1)C(B−1,q)+C(A,r)C(B−1,q−1)`

`≤C(A+B−1,K−1)=C(N−2,K−1)`。

最后一行是 Vandermonde 和中的两个非负项。由于 `m−j≥1`，这里 `B−1≥0`；`q=0` 时含 `q−1` 的项按约定为 0。

### 情形二：m−j≥q+1

由 `C(B,q+1)/C(B,q)=(m−j)/(q+1)≥1`，

`C(A,r−1)C(B,q)`

`=C(A−1,r−1)C(B,q)+C(A−1,r−2)C(B,q)`

`≤C(A−1,r−1)C(B,q)+C(A−1,r−2)C(B,q+1)`

`≤C(A+B−1,K−1)=C(N−2,K−1)`。

同样是 Vandermonde 中两项。`A−1≥0`，且 `r=1` 的越界项为 0。

除以 `C(N,K)` 得

`p_j≤C(N−2,K−1)/C(N,K)=mK/[N(N−1)]`。

取 `r=1,j=1`，分子恰为 `C(N−2,K−1)`，故这一内部界对每个 `m≥K` 都锐。

还要核 `≤1/3`：若 `K=1`，右侧为 `1/(m+1)≤1/3`。若 `K≥2`，则 `N≥4` 且 `mK≤N²/4`，故右侧 `≤N/[4(N−1)]≤1/3`。等于 `1/3` 仅可能 `(m,K)=(2,1),(2,2)`。

## 3. 从完整外部扩张到实际 rank 跳幅

设 `C={c₁<⋯<c_m}` 为自治链，外部点分为全在链下的 `D`、全在链上的 `U`、与整链不可比的 `I`，`t=|I|`。固定完整外部线性扩张 `S`，令合法窗口为最后 `D` 之后、最早 `U` 之前，空边界使用首尾哨兵。窗口中恰有 `K(S)≤t` 个 `I` 点。

条件于 `S`，链的合法交错一一对应于 `m+K` 个位置中的 `K` 元外部位置子集，且均匀。若 `y∈I` 在窗口内为第 `r` 个点，令 `J` 是位于 `y` 之前的链点数，则 `Pr(J=j|S)=p_j`。若 `y` 在窗口外，`J` 恒为 0 或 m，故不贡献任何内部跳幅。这一步必须用完整外部扩张条件化，不能只固定窗口大小而忽略外部权重。

记 `a_i=Pr_P(c_i<y)`。对 `1≤i<m`，

`a_i−a_{i+1}=Pr_P(c_i<y<c_{i+1})=Pr_P(J=i)`。

先由全 j 界得到无附加密度条件的估计

`a_i−a_{i+1}≤t/(m+t)`。

故原拟 `m≥2t` 确实足够。更强地，当 `m≥t≥1`，由上一节逐纤维有

`a_i−a_{i+1}≤mt/[(m+t)(m+t−1)]≤1/3`。

这里 `F_m(K)=mK/[(m+K)(m+K−1)]` 对 `1≤K≤m` 非降，因为比较 `F_m(K+1)` 与 `F_m(K)` 的交叉相乘差为 `m−K−1≥0`。`t=0` 时没有这类配对，相关跳幅为 0。

该实际偏序类别的统一内部界同样锐：取 `C_m` 与一条外部 `t` 点链的不交并，令 `y` 为该外部链首点并取 `i=1`，则 `K≡t`、跳幅恰为上述值。

不能任意删除长度条件：`m=2,K=3,r=2,j=1` 时 `p_j=2/5>1/3`。实际模型为 `C₂⊔C₃`，`y` 是外部三点链的中间点。此时 `(a₁,a₂)=(7/10,3/10)`，缩短后对应概率为 `1/2`。这只是 rank 插值机制的边界控制，不是原猜想反例。

## 4. 同侧、插值及恢复均匀 Q

若 `P` 没有 `[1/3,2/3]` 平衡对，则每个 `a_i` 都 `<1/3` 或 `>2/3`。序列 `a_i` 非增。如果它有两侧值，就有相邻两值跨侧，其差严格大于 `1/3`，与上一节矛盾。跳幅上界为非严格 `≤1/3` 已经足够，不能误写成只有 `<1/3` 才可用。

更精确地，设 `β=δ(P)<1/3`。则同一 `y` 的全部 `a_i` 要么均 `≤β`，要么均 `≥1−β`。

令 `Q=P_{m−1}`，链规范重标为 `c′₁<⋯<c′_{m−1}`。在均匀 `P` 扩张中独立均匀删除一个原链 rank，再规范重标，得到 `Ext(Q)` 上混合法 `μ`。对 `1≤r<m`，

`Pr_μ(c′_r<y)=M_r=((m−r)/m)a_r+(r/m)a_{r+1}`。

同侧使该新配对有一个方向在 `μ` 下概率至多 `β`。完全外部配对在每个删除 rank 下都拉回为同一个旧事件，所以其旧稀有方向在 `μ` 下也至多 `β`。`Q` 的不可比对只分为以上两种，覆盖完整。

但 `μ` 一般不是均匀 `Q` 分布。令 `K(L)` 为 `Q` 扩张对应的外部窗口点数，则

`dμ/dUnif_Q=(m+K)/(m+E_QK)`。

相邻插值与均匀概率 `b_r=Pr_Q(c′_r<y)` 的精确关系是

`M_r=b_r+Cov_Q(1_{c′_r<y},K)/(m+E_QK)`。

因此只说“凸组合仍同侧”不完成均匀 `Q` 的证明。需要控制该倾斜修正；不能默认为协方差为 0 或有有利符号。

## 5. 完整条件保持定理通过

**定理。** 设 `P` 含长度 `m≥2` 的自治链，`t` 为外部不可比点数，`m≥t`。设 `β=δ(P)<1/3`，缩短后 `Q` 非链。令 `k₀=min_{L∈Ext(Q)}K(L)`；结构上可用外部最后前驱/最早后继之间强制夹入的点数计算该最小值，而 `max K=t`。若

`R_av=(m+t)/(m+k₀)<(1−β)/(2β)`，

则 `δ(Q)<1/3`。

**证明。** `Q` 非链保证 `P` 非链且 `β>0`，所以阈值除法合法。由第 3、4 节，`Q` 每个不可比对都可选一个在 `μ` 下概率 `p≤β` 的方向。倾斜权重 `m+K` 的最大最小比为 `R_av`。一般有界密度的反向 odds 界给该方向在均匀 `Q` 下的概率

`q≤R_av p/(1−p+R_av p)≤R_av β/(1−β+R_av β)<1/3`。

最后一个严格号等价于所列 `R_av` 条件。对全部有限不可比对取最大，即得 `δ(Q)<1/3`。证毕。

`t=0` 时 `R_av=1`，定理仍成立。这里不需要额外假设协方差符号；实际 slack 与密度比一起控制了它。也可以保留原拟较强条件 `m≥2t`，但不应丢掉已经证明的 `m≥t` 改善。

**准确限制。**

- 没有得到 `δ(Q)≤δ(P)`；上面的 odds 上界通常大于 `β`。
- 没有证明任意 `β<1/3` 的假想反例满足自治链长度或窗口比条件。
- `β<1/3` 给出每个固定有限对象的正 slack，不给跨对象统一 slack。`R_av>1` 时不能把实际 slack 从保持定理中删去。
- 单一事件协方差反例不等于原猜想反例，也不能反过来否定这个有完整条件的保持定理。
