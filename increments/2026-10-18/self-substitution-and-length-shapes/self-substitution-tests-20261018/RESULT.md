# 自代换 P[P]：四个固定结构的精确诊断

日期：2026-10-18。状态：**强化命题已被最小非链例严格否定；条件性反例保留未被否定。**

## 1. 首要结果与否定范围

令

δ(P) = max_{x∥y} min{Pr_P(x<y), Pr_P(y<x)},

其中线性扩张均匀且有标签。P[P] 的元素写成 (p,a)：外层 p∈P，每个外层点替换为一个内层 P；若 p<r，则整个 p 块先于整个 r 块；若 p∥r，块间无关系。

非空强化候选

δ(P[P]) ≤ δ(P)

已在 P = {X} ⊔ {A<B} 失败：

- δ(P) = 1/3。
- δ(P[P]) = 19/42。
- 增量为 5/42。
- 最优 crosspair 之一是 (X,A) 与 (A,X)，其正向计数为 1026/2268 = 19/42。
- 对偶位置的另一最优 crosspair 是 (X,B) 与 (B,X)，正向概率 1242/2268 = 23/42，平衡度同为 19/42。

这是按 |P| 最小的非链反控：2 点非链只有二点反链，δ=1/2，而任何偏序的 δ≤1/2，所以不可能严格上升。该最小性是两个点的结构性论证，没有追加结构枚举。

**这不是原 1/3–2/3 猜想反例，也不否定条件命题**

δ(P)<1/3 ⇒ δ(P[P])<1/3。

上述最小例已经有平衡度 1/3；本轮四个 P 全都满足 δ(P)≥1/3。因而本轮没有在该条件命题的前提区间内进行实验。强化候选的失败仅排除了“所有非链 P 的 δ 均不增加”这条充分路线。

## 3. 计数方法与可核查公式

### 3.1 原 P 的 rank 计数

对每个 P 直接遍历 n! 个排列、按全部偏序关系筛出 Ext(P)。因此原 P 的 e(P)、全部 pair 概率及 rank 分布均直接得出；最大 n=5，仅 120 个排列。

令 M_a(i) 为 e(P) 个扩张中 a 位于第 i 位的个数，i=1,…,n。按各例上表的点序，rank 计数矩阵为：

C₁⊔C₂，点序 X,A,B：

    1 1 1
    2 1 0
    0 1 2

C₂⊔C₃，点序 A₁,A₂,B₁,B₂,B₃：

    4 3 2 1 0
    0 1 2 3 4
    6 3 1 0 0
    0 3 4 3 0
    0 0 1 3 6

N，点序 A,B,C,D：

    3 2 0 0
    2 2 1 0
    0 1 2 2
    0 0 2 3

    0 1 1 1

原 P 的全部不可比正向概率也保存在 counts.json。具体为：

- C₂⊔C₃：按 (A₁,B₁),(A₁,B₂),(A₁,B₃),(A₂,B₁),(A₂,B₂),(A₂,B₃)，依次 2/5,7/10,9/10,1/10,3/10,3/5。
- N：Pr(A<B)=3/5，Pr(B<C)=4/5，Pr(C<D)=3/5。
- 非对称四点例：Pr(b<d)=2/3，Pr(c<d)=1/3。

### 3.2 core 词精确 DP

R=P[C_n]，记 W=e(R)。每个有标签 P[P] 扩张唯一对应于：

1. 一个 R 的扩张，即每个块号恰出现 n 次的合法标签词；
2. n 个各自属于 Ext(P) 的块内扩张。

反向重建唯一。因此标签词均匀，块内扩张独立均匀，且

e(P[P]) = W e(P)^n。

core 状态 c=(c_p)∈{0,…,n}^n。允许 c→c+e_p 当且仅当 c_p<n 且每个 r<p 已满足 c_r=n。前向 F(c) 数前缀，后向 B(c) 数后缀：F(0)=1，B(n,…,n)=1；沿允许边分别递推加和。

对固定 p∥r，定义整数核矩阵 K^{p,r}，其中 K(i,j) 是 R 的扩张中第 i 个 p 先于第 j 个 r 的扩张数。精确计算式为

K^{p,r}(i,j) = Σ F(c) B(c+e_p)，

求和遍历允许的 p 步且 c_p=i−1、c_r<j。每条符合事件的标签词恰在其第 i 个 p 出现时被计一次。

于是 P[P] 的 crosspair 正向有标签扩张计数为

N_{(p,a),(r,b)} = e(P)^(n−2) Σ_{i,j} M_a(i) M_b(j) K^{p,r}(i,j)。

分母为 W e(P)^n。同块 pair 保留原 P 的概率；可比块固定为 0 或 1。全部 K 矩阵、全部 crosspair 原始计数都在 counts.json，未省略非最优 pair。

### 3.3 独立复核

- 对最小例 P[P] 的 9 个有标签元素，使用与 core DP 无关的递归拓扑排列生成，直接枚举全部 2268 个线性扩张，统计全部 24 个不可比 pair；全部与 rank 混合计数一致。
- 另对四个 P[P] 各自建立完整有标签前驱位集，直接在其理想图上做前向/后向 DP。它不使用 core 词、rank 分布或纤维分解，独立重算 e(P[P]) 和所有不可比 pair 的计数，四例全部一致。
- 25 点例只遍历 782 个有标签理想，**没有枚举其 326876000000 个扩张**。
- 独审另外用 84 个二色 shuffle 的超几何计数独立确认最小例的核矩阵与 19/42 witness。独审没有替代上述完整 pair 覆盖。

## 4. 最小例的手算证书与 crosspair 类型

P=X⊔(A<B)。原扩张为 XAB、AXB、ABX。R=P[C₃] 是 C₃⊔C₆，故 W=binom(9,3)=84。因每个合法词有 3³ 个块内扩张，e(P[P])=84·27=2268。

对 outer X 与 outer A，按其内部第 i、j 个槽位，核计数矩阵为

    K^(X,A) = 28 49 64
                7 19 34
                1  4 10

每项分母 84。对应 outer X 与 outer B 的核计数矩阵为

    K^(X,B) = 74 80 83
               50 65 77
               20 35 56

目标 pair u=(X,A)、v=(A,X) 使用 M_A=(2,1,0)，M_X=(1,1,1)，因此

Σ M_A(i)M_X(j)K^(X,A)(i,j)
= 2(28+49+64)+(7+19+34)
= 342。

未涉 pair 的第三块提供 e(P)=3 个内部扩张，故正向计数为 3·342=1026，反向为 2268−1026=1242。

变平衡的类型是**不同不可比 outer 块中选取不同 inner 角色**：原 outer 关系 Pr(X<A)=1/3；把偏早的内层 A 放在 X 块、把 rank 均匀的内层 X 放在 A 块后，概率变为19/42。另一个最优 pair 对应 upper-chain core B，概率为23/42。变化只来自 crosspair；同块概率精确保留，outer 可比块仍全可比。

全部跨 outer X,A 的概率矩阵（行 inner X,A,B，列 inner X,A,B）为：

    2/7     4/21    8/21
    19/42   9/28    7/12
    5/42    5/84    5/28

全部跨 outer X,B 的概率矩阵为：

    5/7     13/21   17/21
    37/42   23/28   79/84
    23/42   5/12    19/28

逐项取 min(p,1−p) 后最大值就是19/42；同块最大值为1/3。这同时给出 δ(P[P]) 的上界与下界。矩阵中的5/12是另一 crosspair 的有效平衡度，但不是最大值，与19/42不冲突。
