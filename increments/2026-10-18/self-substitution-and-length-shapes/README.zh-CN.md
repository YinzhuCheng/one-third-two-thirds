## 短概览

1. 对非空有限 P、Q，令 m=|Q|，有 LE(P[Q]) ≅ LE(P[C_m]) × LE(Q)^{|P|}。标签词与各块内部扩张独立均匀；cross pair 的实际概率是两个独立内部 rank 分布对外层 rank kernel 的混合。同块 Q 概率完整保留。
2. Δ(P[Q])=mΔ(P)+Δ(Q)。自代换有 |P[P]|=n²、Δ(P[P])=(n+1)Δ(P)；n>1 时归一化量 Δ/(n−1) 不变。δ(P[P])≥δ(P)；三点 P=C₁⊔C₂ 给出 δ: 1/3→19/42，否定的是普适 δ 不增强化。它不满足严格 δ(P)<1/3 前提，不能否定或证明严格反例闭包。
3. t=2、实际合法窗口计数的完全外部 pair 概率，在 x>−1 连续域至多一次真正转折，整数相邻差也至多一次变号。单个 pair 的闭平衡整数长度集至多两段，q 个 pair 的共同严格安全集至多 2q+1 段。一般系数的两段锐例只是抽象系数例，没有实际偏序实现声明。
4. 冻结的 120 个 typed R 样本（117 个不同对象）中，2255 个无序外部 pair 包括 802 个不可比 pair。一个实际结构给出先升后降、先降后升的两个事件，删其绝对最大元后有六点同系数见证。本批未见两段闭平衡集，只是有限证据；该家族本身始终已有平衡 pair，不能充当原猜想反例。
5. 任意 t 的非零窗口多项式 Σ d_K·binom(x+K,K)，在 x>−1 的实根总重数不超过删零系数符号变化数 V(d)。恒零式单列。相应阈值根预算 B 给共同严格安全实区间数至多 1+floor(B/2)，整数化不增加区间数。
6. 对任意固定 t，若一个实际外部 pair 的两个阈值系数列各至多一次删零变号，则其闭平衡整数长度集合至多一段。这是可由已计算系数识别的充分条件。所有 pair 都属于此类时，变成至多 q 个闭区间的覆盖判定；安全集合仍可能为空。
