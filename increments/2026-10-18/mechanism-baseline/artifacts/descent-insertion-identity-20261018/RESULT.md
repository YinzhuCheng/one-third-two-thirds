# 删除递降的插入权重恒等式与可检查保持条件

日期：2026-10-18。范围：只研究有限偏序删除一个点、自治链缩短的计数与分布保持工具。本文件不处理原 1/3–2/3 猜想的证明，不给全局分类，也不声称得到一般反例递降。

## 0. 已证结果与限制

已证：

1. 任意删除的精确插入密度、协方差恒等式。
2. 插入权重的关系型锐最小值、锐最大值，及权重恒定的充要结构条件。
3. 自治链删除固定 rank 的准确边界公式，以及平均 rank 删除的另一套密度公式；二者不能混同。
4. 由权重比得到的单事件阈值界和显式 margin 条件。
5. 一个完全外部旧配对事件、在 P 中概率严格小于 1/3、但具有负协方差的解析反例。因此常用的“稀有旧方向在插入权重下应正相关”假设失败。

主要限制：自治链原长至少 2，且有 t≥1 个外部不可比点时，固定 rank 权重比的结构锐界是 t+1。仅凭该比的全局 δ 保持条件降到 δ(P)<1/(2t+3)≤1/5，不能覆盖一个任意接近 1/3 的假想反例，不能称一般递降进展。平均 rank 对完全外部配对可有更好的界，但对含链 rank 的配对会出现相邻 rank 插值，仍不能推出 δ 非增。

以下所有“概率”均指均匀随机线性扩张；所有权重期望/协方差均明确标明所在偏序。

## 1. 任意删除：精确权重与协方差

设 P 是有限偏序，x∈P，Q=P−x 是诱导子偏序，n=|Q|。记严格前驱、后继及不可比集合为

- D={y∈Q:y<_P x}；
- U={y∈Q:x<_P y}；
- I={y∈Q:y∥_P x}，t=|I|。

对 L=(q₁,…,qₙ)∈Ext(Q)，令 pos_L(qᵢ)=i，并定义

- a(L)=max_{d∈D} pos_L(d)，D 空时 a(L)=0；
- b(L)=min_{u∈U} pos_L(u)，U 空时 b(L)=n+1；
- w(L)=b(L)−a(L)。

### 命题 IW-1（精确插入计数，已证）

把 x 插在 L 的第 i 个点后（i=0,…,n）得到 P 的线性扩张，当且仅当 a(L)≤i<b(L)。因而恰有 w(L) 个合法插法；w(L)≥1，且

Σ_{L∈Ext(Q)} w(L)=e(P)，E_Q w=e(P)/e(Q)。

删除均匀 P 扩张中的固定点 x，所得 Q 扩张的分布 ν 满足

ν(L)=w(L)/e(P)，
ν(L)/Unif_Q(L)=w(L)/(E_Q w)。

证明：前驱必须全部在 x 前，后继必须全部在 x 后，这也已经充分。P 扩张与“Q 扩张、合法插槽”一一对应。

### 推论 IW-2（任意旧事件，已证）

若 E⊆Ext(Q)，把它拉回为只依赖删去 x 后次序的 P 事件，则

Pr_P(E)−Pr_Q(E)=Cov_Q(1_E,w)/(E_Q w)。

特别地，对任意 u,v∈Q 的旧配对事件 E={u 在 v 前} 适用。这里 Pr_P(E) 不是把 P 的均匀分布误当成 Q 均匀分布；恰是上述 w 加权分布。

更精确地，若 q=Pr_Q(E)，0<q<1，μ_E=E_Q[w|E]，μ_¬E=E_Q[w|¬E]，则

Pr_P(E)=q μ_E/[q μ_E+(1−q)μ_¬E]。

故偏差的符号等价于 μ_E−μ_¬E 的符号，而不是由“事件稀有”本身决定。

## 2. 无需扩张枚举的锐结构界

D、U 分别是 Q 中的下集、上集；不存在 I→D 或 U→I 的严格关系，且每个 D 点都小于每个 U 点。

令 D*=Max(D)，D 空时只放一个形式哨兵 −∞；令 U*=Min(U)，U 空时只放一个形式哨兵 +∞。对 z∈I 约定 −∞<z<+∞。定义

k₀=min_{d∈D*,u∈U*} |{z∈I:d<z<u}|。

### 定理 IW-3（精确极值，已证）

min_{L∈Ext(Q)} w(L)=1+k₀，
max_{L∈Ext(Q)} w(L)=1+t。

因此 R=(t+1)/(k₀+1) 是只查 P 的关系即可计算的精确全局权重比，通常比粗界 t+1 更好。

证明（上界及达到）：a、b 之间的所有实际点都属于 I，所以 w≤t+1。按 D、I、U 三段各取内部线性扩张串接是合法扩张，恰有 w=t+1。

证明（下界）：若 L 的最后前驱为 d、最早后继为 u，则 d∈D*、u∈U*（空集用哨兵）。任何满足 d<z<u 的 I 点必须在二者之间，故 w(L)≥1+k₀。

证明（每个候选 d,u 的下界均可达到）：固定 d∈D*、u∈U*，把 I 分成

A={z∈I:¬(d<z)}；
B={z∈I:d<z<u}；
C={z∈I:d<z 且 ¬(z<u)}。

取下列顺序，各集合内部取任意线性扩张：

D\{d}，A，d，B，u，C，U\{u}。

哨兵不作为实际点输出。该顺序合法：

- d 在 D 中极大，所以 D\{d} 可先放；u 在 U 中极小，所以 U\{u} 可后放。
- I→D、U→I 不可能。
- 若存在由 B 或 C 中的点指向 A 中的点的严格关系，会由传递性推出 d<A，矛盾。
- 若存在由 C 中的点指向 B 中的点的严格关系，会推出 C<u，矛盾。
- C 中点与 u 不可比；u<C 会推出 x<C，亦矛盾。

所得扩张中 d 是最后前驱、u 是最早后继，二者之间恰为 B。因此 w=1+|B|。选择实现 k₀ 的候选即可。

注：D 空、U 空、二者皆空都已包含在哨兵约定中。例如 x 孤立时 k₀=t，权重恒为 t+1，绝非恒为 1。

### 定理 IW-4（恒定权重的充要结构判据，已证）

下列条件等价：

(a) w 在 Ext(Q) 上恒定；
(b) k₀=t；
(c) 两个分别量化的条件都成立：(∀d∈D)(∀z∈I) d<z，且 (∀z∈I)(∀u∈U) z<u；这两个全称条件各自按空集约定，而不是使用可能整体空泛的联合三重量词；
(d) P 是序和 D ⊕ (I ⊔ {x}) ⊕ U。

此时 w≡t+1，ν=Unif_Q，因而删除 x 保留全部旧事件和旧配对概率。

证明：(a)⇔(b) 由 IW-3；(c) 显然推出 (b)。反之，若存在 d₀∈D 与 z∈I 不满足 d₀<z，则 z<d₀ 不可能，否则 z<x。把 d₀ 向上延至一个 d∈Max(D)；若 d<z 则 d₀<z，矛盾，因此 d∥z。任取 u∈U*，其候选集合不含 z，故 k₀≤t−1。若缺失 z<u₀，向下延至 Min(U) 的对偶论证相同。因此 (b) 推出 (c)。(c) 与 (d) 只是结构的展开。

这是非循环、非空泛、直接查关系的精确保持条件，不要求事先知道任何协方差或配对概率。若还要求它产生非链递降，必须另检 Q 非链。例如 D、I、U 任一含不可比对即可保证 Q 非链。该条件不声称所有相关偏序均满足，也不声称其适用于非平凡自治链缩短。

## 3. 自治链：固定 rank 删除与平均 rank 删除

设 C={c₁<⋯<c_m} 是 P 的自治链：每个外部点与 C 的关系要么全在其下、要么全在其上、要么与全链不可比。设外部三类集合为 D_C、U_C、I_C，t=|I_C|，m≥2。

删除固定 rank j 的 c_j 后，把幸存链规范重标为 c′₁<⋯<c′_{m−1}，得到同一抽象偏序 Q=P_{m−1}。对 L∈Ext(Q)，定义

a₀=max pos_L(D_C)，空时0；b₀=min pos_L(U_C)，空时|Q|+1。

把 c′₀、c′_m 仅作为位置分别为 a₀、b₀ 的哨兵，则

w_j(L)=pos_L(c′_j)−pos_L(c′_{j−1})，1≤j≤m。

内部 rank 是两侧相邻幸存克隆的位置差；j=1 时下边界必须用最后外部前驱；j=m 时上边界必须用最早外部后继。除相应外部集合确实为空外，不能把端点直接换成0或|Q|+1。

### 命题 AC-1（固定 rank 的锐范围，已证）

对每个固定 j，min w_j=1、max w_j=t+1。若 t>0，该权重一定非常数；若 t=0，w_j≡1。

证明：它是 IW-3 的特例。若 j>1，最近前一幸存克隆是 x 的极大前驱且与全部 I_C 不可比；若 j=1，下一幸存克隆是极小后继且与全部 I_C 不可比。因此 k₀=0。最大值仍为t+1。也可把全部 I_C 安排在选定插槽中实现最大，把该槽留空实现最小。

m≥2 不能删去：m=1 时没有任何幸存克隆，上述最小值可以大于1。

### 命题 AC-2（平均 rank 的精确密度，已证）

令 K(L) 为外部 D_C/U_C 边界之间的 I_C 点数。由于窗口中恰有 m−1 个幸存克隆，

Σ_{j=1}^m w_j(L)=b₀−a₀=m+K(L)。

固定 rank 删除产生的规范化 Q 分布均使用同一归一化常数 μ=e(P_m)/e(Q)，但密度分别为 w_j/μ。不同 rank 删除得到的抽象偏序Q彼此同构，因而δ(Q)相同；其由P均匀扩张推前的分布却不同，不能用选择删除rank来改变δ(Q)，也不能把各rank的推前法则当成相同。若在均匀 P_m 扩张中独立均匀选删除 rank，再规范重标，则混合分布的相对 Q 均匀密度为

(m+K(L))/(m+E_Q K)。

证明：每个固定 rank 删除后的偏序均与 Q 同构，所以 E_Q w_j=μ；求和得 mμ=m+E_QK。平均密度即得。

完全外部事件 E（只涉及 P\C 的点）在每个删除 rank 下拉回为同一 P 事件，故

Pr_{P_m}(E)−Pr_Q(E)=Cov_Q(1_E,K)/(m+E_QK)。

还可作更强的条件化核对：固定外部扩张 S，合法窗口中有K个外部点；Q的全部幸存克隆交错法一一对应把K写成m个非负整数的弱组成（有序m元非负整数向量），条件分布均匀。第j段的w_j是该分量加1。因此

E_Q[w_j|S]=(m+K(S))/m，
Cov_Q(1_E,w_j)=Cov_Q(1_E,K)/m。

所以对完全外部事件，任意固定删除rank的协方差符号实际上相同；平均rank并没有改变其偏差。该条件化结论仅用于完全外部可测事件，不能用于含链rank事件。

但含链 rank 的事件不能照搬上式。对 z∈I_C、1≤r≤m−1，记

a_r=Pr_{P_m}(c_r<z)，b_r=Pr_Q(c′_r<z)。

则准确式是

((m−r)/m)a_r+(r/m)a_{r+1}
=b_r+Cov_Q(1_{c′_r<z},K)/(m+E_QK)。

理由：删掉原链前 r 个 rank 中任一个时，Q 的第 r 位来自原第 r+1 位；删其余 m−r 个 rank 时来自原第 r 位。这是相邻 rank 的凸插值，不是一个固定原配对概率。

因此即使 K 恒定，使平均删除分布均匀，或使所有完全外部配对概率完全保留，也不能推出含链配对概率保留或 δ 非增。两相邻 a 值若位于不同阈值区间，插值可能落入 [1/3,2/3]。这里仅指出代数障碍，不声称该机制已经构造了原猜想反例。

### 平均 rank 的结构收益及边界

在外部偏序 R=P\C 中，用 D_C、U_C、I_C 定义与 IW-3 相同的 k₀，则

min K=k₀，max K=t。

因为 K 只依赖外部次序；任何外部扩张都能在其合法窗口插入 m−1 个克隆。因此平均 rank 的权重比是

R_av=(m+t)/(m+k₀)，

可明显优于固定 rank 的 t+1。对完全外部配对可使用下一节的比值界；它不控制相邻 rank 插值。

特别地，若外部关系直接满足 D_C<I_C<U_C，即

P=D_C ⊕ (C ⊔ I_C) ⊕ U_C，

则 K≡t，所有完全外部配对概率在链缩短下完全相同。固定 rank 的 w_j 在 t>0 时仍然非常数，不能把这两条结论混同。

## 4. 阈值控制：精确 odds 界、TV 界与不可省略的 slack

设任一上述加权模型的权重满足 0<A≤w≤B，R=B/A≥1。对事件 E，令 p=Pr_P(E)、q=Pr_Q(E)。由条件均值属于[A,B]，有锐事件界

qA/[qA+(1−q)B] ≤ p ≤ qB/[qB+(1−q)A]，

等价地，

p/[R(1−p)+p] ≤ q ≤ Rp/[1−p+Rp]。

这些界在仅知道[A,B]、不增加偏序结构信息时是最优的：让权重在E、¬E上分别取两个端点即可达到。

若 p<1/3，要仅凭该比保证 q<1/3，一个充分且对该区间信息最优的条件是

p<1/(1+2R)。

若 p=1/3−ε，ε>0，等价于

R<(2+3ε)/(2−6ε)。

每一个要保留的旧不可比对 {u,v} 都须选取它在 P 中的稀有方向，记其概率 p_{uv}<1/3、slack ε_{uv}=1/3−p_{uv}，并满足自己的该条件。若 Q 非链，定义待保留旧配对的最小 margin

ε_min(P;Q)=min_{{u,v}⊆Q,u∥v} ε_{uv}，β_{P;Q}=max_{{u,v}⊆Q,u∥v}p_{uv}=1/3−ε_min(P;Q)。

统一条件为 R<(2+3ε_min)/(2−6ε_min)，等价于 β_{P;Q}<1/(1+2R)。不能只说“P 不平衡”而不写 slack；对固定有限反例 ε_min>0，并不意味着存在跨所有反例的统一正下界。

若 Q 非链，且定义

δ(P)=max_{u∥v} min(Pr_P(u<v),Pr_P(v<u))=β<1/3，

则 β<1/(1+2R) 足够保证 δ(Q)<1/3。这里只用了所有 Q 旧配对稀有方向的概率≤β。更精细时可逐对使用 p_{uv} 及其实际条件均值，而无需统一β。

注意：已知 β<1/3 而不知道 ε=1/3−β 的统一正下界时，任何固定 R>1 都不能由上述界给普适保持。

TV 的精确式及仅由比得到的锐界为

TV(ν,Unif_Q)=(1/2)E_Q|w/E_Qw−1|
≤(√R−1)/(√R+1)。

故若全部待保留方向的 margin 至少 ε，且右侧严格小于ε，也足够。该充分条件比直接事件 odds 界稍弱。TV 锐界可由给定均值μ时凸性估计 E|w−μ|≤2(B−μ)(μ−A)/(B−A)，再对μ∈[A,B]最大化得到，极值在μ=√(AB)。R=1时按连续极限取0。

对自治链固定 rank，R=t+1。t≥1时统一条件变成 β<1/(2t+3)≤1/5；它对个别很稀有配对可能有用，但不足以处理一般δ<1/3的假想反例。若再结合某个高于该阈值的已知一般δ下界，这一全局充分条件甚至不可能被相关非链实例满足。本文件不把它包装成有适用实例的一般反例递降定理，也不在此调用或核验外部δ下界。

对平均 rank 的完全外部配对，可把R换成R_av；当m大而t固定时它接近1，因此给定正 slack 后可有实际外部配对控制，但含链配对仍必须另行处理。

## 5. 常用协方差符号假设的精确反例

取

P：d<c₁<c₂，另加孤立点b。

C={c₁,c₂} 是长度2的自治链；删固定 rank 1，即x=c₁，得

Q：d<c₂，另加孤立点b。

选完全外部事件 E={b<d}，其两点均不在自治块C内。Q的三条均匀扩张与插回c₁的权重为

- d c₂ b：w₁=1，E为假；
- d b c₂：w₁=2，E为假；
- b d c₂：w₁=1，E为真。

因此

Pr_Q(E)=1/3，E_Qw₁=4/3，E_Q(1_Ew₁)=1/3，
Cov_Q(1_E,w₁)=−1/9，
Pr_P(E)=1/4。

这严格否定了“若旧事件在P中概率<1/3，那么其与插入权重协方差非负”的假设，而且事件完全在自治块外、Q非链、删除rank及边界均无歧义。

对同例的平均 rank，三条扩张的 K 分别为1、1、0，故Cov_Q(1_E,K)=−2/9，分母m+E_QK=8/3，仍给出1/4−1/3=−1/12。因此平均 rank 也不能拯救该符号假设。

符号也并非一律非正。例如P为长度a的链A与长度3的链c₁<c₂<d的不交并，自治块仍为{c₁,c₂}，删c₁，选完全外部事件E={A的最大点<d}。直接按最后一个点来自哪条链计数，有

p_P=3/(a+3)，p_Q=2/(a+2)，E_Qw₁=(a+3)/3，
Cov_Q(1_E,w₁)=a/[3(a+2)]>0。

a≥7时p_P也严格小于1/3。因此即便限制到P中的稀有完全外部事件，协方差的正负皆可发生。

这些例子只反驳保持机制的符号假设；它们不是1/3–2/3猜想的反例。

## 7. 尚未得到的结论

- 没有证明任意自治链缩短使δ非增；另一路已给出相反方向的具体检验，因此不能把此处密度公式当成该命题的证明。
- 没有证明任意δ(P)<1/3、Q非链时必可选某删除点保持δ(Q)<1/3。
- 没有为含链rank的相邻插值提供普遍阈值保持定理。
- 没有解原猜想，也没有做全局结构分类。

真正可直接复用的承重工具是IW-1至IW-4、固定/平均rank分布的准确区分、以及显式依赖实际slack的权重比界。
