- **原命题 H：已反驳。** 二元反链基底、长度 `(1,2) → (2,6)`，有 `δ: 1/3 → 13/28`。新增元素对 `A₂,B₅` 的两个方向扩张计数为 `15/28` 与 `13/28`。
- **不是单位块或二块形式的唯一现象。** `(2,3) → (4,9)` 有 `δ: 2/5 → 70/143`；连通的 N 基底 `(1,2,1,1) → (2,6,1,1)` 有 `δ: 4/9 → 1/2`，新增对 `B₆,C₁` 的计数为 `56/112` 与 `56/112`。

## 1. 固定操作和量词

基底 P 是有限有标签偏序，标签为 `0,...,n−1`，至少有一对不可比元素。长度向量 `ℓ∈Z_{≥1}^n`。自主链膨胀 P(ℓ) 的元素为 `(v,i), 1≤i≤ℓ_v`：同块依下标成链；不同块 u,v 的全部元素之间具有基底关系 `u<v`；基底不可比时全部跨块元素不可比。

按标签字典序取第一对不可比元素 `(x,y), x<y`。本轮始终采用唯一规则 U：

- `ℓ′_x = 2ℓ_x`
- `ℓ′_y = 3ℓ_y`
- 其余 `ℓ′_v = ℓ_v`

两块同时、非对称地改变；测试后没有改选规则或见证块。

对含不可比对的有限偏序 Q，定义

`δ(Q) = max_{u∥v} min{Pr_Q(u<v), Pr_Q(v<u)}`，

概率均来自全部线性扩张上的均匀分布。

**原命题 H：** 对每个上述 P 和每个正整数向量 ℓ，均有

`δ(P(U(ℓ))) ≤ δ(P(ℓ))`。

反控输入本身确实满足 `δ<1/2`。它们没有被称作 `δ<1/3` 的假想反例，也没有用空前件样本作条件推断。

## 2. 最小精确反控：所有新跨块对

取基底 `P={A∥B}`、标签 A=0、B=1，长度 `(1,2)`。三个扩张为 `ABB, BAB, BBA`。原有两对的概率为 `1/3,2/3`，因此 `δ=1/3`。

规则 U 给出长度 `(2,6)`。扩张等价于含 2 个 A、6 个 B 的字，数量为 `binom(8,2)=28`。以下列出**全部 12 个跨块个体对**；块内全为可比对，无需选取不可比见证。

| 对 | Aᵢ 在 Bⱼ 前的数量 / 28 | 较小方向概率 |
|---|---:|---:|
| A₁,B₁ | 7/28 | 1/4 |
| A₁,B₂ | 13/28 | 13/28 |
| A₁,B₃ | 18/28 | 5/14 |
| A₁,B₄ | 22/28 | 3/14 |
| A₁,B₅ | 25/28 | 3/28 |
| A₁,B₆ | 27/28 | 1/28 |
| A₂,B₁ | 1/28 | 1/28 |
| A₂,B₂ | 3/28 | 3/28 |
| A₂,B₃ | 6/28 | 3/14 |
| A₂,B₄ | 10/28 | 5/14 |
| A₂,B₅ | 15/28 | 13/28 |
| A₂,B₆ | 21/28 | 1/4 |

故 `δ=13/28>1/3`，差为 `11/84`。`A₂,B₅` 的 A₂ 与 B₅ 均超出旧长度，不是只检查旧块代表。`A₁,B₂` 也是极值，但它是原有下标的概率变化，不能拿它冒充新增元素对。

无单位块的独立反控为 `(2,3)→(4,9)`：扩张数 `10→715`，δ 为 `2/5→350/715=70/143`。全部 6 个旧跨块对、36 个新跨块对均存于数据文件并经独立显式枚举复核。

反向的全称单调性也不成立：`(1,1)→(2,3)` 给出 `1/2→2/5`。因此这个更新既非 δ 单调增加，也非 δ 单调减少。

## 3. 非对称连通基底反控，以及跨越未更新块的新增见证

基底 N 有标签 `A=0,B=1,C=2,D=3`，严格关系恰为

`A<C, A<D, B<D`。

可比图与不可比图均连通。所选对仍是 A,B。

输入 `(1,2,1,1)` 有 9 个扩张。不可比块对只有 A-B、B-C、C-D，各自最大平衡度为

- A-B：`4/9`
- B-C：`1/3`
- C-D：`1/3`

故旧 δ 为 `4/9`。U 给出 `(2,6,1,1)`，有 112 个扩张；三组最大值为

- A-B：`13/28`（原始计数 `60/112` 与 `52/112`）
- B-C：`1/2`，由新增元素对 `B₆,C₁` 实现
- C-D：`1/4`

全局新 δ 为 `1/2`。这也说明，单独分析两个被加长块之间的概率会漏掉**被加长块与未加长块**之间更强的新增见证。

### 对关键 112 与 56 的独立手算

更一般地，N 上长度 `(a,b,1,1)`：

- 若 `C<D`，线性扩张是链 `A^a C` 与链 `B^b` 的交错，数量 `binom(a+b+1,a+1)`。
- 若 `D<C`，D 必在全部 A、B 后且 C 随后，数量 `binom(a+b,a)`。

故总数

`E(a,b)=binom(a+b+1,a+1)+binom(a+b,a)`。

要求 `B_b<C`，在上述两类中分别有 `binom(a+b,a)` 个，因此

`Pr(B_b<C)=2 binom(a+b,a)/E(a,b)=2(a+1)/(2a+b+2)`。

当 `(a,b)=(2,6)`，有 `E=84+28=112`、分子 `28+28=56`。其精确平衡来自 `b=2a+2`。这是锁定更新在新长度上命中离散平衡阈值的具体机制，并不需要任何极限论证。

## 5. 修正版 R：同一操作的精确局部概率与定量障碍（已证）

这里的修正是输出定量局部误差界，不加一个导致保持性自动成立的 `δ=1/2` 假设，也不换构造。结构限制为确实非空的二块基底 `A∥B`，权重 a,b 为任意正整数。

### R1：全部元素对的精确公式

对每个 `1≤i≤a, 1≤j≤b`，设 `N=a+b, k=i+j−1`，则

`Pr(A_i<B_j) = [Σ_{r=max(i,k−b)}^{min(a,k)} binom(k,r)binom(N−k,a−r)] / binom(N,a)`。

**证明。** 全部扩张对应在 N 个位置中任选 a 个 A 位置。`A_i<B_j` 等价于前 k 个位置中至少有 i 个 A。按前 k 位 A 的数量 r 分类即得。公式对每个个体对成立，允许用完整概率矩阵检查任何指定有限候选菜单；并非混合后挑见证。

### R2：显式误差上界

对任意正整数 a,b，

`0 ≤ 1/2−δ(C_a ⊔ C_b) ≤ min(a,b)/(2(a+b))`。

特别地，同一个一步 U 满足

`δ(C_{2a}⊔C_{3b}) ≥ 1/2−min(2a,3b)/[2(2a+3b)]`。

这是一条精确有理数不等式，未声称总是尖锐。

**证明。** 先看 `p_j=Pr(A_1<B_j)`，添加边界 `p_0=0,p_{b+1}=1`。由首个 A 的位置，

`p_j=1−binom(N−j,a)/binom(N,a)`，

且相邻差为

`p_j−p_{j−1}=binom(N−j,a−1)/binom(N,a) ≤ a/N`。

因此从 0 到 1 的这个单调网格必有一个实际元素下标 `1≤j≤b`，使 `|p_j−1/2|≤a/(2N)`：取跨过 1/2 的两个相邻网格点中较近者。边界 0、1 不会比相邻的实际点更近，因为 `0<p_1` 且 `p_b<1`。于是 δ 至少为 `1/2−a/(2N)`。交换 A,B 得 b 版本，取较强者。证毕。

### R3：锁定更新的迭代速率

对**每个**初始 a,b≥1 与**每个**整数 t≥0，按本轮固定 U 反复作用，长度为

`a_t=2^t a, b_t=3^t b`。

R2 立即给出

`0 ≤ 1/2−δ(C_{a_t} ⊔ C_{b_t}) ≤ a·2^t/[2(a·2^t+b·3^t)] ≤ (a/(2b))(2/3)^t`。

故 δ 趋于 1/2；而最大不可比度 `Δ=max(a_t,b_t)` 趋于无穷。此处 Δ 无界**伴随平衡度逼近 1/2**，不会产生所需的统一 `δ≤c<1/2` 放大家族。

更精确地，对固定 `0≤c<1/2`，一旦

`(3/2)^t(b/a)>2c/(1−2c)`，

上述下界已保证 `δ>c`。

### R4：H 失败的无限族，不靠无反例搜索

输入 `a=1,b` 为任意正偶数。单个 A 的 b+1 个位置等可能，故

`δ(C_1⊔C_b)=1/2−1/[2(b+1)]`。

U 输出 `(2,3b)`。R2 给出

`δ(C_2⊔C_{3b}) ≥ 1/2−1/(3b+2) > 1/2−1/[2(b+1)]`，

因为 b>0 时 `3b+2>2b+2`。所以不仅 `(1,2)`，而是**每个正偶数 b** 都严格违反 H。

## 6. 可迁移机制与精确 gap

1. **长度更新不保持均匀扩张测度。** 把旧字中的 A/B 替换成连续重复字，只覆盖新扩张中的一个特殊子集；不能借此推出全体均匀新扩张的方向概率保持。
2. **不对称增长仍会产生离散半概率网格。** 在二块族中，增长比 `(3/2)^t` 足以让首个较短块元素与长块下标形成越来越细的跨半概率网格；不是“多块一起增长就绕开单块逼近 1/2”。这里给出了该固定操作自己的证明，没有改回单块长链操作。
3. **全个体配对要求实质重要。** N 例的最大新见证跨 B-C，其中 C 没有被更新；不能只追踪被更新的 A-B。
4. **尚缺的精确内容：** 对一般基底 P，不可比块的相对交错受其余块影响，R1 的二块均匀超几何公式通常失效。若要沿同一 U 继续研究，必须控制实际扩张测度下全部跨块概率网格的跳幅及权重，而不是把二块公式直接套用；本轮未证明这种控制。
5. **没有推出关于假想反例的结论。** `δ<1/3` 前件没有样本，未据此提出“若 P 是反例则 U 保持反例”的实验性断言。本文只反驳无条件 H，并证明局部定量障碍。
