# 固定外部、单块自主链放大：独立证明审核

结论：所给证明路线成立，未发现下界或单射漏洞。证明完全自足，不使用 Aires 的结果。此处只审核这个固定基底的单块命题，不研究原猜想或分类，也不声称文献新颖性。

## 1. 精确定义与结论

令 P 为固定有限偏序集，x∈P。这里 P−x 指诱导子偏序；删除 x 不删除原有元素间已成立的传递比较。令

- D={z∈P:z<x}（严格下集）；
- U={z∈P:x<z}（严格上集）；
- S={z∈P:z 与 x 不可比}，m=|S|≥1。

把 x 替成有标签的链 C_k=(c₁<⋯<c_k)，k≥1。每个 d∈D 小于所有 c_i，每个 u∈U 大于所有 c_i，每个 s∈S 与所有 c_i 不可比。所有外部元素及其比较关系均保持不变。所得偏序记为 P_k。

对有限偏序 Q，e(Q) 是其线性扩张数，约定 e(∅)=1。所有子集均取诱导子偏序。定义

A=e(P−x)/(e(D)e(S)e(U)),
η_k=A m/(k+m),

以及通常的平衡常数

δ(Q)=max_{a∥b} min{Pr(a<b),Pr(b<a)},

其中概率是均匀随机线性扩张中的先后概率。

**已证定理。** 对每个 y∈S，只要 η_k≤1/2，就存在确定的 i=i(k,y)∈{1,…,k}，满足

min{Pr(c_i<y),Pr(y<c_i)} ≥ 1/2−η_k/2。

因此

δ(P_k)≥1/2−A m/[2(k+m)]，只要 k≥m(2A−1)，

从而 δ(P_k)→1/2。这里 P 和全部外部结构固定，常数 A、m 不随 k 改变；没有得到对变化基底的统一结论。所选 i 不依赖随机扩张，但通常依赖 k，不能理解为在所有 k 中固定同一个链位置。

## 2. 分母下界的完整核验

选择任意 D 的线性扩张 L_D、S 的线性扩张 L_S 和 U 的线性扩张 L_U。把 L_S 与固定链 C_k 任意交错，再在前后分别连接 L_D、L_U，得到

L_D | shuffle(L_S,C_k) | L_U。

这个序列始终是 P_k 的线性扩张。关键是不存在任何需要从后面的块指向前面的块的关系：若 s<d<x，则 s∉S；若 x<u<s，则 s∉S；U 也不可能在 D 之前有偏序比较。可能存在的 D→S、S→U 或 D→U 比较全部被此块顺序满足。C_k 与 S 不可比。

这些选择产生的有标签序列彼此不同：投影到 D、S、U 可恢复所选子扩张，投影到 S∪C_k 可恢复交错。故

e(P_k)≥e(D)e(S)e(U) binom(k+m,m)。              (1)

相同的块连接在没有 clone 的 P−x 中也有效，所以 A≥1。D 或 U 为空不影响论证。

## 3. 固定外部扩张后的删除映射确为单射

固定 L∈LE(P−x)。考虑所有删除 C_k 后等于 L 的 P_k 线性扩张 E。把 E 中的 D∪U 元素删去，得到 S∪C_k 上的序列 T。

**单射理由。** L 已经确定所有外部元素两两之间的相对次序；T 确定 clone 与 S、clone 与 clone 的相对次序。剩下唯一尚未由 L 或 T 指定的类型是 clone 与 D/U，而它们全部由偏序强制：每个 D 元素在所有 clone 之前，每个 U 元素在所有 clone 之后。因此 (L,T) 确定每一对标签的相对次序，至多恢复一个总序列 E。

这说明删除 D/U 不会因遗忘它们在某个 S-gap 内的位置而合并两个有效插法。若相应位置无法同时满足固定 L 和上述强制关系，则 T 没有原像；这只会减少插法数。D–S、S–U 的额外关系不破坏单射。

## 4. J 的单点概率上界

固定 y∈S。令 J 是在随机扩张中排在 y 之前的 clone 数，所以 J∈{0,…,k}。

仍固定外部扩张 L。令 L 投影到 S 后，y 前有 r 个 S 元素，0≤r≤m−1。在删除 D/U 后的序列 T 中，若 J=j，则：

- y 前的 r 个固定次序 S 元素与 j 个固定次序 clone 有 binom(j+r,r) 种交错；
- y 后的 m−1−r 个固定次序 S 元素与 k−j 个固定次序 clone 有 binom(k−j+m−1−r,m−1−r) 种交错。

由于上一节的单射，固定 L 且 J=j 的原扩张数至多为

N_{L,j}≤binom(j+r,r) binom(k−j+m−1−r,m−1−r)。       (2)

令 a=j+r，b=k−j+m−1−r，t=m−1。右侧是 Vandermonde 展开

binom(a+b,t)=sum_q binom(a,q)binom(b,t−q)

中的 q=r 项；因此

N_{L,j}≤binom(k+m−1,m−1)。                       (3)

对所有 e(P−x) 个 L 求和，并用 (1) 得

Pr(J=j)
≤e(P−x) binom(k+m−1,m−1)/e(P_k)
≤[e(P−x)/(e(D)e(S)e(U))]·m/(k+m)
=η_k。                                         (4)

此界包含 j=0 和 j=k，且与 y 的选择无关。

## 5. 离散中位数跨越给出平衡 clone

写 p_i=Pr(c_i<y)=Pr(J≥i)，1≤i≤k。于是

p₁≥1−η_k，p_k≤η_k，p_i−p_{i+1}=Pr(J=i)≤η_k。

若 η_k≤1/2，则 p₁≥1/2≥p_k。若某个 p_i=1/2，结论立即成立。否则有相邻两项 p_i>1/2>p_{i+1}，它们到 1/2 的距离之和等于 p_i−p_{i+1}≤η_k，故其中至少一个距离不超过 η_k/2。选此确定的指标，便有

min(p_i,1−p_i)=1/2−|p_i−1/2|≥1/2−η_k/2。

这也说明原先使用 η_k<1/2 的条件可放宽为 η_k≤1/2。等号情形以及 k=1 不会留下端点漏洞：若此时没有相邻跨越，就已经有 p_i=1/2。

因为 clone 与 y 始终不可比，以上确实给出 δ(P_k) 的下界。再用 δ(P_k)≤1/2，即得收敛结论。

## 6. 显式 1/3 阈值，严格与非严格区分

设 T=m(3A−1)。这是充分阈值，不是每个基底的必要阈值。

- 若 k≥T，即整数 k≥ceil(T)，则 η_k≤1/3，因此至少一对的平衡度≥1/3。
- 若 k>T，即整数 k≥floor(T)+1，则 η_k<1/3，因此至少一对的平衡度>1/3。

若 T 非整数，两种整数阈值相同；若 T 是整数，第二种阈值比第一种大 1。这些条件自动保证 η_k≤1/2。

不能从 η_k=1/3 一般推出严格大于 1/3：取 P 为二点反链 {x,y}，k=2 时 P_k 为二链加一个不可比点，δ(P_k)=1/3。

## 7. 误差阶的简单精确检验

仍取二点反链 {x,y}。此时 m=A=1；P_k 的 k+1 个线性扩张对应 y 的 k+1 个插入位置，所以 J 在 {0,…,k} 上均匀分布，且

δ(P_k)=floor((k+1)/2)/(k+1)。

偶数 k 时，这等于 1/2−1/[2(k+1)]，正好达到本定理的下界。因此在该固定基底上，所有 k 的误差一般不能改成 o(1/k)。这只是边界与锐性核验，不涉及文献新颖性。

## 8. 原标签精确计算审核

脚本 verify.py 中每个 clone 都有独立标签和独立 bit，没有使用同构商、轨道压缩或加权链替代。

1. 对下面 8 个基底，在 k=1,2,4 逐条枚举全部原标签线性扩张。
2. 直接检查每个 (外部 L, 删除 D/U 后 T) 键无碰撞。
3. 对每个 L、每个 y、每个 j 检查 (2) 与 (3)。
4. 显式构造下界中的所有块连接序列，检查合法且不重复。
5. 用独立的原标签理想动态规划复核线性扩张总数，并精确计算 J 分布和所有不可比对概率；测试 k=1,2,4,8,16 及两个 1/3 阈值，最大 k=83。
6. 检查全部概率界、定理界及阈值后果，所有断言通过。

基底与部分精确数据如下；全部生成边、D/U/S、J 直方图和最佳对在 exact_results.json 中。
