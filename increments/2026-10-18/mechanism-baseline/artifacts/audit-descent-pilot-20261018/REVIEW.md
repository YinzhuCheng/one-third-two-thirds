# 自主链块单步缩短：独立审稿

日期：2026-10-18。审查范围仅为同一操作 `ℓ → ℓ−e_i` 的递降机制；不研究或声称推翻原猜想，不新增第三版假设。

## 审稿结论先行

1. **H0 被严格反控。** 当至少两个自主链块可缩短时，未必有任何单块缩短能使 δ 非增。`Q=A₂, ℓ=(3,2)` 已足够：δ 为 2/5，两个允许后继均为 1/2。
2. **一次修订 H1 也被严格反控。** 即使 `Q=A₂` 且两长度皆为偶数且至少为 2，`ℓ=(8,4)` 的 δ 为 14/33，两个允许后继的 δ 分别为 31/66、27/55，均严格增加。
3. **两个无限反控族的证明成立。** 一是 `(2k+1,2k)`，两后继均为 1/2；二是满足 `(a+1)(a+2)=2u²` 的 `(a,2)`。第二族块长比无界，并含无穷多个偶偶实例，故障碍不能仅归结为奇偶共振或相近块长。
4. 这些都是**辅助递降断言的反控**，且均满足 δ≥1/3。它们不是原猜想的反例；也不检验假设 δ<1/3 的条件保持性。当前没有给出可接受的第三版单步递降定理。

## 1. 定义和量词

令 `P(Q,ℓ)` 是将 Q 的每个元素 i 替换为长度 ℓ_i≥1 的自主链的偏序：块内依链序，若 i<_Q j 则第 i 块所有元素均小于第 j 块所有元素。令

`p_P(x,y)=Pr[x<y in a uniformly chosen labeled linear extension]`，

`δ(P)=max_{x∥y} min(p_P(x,y),1−p_P(x,y))`。

以下取 Q 为两点反链 A₂，写两个链块为 `A₁<⋯<A_a` 和 `B₁<⋯<B_b`。所有 a·b 个跨块对都不可比，块内对的平衡值为零。

- **H0（初版，已否定）**：对每个 Q、每个 ℓ，若 `#{i:ℓ_i≥2}≥2`，则存在某个 `i`（ℓ_i≥2），使 `δ(P(Q,ℓ−e_i))≤δ(P(Q,ℓ))`。
- **H1（producer 固定的一次修订，已否定）**：对每个偶数 a,b≥2，存在一个允许缩块，使 `δ(A_{a−1}+A_b)≤δ(A_a+A_b)` 或 `δ(A_a+A_{b−1})≤δ(A_a+A_b)`。

H1 的“或”是在每个输入实例之后选缩块；反控须同时排除两条后继。本文每个反控均这样检查。这里 A_a+A_b 表示两个互不比较的链的并，不是序和。

删除同一自主链的任一元素，保持其余元素次序后，都与长度缩一同构。因此这里没有因删除块内不同位置而遗漏其他同类操作。

## 2. 独立计算方法与结果

审查器 `independent_labeled_extensions.py` 不导入 producer 的代码，不使用 producer 的链状态 DP 或 shuffle 公式。它将每个原扩张标签 `(块号,链内秩)` 单独建模，用前驱 bit mask 递归生成全部合法原标签线性扩张。每到一个完整扩张，记录所有原标签跨块对的先后关系；先构造全对计数，最后取最大平衡值。

`check_requested_cases.py` 执行以下核验；每例全对的整数分子、总扩张数、约分概率和 balance 均保存在 `requested_cases_full_labeled_counts.json`。

位置公式如下：令 t=i+j−1，在前 t 个位置有至少 i 个 A 等价于 `A_i<B_j`，故

`p(A_i<B_j) = [Σ_{k≥i} C(t,k) C(a+b−t,a−k)] / C(a+b,a)`，

其中越界二项式视为零。这是直接按 A 的位置计数完整二进制字，并非 producer 公式的调用。

## 3. 最小反控 (3,2)：全对整数计数

10 个扩张中，以下矩阵第 i 行、第 j 列为 `#{A_i<B_j}`：

```
6 9
3 7
1 4
```

全对 balance 最大为 4/10=2/5。

缩为 (2,2) 时扩张数 6，计数矩阵为

```

1 3
```

存在概率 1/2，所以 δ=1/2。

缩为 (3,1) 时扩张数 4，计数列为 `(3,2,1)`，同样 δ=1/2。H0 的两个可选索引至此都已排除。

## 4. 连续长度族：全对最大值证明

### 定理

对每个整数 n≥1，两个独立链长度为 `(n+1,n)` 时，

`δ(A_{n+1}+A_n)=n/(2n+1)`。

### 证明

写 `p_{r,s}=Pr(A_r<B_s)`。先取对角 `r=s∈{1,…,n}`，令 t=2r−1。

从 n+1 个 A 中指定一个特殊 A。考虑前 t 个位置：

- 特殊 A 不在其中时，前 t 位是 n 个普通 A 与 n 个 B 的对称奇数样本，A 严格多数的概率为 1/2。
- 特殊 A 在其中时，剩余 t−1=2r−2 位是对称偶数样本；达到至少 r 个总 A 的概率为 `1/2 + 1/2·Pr[普通 A 与 B 各 r−1 个]`。

特殊 A 在前 t 位的概率为 t/(2n+1)。因此

`p_{r,r} = 1/2 + (1/2)·C(n,r−1)² / C(2n+1,2r−1)`。

令 s=r−1。Vandermonde 恒等式和二项系数的对数凹性给出

`C(2n,2s)=Σ_{j=0}^{2s} C(n,j)C(n,2s−j) ≤ (2s+1) C(n,s)²`。

这里每个对称乘积至多为中心乘积，越界项为零。又

`C(2n+1,2s+1)=[(2n+1)/(2s+1)]C(2n,2s)`，

故 `C(n,s)²/C(2n+1,2s+1)≥1/(2n+1)`，即

`p_{r,r}≥(n+1)/(2n+1)`。

这不只是两个展示对，而能控制全部 a·b 个跨块对：

- 若 r≤s，则因 `B_r≤B_s`，有 `p_{r,s}≥p_{r,r}≥(n+1)/(2n+1)`。
- 若 r≥s+1，把一个完整扩张反转并将每条链的秩反转，得到概率恒等式
  `p_{r,s}=1−p_{n+2−r,n+1−s}`。
  右侧新秩满足 `n+2−r≤n+1−s`，所以 `p_{r,s}≤n/(2n+1)`。

于是每个跨块对的 balance 均≤n/(2n+1)。而 `p_{1,1}=(n+1)/(2n+1)`，取到上界。证毕。

### 反控推论

令 n=2k，k≥1，则原长度 `(2k+1,2k)` 的 δ 为 `2k/(4k+1)<1/2`。

- 缩第一块得到 `(2k,2k)`：交换两条等长链使 `Pr(A₁<B₁)=1/2`。
- 缩第二块得到 `(2k+1,2k−1)`：两长度都为奇数，反转全部扩张并反转链秩会固定中点对 `(A_{k+1},B_k)` 的标签而交换其先后，故该对概率为 1/2。

因此两个后继的 δ 均严格增加至 1/2。

**重要边界：** 不能把这句话写成对所有连续长度 `(n+1,n)` 都是局部极小。比如 `(4,3)` 的 δ=3/7，而缩成 `(4,2)` 的 δ=2/5<3/7。需要 n=2k 的条件。

## 6. Pell 型无界块长比反控族

### 定理

若整数 a≥2、u≥1 满足

`(a+1)(a+2)=2u²`，

则 `(a,2)` 是单步缩短的严格局部极小：

`δ(a,2)=(u−1)/(2u)`，且 `δ(a−1,2)>δ(a,2)`、`δ(a,1)>δ(a,2)`。

### 全对原值

置 D=(a+1)(a+2)=2u²。直接按两个 B 的位置计数得

`p(A_i<B₁)=(a+1−i)(a+2−i)/D`，

`p(A_i<B₂)=1−i(i+1)/D`。

因此全部 2a 个跨块对的 balance 恰由

`min[t(t+1)/D,1−t(t+1)/D]`，`t=1,…,a`

给出。这包含全部配对，无需先猜取见证。

由 a>0 可得 `u²=(a+1)(a+2)/2<(a+1)²`，故整数 u≤a。由于 a≥2，相关解有 u≥2。于是 t=u−1 与 t=u 都合法，且

`(u−1)u/D=(u−1)/(2u)<1/2`，

`u(u+1)/D=(u+1)/(2u)>1/2`。

t(t+1) 随 t 严格增加；这两个相邻项到 1/2 的距离相等，其他项不可能更近。所以全对最大 balance 恰为 `(u−1)/(2u)`。不存在 floor 或“最近乘积对”的未处理分支。

### 缩第一块

缩成 `(a−1,2)` 后分母为 D'=a(a+1)。选 t=u−1（因 u≤a，仍然合法），令

`p'=u(u−1)/[a(a+1)]`。

必须同时验证下列两个严格不等式，而不能只验证其中一个：

1. `p'>δ`，因为 D'<D 且 u(u−1)>0；
2. `p'<1−δ`，等价于
   `(a+2)(u−1)<a(u+1)`，再等价于 `u<a+1`，已证。

于是 `min(p',1−p')>δ`，故新 δ 严格增加。这里不需要求出新偏序的全对最大值。

### 缩第二块及奇偶边界

对于长度 `(a,1)`，B 的插入位置均匀，故

`δ(a,1)=floor((a+1)/2)/(a+1)`。

- 若 a 为奇数，该值为 1/2，显然大于 `(u−1)/(2u)`。
- 若 a 为偶数，该值为 `1/2−1/[2(a+1)]`，由 u<a+1 严格大于 `1/2−1/(2u)`。

因此两种奇偶都成立，且没有把 floor 擅自去掉。

### 无界族和偶偶子族

从 `(a,u)=(7,6)` 开始用递推

`a'=3a+4u+3`，`u'=2a+3u+3`。

把 x=2a+3，则条件等价于 `x²−8u²=1`；递推正是 `(x+u√8)→(3+√8)(x+u√8)`，因此保持等式。a 严格增大且趋向无穷。直接得到

`(a,u)=(7,6),(48,35),(287,204),(1680,1189),…`。

由于 `a'≡a+1 (mod 2)`，a 的奇偶交替，所以 a=48,1680,… 提供无穷多个偶偶输入 `(a,2)`；同时 a/2 无界。这只需要构造性递推，不依赖“已经完整分类所有 Pell 解”的额外声明。

## 7. 可接受结论、不可接受跨越和剩余缺口

### 当前可接受

- H0 和指定的一次修订 H1 都严格为假。
- 连续长度无限族与 Pell 型无限族均有全对最大值证明。
- 反控不仅有近等长奇偶共振，也有偶偶和无界长度比。
- Q=A₂ 已足够反控，因此一般 Q 的复杂性不是这条无条件递降规则失败的必要原因。

### 不可从本结果推出

- 不能称这些对象为原猜想反例。
- 不能从 δ≥1/3 的样本推出或否定“若真反例 δ<1/3，则存在保持反例性质的缩块”。该条件的前件在这些样本上不成立。
- 不能用某个展示 pair 在缩块后改善/恶化替代全对最大值的控制。
- 不能以有限枚举没有发现新障碍来证明任意新修订成立。
- 不能从 δ 的严格局部极小推出所有可能递降势函数、复合操作或其他研究路线都不可能。

### 真正尚缺的承重命题

如仍想服务于最小反例归纳，必须另行提出并证明一个范围清楚的保持性定理，例如在真实假想反例类中保证某允许缩块仍留在该类；需要说明该定理用到哪些具体结构假设。当前工作没有这项证明。producer 已明确本批不再加第三版假设，也不把 δ<1/3 的空样本条件论当作实验进展。
