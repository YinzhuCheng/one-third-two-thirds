# 序和真保留与外部 pair 长度证书

日期：2026-10-18。最终 A、B 均已独立审阅 PASS，统一审稿已冻结。本文仅归档两条局部变换机制，不重包此前的槽机制成果。

## 结论概览

### A. 序和真正保留假设反例，但不增长关键局部参数

固定非链有限偏序 P，均匀有标签线性扩张下的最大 pair 平衡度记为 δ(P)。对 a,b≥0、r≥1，令 Q=C_a⊕P^⊕r⊕C_b。全部旧块内 pair 概率精确保留，跨块 pair 全可比，因此 δ(Q)=δ(P)。所以在假设 δ(P)<1/3 的前提下，这个操作确实保持严格反例。

元素总数、高度、不可比对总数可以增长；宽度与最大不可比度保持不变，不可比图的非平凡连通块类型及最大块大小也不变。不能只凭总规模增长就套用要求大宽度、大局部不可比度或大连通块的排除界。

非恒等自同构必强制出现闭区间 [1/3,2/3] 内的不可比 pair。因而可交换的同构不交并副本、可交换不可比克隆不能作为严格反例保持操作；直接交换一对对应点时，该 pair 概率就是 1/2。序和串联的前后副本不能交换，故这不否定上面的保持公式。

### B. 完全外部 pair 的链长判据可一次跳过不安全中间长度

固定自主链的完整外部偏序与比较关系，只改变该链长度。设与整条链不可比的外部元素数为 t。对任意完全外部 pair 事件 E，按合法插入窗口的外部纤维分类，其概率可写为 binomial 基中分子、分母次数至多 t 的比值。该式严格依赖“完全外部”与固定外部结构，不能直接用于含链元素的 pair。

t=2 时，严格安全条件 p(E)<1/3 或 p(E)>2/3 化为整数系数二次多项式严格为正。使用整数平方根和精确端点处理，可以直接给出所有正整数链长上的有限区间证书，再交上 1≤k<m 取得缩短目标；无需逐个扫描链长。两侧并集模式允许直接跳过不安全中间长度，同侧模式则保留当前稀有方向。

在独立含链列保持前提下，“固定外部结构的最小正链长反例”还等价于：每个更短正整数长度，均被至少一个完全外部 pair 的闭平衡整数区间覆盖。允许不同 pair 在不同长度接力覆盖；本轮提供准确覆盖证书，未证明这种覆盖不可能。

这仅提供条件性递降判据。它不保证较短安全落点存在；完全外部 pair 全安全也不自动保证含链 pair 安全，更不等于已证明全局 δ<1/3 的保持。最终结论及小 exact 结果以 B 主稿和独立审阅为准。粗尾界仅为外部多项式符号稳定的算法说明；已有单长链直接排除界更强，不能把该粗界当作新的反例排除进展。
