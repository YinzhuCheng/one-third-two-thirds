# 单一缩链、三对有限菜单的独立审查

**结论：按下述明确的全称量词，反控成立。** 这个 9 点偏序否定“指定的任意外部平衡对均可用 `{u/v, y/u, y/v}` 菜单回传”这一辅助机制。它不是原主猜想的反例，也不否定“存在某个可回传的外部平衡对”。

本审查独立从具名 Hasse 关系重建偏序，使用全标签全排列枚举、下闭集动态规划两种计数算法，并补给不依赖程序的手算证书。未修改 producer 文件。

## 1. 被审查命题及量词

令 `Bal_P(r,s)` 表示 `r,s` 不可比，且在 P 的均匀随机线性扩张中

`1/3 ≤ Pr_P(r precedes s) ≤ 2/3`。

由于反向概率互补，平衡与方向无关。被审查的强命题是：

> 对每个满足前提的 `(P,C,y)`，令 Q 为 C 缩去一个链点后的偏序；对 Q 中每个均在 C 外且均不等于 y 的平衡对 `{u,v}`，P 中 `{u,v}`、`{y,u}`、`{y,v}` 至少一对平衡。

这里的前提是：C 是长度 `m ≥ 2` 的极大自治链；C 外唯一与 C 不可比的点是 y；原偏序中所有 `{c,y}`（`c ∈ C`）均不平衡。

这个反例满足这些前提，取 `m=2`，并提供一个不能由上述菜单回传的指定平衡对 `{u,v}`。若原意含有以下额外要求，则本例不构成那些其他命题的反例：

- 要求 C 是**普通极大链**，而非极大自治链；
- 要求 u、v **二者都与 y 不可比**；本例有 `v<y`；
- 只要求**存在**一个可选的 Q 平衡对能回传；本例 `{a,b}` 在 Q 和 P 都平衡。

## 2. 完整具名偏序

点集为

`P = {u,a,b,t,v,z,c1,c2,y}`，`D={u,a,b,t,v,z}`，`C={c1<c2}`。

实际 Hasse 边恰为：

- `u<a`，`u<b`，`a<t`，`b<t`，`v<t`；
- `t<c1`，`z<c1`，`c1<c2`；
- `v<y`。

取这些边的传递闭包，不添加其他关系。特别地：

- D 的每个点都小于 c1 和 c2；
- z 在 D 内孤立；
- y 与 `{u,a,b,t,z,c1,c2}` 全部不可比，且 `v<y`。

Q 是诱导子偏序 `P \ {c1}`，保留标签 c2。由于 C 自治，这与把 C 缩为一链点等价；删去 c2 则得到外部关系相同的重标记偏序。

Producer 的 `counterexample.json` 使用另一套自然标号：

`0=u, 1=v, 2=z, 3=a, 4=b, 5=t`。

其 `rows=[56,32,0,32,32,0]`、`A=2`、`pair=[0,1]` 正好对应上述 D、`v<y` 和指定对 `{u,v}`。

## 3. 自治性、唯一外不可比点与极大性

### 自治性与唯一性

C 外每个 D 点都在 C 全部点之下，而 y 与 C 全部点不可比。因此 C 自治，且 y 是 C 外唯一与 C 不可比的点。

### 极大自治链

设一条链 T 真包含 C。y 不可能在 T 内，因此 T 必须加入非空 `S ⊆ D`。

- 若 `z ∉ S`，则 z 在 T 外，与 S 每个点都不可比，却小于 c1、c2。故 z 对 T 的关系不一致，T 不自治。
- 若 `z ∈ S`，因 z 与 D 的其他点不可比，链性质迫使 `S={z}`。这时取 `u ∈ D\S`：u 与 z 不可比，却小于 c1、c2。故 T 仍不自治。

因此没有严格更大的自治链包含 C，C 是极大自治链。程序也穷举所有含 C 的点集，独立确认唯一自治链超集就是 C。

C **不是**普通极大链，例如可扩张为 `t<c1<c2`。这一术语区别是承重条件。

## 4. 完全手算的计数证书

记 `E=D\{z}`，`R=D∪{y}`，`S=E∪{y}`。所有概率都对全标签线性扩张均匀取样。

### D 的计数

在 E 中，t 最后；此前四点为 u、a、b、v，约束仅 `u<a,b`。共有 `4!/3=8` 种，其中 `u<v` 当且仅当 u 是这四点中第一个，共 `3!=6` 种。孤点 z 有 6 个插入位置，所以

- `e(D)=6×8=48`；
- `N_D(u<v)=6×6=36`。

### R 的计数

S 的极小元为 u、v。

- 以 v 开始时，剩余是四点菱形 `u<a,b<t` 加孤点 y。共有 `2×5=10` 种。
- 以 u 开始时，剩余约束为 `a,b,v<t` 与 `v<y`。若 `t<y`，前面的 a、b、v 可任排，有 6 种；若 `y<t`，t 最后，前面 a、b、v、y 只要求 `v<y`，有 12 种。因此共有 18 种。

于是 `e(S)=10+18=28`，且 `N_S(u<v)=18`。另外 `y<u` 强制前缀 `v,y,u`，随后 a、b 任排再到 t，所以 `N_S(y<u)=2`。

插回孤点 z，各有 7 个位置，得到

- `e(R)=7×28=196`；
- `N_R(u<v)=7×18=126`；
- `N_R(y<u)=7×2=14`。

### 从 D、R 还原 P、Q

P 的扩张按 y 相对于 C 的位置分成三块：

1. `y<c1<c2`：R 的每个扩张后接 c1、c2，共 196 个；
2. `c1<y<c2`：D 的每个扩张后接 c1、y、c2，共 48 个；
3. `c1<c2<y`：D 的每个扩张后接 c1、c2、y，共 48 个。

因此

- `e(P)=196+48+48=292`；
- `N_P(u<v)=126+36+36=198`；
- `N_P(y<u)=14`；
- `N_P(c1<y)=96`，`N_P(c2<y)=48`。

Q 只有 `y<c2` 和 `c2<y` 两块，分别为 R 和 D 的扩张，故

- `e(Q)=196+48=244`；
- `N_Q(u<v)=126+36=162`；
- `N_Q(y<u)=14`；
- `N_Q(c2<y)=48`。

`v<y` 是偏序关系，所以两个偏序中 `N(y<v)=0`，反向概率为 1。

## 5. 指定见证及菜单的全部方向

|有序事件|P 的计数 / 292|Q 的计数 / 244|P 中结论|
|---|---:|---:|---|
|u 先于 v|198 / 292 = 99/146|162 / 244 = 81/122|大于 2/3|
|v 先于 u|94 / 292 = 47/146|82 / 244 = 41/122|小于 1/3|
|y 先于 u|14 / 292 = 7/146|14 / 244 = 7/122|小于 1/3|
|u 先于 y|278 / 292 = 139/146|230 / 244 = 115/122|大于 2/3|
|y 先于 v|0 / 292|0 / 244|概率 0，且可比|
|v 先于 y|292 / 292|244 / 244|概率 1，且可比|

精确阈值检验：

- Q：`244 ≤ 3×162=486 ≤ 2×244=488`，因此 `{u,v}` 平衡；反向也满足 `244 ≤ 3×82=246 ≤ 488`。
- P：`3×198=594 > 2×292=584`，因此 `{u,v}` 不平衡；反向 `3×94=282 < 292`。
- P：`3×14=42 < 292`，因此 `{y,u}` 不平衡；反向 `3×278=834 > 584`。
- `{y,v}` 可比，不是平衡对候选；即使把可比对纳入数值检查，其概率 0、1 也不在闭区间内。

所以菜单 `{u/v, y/u, y/v}` 的任何方向都无法给出 P 的平衡对。

## 8. 不能宣称什么，以及仍存在的平衡对

P 中完整的无序平衡对恰为以下五对（方向按表给出）：

- `{a,b}`：`Pr(a<b)=146/292=1/2`；
- `{a,z}`：`Pr(a<z)=142/292=71/146`；
- `{b,z}`：`Pr(b<z)=142/292=71/146`；
- `{t,y}`：`Pr(t<y)=152/292=38/73`；
- `{v,z}`：`Pr(v<z)=192/292=48/73`。

因此这个对象明确仍有平衡对。特别地，交换 a、b 是 P 和 Q 的自同构，所以二者中 `{a,b}` 的概率均为 1/2。这也直接说明“存在一种好的 Q 见证选择”并未被反驳。

本审查未作任何最小性主张，未重新分类原猜想，也未检验更大范围的候选机制。已证否定范围仅为第 1 节所列的单次缩链、指定外部见证、三对有限菜单全称命题。
