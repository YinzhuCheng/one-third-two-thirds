## 2. 记号与分类口径

S(t)=∪ₐ{cₐ,ₜₐ,…,cₐ,ₗₐ₋₁}。链和点坐标均从 0 开始。对象由保存的链长及全部跨链边确定；principal 指该实际 upset 恰有一个最小元，不能仅看阈值有几项未到链尾。

程序从已存链内边和跨链边取传递闭包，逐个找 S 内最小元，并独立核对“恰一最小元”等价于 S=↑v。只做有限关系运算，不枚举线性扩张或下理想。

分类按表中顺序互斥处理：先含空，再 both principal，再仅一侧 principal 时按 exact 均值定大小，最后 both nonprincipal。恰有 1 对均值相等且仅一侧 principal，按要求归入较小侧类：`disjoint2_1_19`，filter 索引 (13,35)，阈值 (1,4)/(0,5)，r=s=17/4；其最小元分别为 {(1,4)} 与 {(0,0),(1,5)}。

保存 K=|LE(U)| 及整数 A=ΣR_y、B=ΣR_z、C=ΣR_yR_z、D=Σmin，ℓ=min(A,B)。只用这些保存整数计算：

- T：N≤rs+m²+2m；p_T=((C+D)K−AB)/(ℓ²+2ℓK)，δ_T=Tnum/(ℓ²+2ℓK)=1−p_T。
- Cov：Cov≤m²+m；p_C=(CK−AB)/(ℓ²+ℓK)，δ_C=Cnum/(ℓ²+ℓK)=1−p_C。
- Tnum=AB+ℓ²+2ℓK−(C+D)K；Cnum=AB+ℓ²+ℓK−CK。后处理核对了这些等式与保存分子的一致性。

两条候选始终分别报告。极值选择用 Python Fraction 的任意精度有理数比较；下表的小数仅为最终展示。m=0 时压力与相对余量不定义，不参与这些极值。均值比的有限最大值也仅取两均值正的对子；恰一均值为零另记为 ∞，两均值皆零为 0/0。

## 7. 文件、复用与停止边界

本目录交付：

- `postprocess.py`：只读旧关系、阈值、exact 矩的后处理脚本；不导入或调用旧 DP，不联网，不算散列。
- `summary.json`：五类数量、对象分布、分开记录的 T/Cov exact 极值、完整对象/filter 引用、等均值特例与可恢复的小批次条目。
- `pair_labels.json`：5,073 个既有对子逐个给出 case、i、j、互斥结构标签及是否命中待审 T 假设，便于以后避免重复已有覆盖范围。
- `RESULT.md`：本报告。`postprocess_console.txt` 为后处理摘要；`write_result.py` 仅将 summary 排版为本报告。

复算本统计只需执行 `python postprocess.py`；若要同步报告排版，再执行 `python write_result.py`。两者仅写本新目录。

本报告止于现有样本的结构统计。没有补算未开始对象或未完成对子，没有提出额外推广，没有将有限抽样结果或待审证明升级为全称结论。
