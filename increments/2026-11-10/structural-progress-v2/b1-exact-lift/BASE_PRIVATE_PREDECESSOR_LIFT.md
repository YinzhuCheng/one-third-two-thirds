# Private-predecessor lift: exact original-word transfer and variable-J payment

Status: analytic candidate; independent audit requested. This is a new local research mechanism, not an originality claim. It is not whole B1/D10 payment. 

## 1. General original contract

Let P be any finite original B1: only minima a,b, a below every label other than a,b. Set R=P−{a,b}, T={v in R:v||b}, C=R−T. Assume T={x,y,z} is a three-point antichain. C may have empty T-signatures. Let A_k count the actual original LE(R) words with initial T-prefix length K=k, 0<=k<=3 (K=3 if C empty). These are unweighted R counts; complete P insertion multiplicities are K+2.

Let E be any ideal of C, all of whose points have COMPLETE T-signature {y,z}. Write m=|E|. Construct P+ by adding one label u with exactly the comparisons generated by

    a<u<x; u<C−E;

and no additional comparisons except transitive closure. In particular u||b,y,z,E. This is an induced extension of P: E is an ideal and x is below no E point, so the specified noncomparisons are consistent. No old relation is added. The new B1 has private ideal T+={u,x,y,z}, with u<x and its three actual private a-children u,y,z. Its C order is unchanged.

The main structural closure is:

**If the original seed P passes its original two-moment condition, and m<=2, then the one fixed physical pair (u,b) in P+ satisfies**

    38/(81+12m) <= Pr_(P+)(u<b) <= 5/9.

In particular m<=2 gives [38/105,5/9], strictly inside [1/3,2/3]. No new-P+ moment condition is required. No claim that these constants are sharp.

The seed moment condition is exactly

    A3 >= A2+2A1+2A0,

since its K<=3 makes mu<=4 automatic. Seed labels, topology and size are otherwise arbitrary. This is not a fixed-J template.

## 2. Degree and intrinsic-interface transport

For any degree bound d, the lift keeps Delta<=d exactly when, in addition to Delta(P)<=d,

    deg_P(b),deg_P(y),deg_P(z),deg_P(e) <= d−1 for every e in E,
    m+3 <= d.

Only these old degrees increase, each by one. New u has precisely m+3 incomparable labels: b,y,z,E. In particular these are checkable original-structure conditions, not a degree claim inherited from deletion.

Put F=Min(C), S={a,b} union T union F, and intrinsic J=union_(s in S)(P−U(s)), using strict upper sets. The lift leaves C and F unchanged and replaces S by S union {u}. Every old point outside J is above every old S point, in particular above x, hence above u. Inducedness preserves old membership in J, while u itself belongs to J+ because u is in S+. Thus

    J(P+) = J(P) union {u}

as physical induced orders. This is exact cardinal increase by one. It is why changing T escapes the reviewed same-T V2 J-lock without contradicting it.

## 3. Original-word insertion channels

Write I=#old R words with K=2 and x in the initial prefix. Write X=#old words with K=1 and x in that prefix, Y=A1−X, and J2=A2−I.

For a word counted in J2, its initial T letters are y,z. Let ell(w) be the number of consecutive E labels following those first two letters, stopping at x or the first C−E label. Define L=sum ell(w) over these actual words. Then

    0<=L<=m J2.

No freely chosen suffix distribution or equal weighting of interface cells is introduced. L is a sum over the full original R words.

The first successor of u in an old R word is the first label from {x} union (C−E). Insert u in each slot before that successor. This gives every LE(R+) exactly once; deleting u recovers both the old word and the insertion slot.

- K=0: the first C point is not in E, so one slot, new K=1.
- K=1, prefix x: one slot, new K=2.
- K=1, prefix not x: two slots, new K=2. The first C cannot lie in E because E needs both y,z.
- K=2, prefix contains x: rank(x)=1 or2. Each rank occurs equally often within the physical initial-prefix/first-C/suffix cells, so there are 3I/2 slots, all new K=3.
- K=2, prefix y,z: three slots give new K=3, and ell(w) later slots give new K=2.
- K=3: rank(x)=1,2,3 equally often; there are 2A3 slots, all new K=4.

Hence the exact new histogram is

    A0+=0,
    A1+=A0,
    A2+=X+2Y+L,
    A3+=3A2−3I/2,
    A4+=2A3.                                  (1)

All half/third coefficients below multiply divisible original counts, because the rank symmetries just described are literal permutations inside legal prefix cells.

## 4. Full original-P+ pair counts

Let N+=e(P+) and K+=#LE(P+) with u before b. After inserting u, restore the original roots with the exact new-prefix weight Knew+2. If u is inserted after j initial T letters before the first C, the number of root slots giving u<b is Knew−j. If inserted after that first C, it is zero. Summing these genuine full-word recoveries yields

    N+ = 3A0+12A3+15A2−15I/2+4L+4X+8Y,
    K+ = A0+(20/3)A3+6A2−2I+2X+3Y.             (2)

Consequently

    3K+−N+ = 8A3+3A2+(3/2)I−4L+2X+Y,           (3)
    5N+−9K+ = 6A0+21A2−(39/2)I+20L+2X+13Y >=0. (4)

The last inequality uses I<=A2. It proves the uniform upper bound 5/9 directly; the old one-way chain-private factor2 upper bound also applies because D(b)−D(u) is empty and U(u)−U(b)={x}, but is weaker here.

## 5. Uniform seed-moment closure

Suppose the old seed moment condition holds. Put

    A3=I+J2+2X+2Y+2A0+S0, with S0>=0.

In the nonnegative coordinates (I,J2,X,Y,A0,S0), the numerator K+ has coefficients

    (32/3,38/3,46/3,49/3,43/3,20/3).

Using L<=m J2, the denominator N+ is at most the same coordinate combination with coefficients

    (39/2,27+4m,28,32,27,12).

For m=0,1,2 the minimum of these six coefficient ratios is

    (38/3)/(27+4m)=38/(81+12m).

Thus the lower bound in section1 follows with the correct original full-P+ law. Equation(4) gives the upper bound. The finite R word with all T first exists, so A3>0 and there is no zero-denominator case.

## 6. A weaker input criterion and exact new-moment test

For arbitrary seed counts (without requiring seed moment passing), (3) and L<=m(A2−I) show that

    8A3 >= (4m−3)A2                             (5)

is sufficient for Pr_(P+)(u<b)>=1/3. The 5/9 upper bound remains valid. Equality in (5) is allowed and only guarantees the closed lower endpoint. For m=0 the condition is automatic; for m=1 it is A3>=A2/8, not automatic. This is an original-count sufficient condition, not a theorem about arbitrary abstract moment vectors.

The new T+ has four points, so mu+<=4 automatically. Its own two-moment condition is exactly

    H4+ := e(R+)[3Q2+−8(mu++2)]
          =24A3−12A2+6I−14L−14X−28Y−18A0 >=0.  (6)

The fixed-pair theorem above does NOT require(6); section7 gives a real separation example.

## 10. Pure original-structure sufficient condition (no seed LE computation)

For any A subset T define the C ideal

    C_A={c in C: complete T-signature(c) is a subset of A}.

Define the integer original-structure corridor parameter

    rho=max_(i,j distinct in T)(|C_empty|+|C_{i}|+|C_{i,j}|).

This does not use a chosen extension, moments, or any sampled/canonical suffix. For beta in LE(C), let h_i(beta) be the number of initial C letters not above i, capped at |C| if none is above i. Then

    max_beta sum_(i in T) h_i(beta) = rho.        (7)

For the upper bound, sort roots i,j,k by their first-hit positions in beta, allowing ties and never-hit positions at the end. All letters before the earliest hit have empty support, so h_i<=|C_empty|. All letters before the second hit have support contained in {i}, so h_j<=|C_i|. All before the last hit have support contained in {i,j}, so h_k<=|C_ij|. This also covers simultaneous hits and absent supports.

For the converse fix ordered i,j. The three sets C_empty subset C_i subset C_ij are nested ideals. List their three differences successively before the remaining C letters, using any legal internal extensions. These prefixes avoid respectively every root, both j,k, and k. Consequently h_i>=|C_empty|, h_j>=|C_i|, h_k>=|C_ij|, proving equality after maximizing.

Deleting T from an actual old R word gives beta. All words with K=3 are the six T orders followed by beta; hence A3=6e(C). A word with K=2 has first the two roots other than some i in either order, then j>=1 initial beta letters missing i, then i. For each beta there are exactly 2h_i(beta) such words. Thus

    A2=2 sum_beta sum_i h_i(beta),
    A2/A3<=rho/3.                              (8)

Therefore the following is a sufficient condition entirely in the old original order:

**T3 is an antichain; rho<=4; E is a C ideal of at most two points, each of exact support T−{x}. Then the lift's fixed pair (u,b) is balanced.**

Indeed m<=2 and(8) give 8A3−(4m−3)A2>=8A3−5A2>=(4/3)A3>0. Equations(3) and(4) yield

    1/3 < Pr_(P+)(u<b) <=5/9.

No old seed moment test is required. If degree-budget conditions in section2 hold, this is a genuine D10 sufficient structural class with intrinsic J increased by one. Neither this condition nor the old-moment closure is claimed to cover every B1.

For the V2 source, C_empty is empty. C_{d1}={l}, C_{d2}=C_{d3}=empty; C_{d1,d3}={l,k1,k2}; C_{d2,d3}={h1,h2,h3,h4}; C_{d1,d2}={l}. Hence rho=4 directly from the original signatures. Taking the nonchain E={h1,h2} gives the section8 J18 instance by this pure structural theorem, not just by a new numerical test.
