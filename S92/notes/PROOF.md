# S92：高拥挤不能保留原目标——双门夹层的精确计数与分位点迁移

日期：2026-10-03。父版本为 main 中 S91，数学快照 `dff36d6ec46fc9c14110f0f9660b4642afb00d09`。

**状态：自含研究稿，尚无外部独立审阅或穷尽首创性调查。** MAIN33、一般 WIDTH3 和 TEN40 均未解决；不以 U58 为输入。全参数结果由解析证明承担，程序仅核对真实计数。此次不改写 S91，也不认证全部自动研究稿。

## 0. 本轮选择及准确意义

S91 的低拥挤分支已成立：目标 x 对链的半点切口若很少遇到分割点，就可从该链选平衡伙伴。本轮检查高拥挤分支，发现一个无条件加强不可能成立：即使半点穿越位于中央、拥挤概率趋于 1，所有分割点也可以与 x 可比，且 x 在整个偏序中根本没有平衡伙伴。

这个障碍来自真实宽度二/三偏序，不是任意概率松弛。它要求候选迁移时允许同时更换两个标签。为此，本轮在同一族中推导了真实前缀完成数的分位点选择，得到对所有参数成立的显式跨边界保证。

## 1. S91 的一个直接加强：使用同时碰撞而不只是拥挤

沿用 S91 的记号：C 为 t 点指定链，x 与 C 全不可比；S 含所有对 C 非一致的外部点且 x 不属于 S。概率均来自原 P 的均匀完整扩张。令

    A_r={J_x=r},
    B_(r,b)={存在 s∈S 使 |K_s-r|≤b-1},
    chi_(x,r,b)=Pr(A_r ∩ B_(r,b)),
    alpha_b=binom(2b,b)/4^b。

其中 b≥3，b≤r≤t-b。

**推论 S92-COLLISION。**

    Pr(J_x=r) ≤ alpha_b+(1-alpha_b) chi_(x,r,b)。          (1.1)

特别地 b=3 时，chi≤1/33 足以使该原子≤1/3；半点穿越时，两个链标签之一的平衡度≥11(1-chi)/32。

**证明。** 使用 S91 已证明的完整前后缀分割。设未获得 alpha_b 条件原子界、且 A_r 可能出现的坏纤维总质量为 eta。所有坏纤维整体包含于 B_(r,b)。设 q=Pr(A_r 且处在坏纤维)。则 q≤eta 且 q≤chi，而好纤维的原子贡献≤alpha_b(1-eta)。所以

    Pr(A_r)≤alpha_b(1-eta)+q
           ≤alpha_b+(1-alpha_b)q
           ≤alpha_b+(1-alpha_b)chi。

这只是 S91 纤维证明的直接推论，不认领新的基础反集中原理。chi≤epsilon，保留了 x 与分割点的共同位置；不能用独立边缘的乘积代替它。下面的家族说明：即使改用 chi，高碰撞也不自动产生以 x 为端点的候选。

## 2. 双门夹层族：定义与宽度

取整数 r,q≥1，t=r+q，以及互不相交的有限偏序 A、B，大小分别为 L、M（允许为空）。另取链 C=(c_1<...<c_t) 和三个点 s,x,u。定义 P=P(r,q;A,B)，由以下关系生成并取传递闭包：

    A<s<x<u<B，    c_r<u，    s<c_(r+1)。                (2.1)

A<s 表示每个 A 点都低于 s，u<B 同理；除 A、B、C 的内部关系和这些关系以外，不额外添加比较。

准确关系如下：x 与整个 C 不可比；所有 A、s 都与 C 的前 r 点不可比，却低于后 q 点；所有 u、B 都高于前 r 点，却与后 q 点不可比。所有 P\(C∪{x}) 元素均与 x 可比。

因此 x 的全部不可比伙伴恰好就是 C。

约定空偏序宽度为0。直接按反链所在区域可得

    w(P)=max{2, w(A)+1, w(B)+1}。                       (2.2)

证明：反链不能同时含 A 与 B，也不能将 A 与 s,x,u 混用，或将 B 与 s,x,u 混用。包含 A 的反链最多再加入 C 前段的一点；B 对偶。否则只在 C 与 s<x<u 两条链中，至多两点。反向可用 A 或 B 的最大反链加上相应 C 标签达到上界。

A、B 均为链时宽度二；若二者宽度至多二且至少一个宽度二，则 P 宽度恰三。A、B 内部形状任意时，下节计数仍成立，只是不保证宽度三。

## 3. 全部链秩分布的闭式

令 eA=e(A)、eB=e(B)，空偏序扩张数为1。固定 A、B 各自的一条内部扩张后，只需计数两个内部顺序与 C、s,x,u 的交错；因此所有以下计数乘上 eA eB 即为完整计数。

定义

    f_k = binom(L+min(r,k)+1,min(r,k))
          ·binom(M+min(q,t-k)+1,min(q,t-k)),  0≤k≤t。

**定理 S92-SANDWICH。** 在原 P 的均匀完整扩张律下，

    #{J_x=k}=eA eB f_k，                               (3.1)
    e(P)=eA eB Z，
    Z=binom(L+r+1,r)binom(M+q+1,q)
       ·[1+r/(L+2)+q/(M+2)]。                           (3.2)

### 3.1 计数证明

令 a 为 s 前的 C 点数，b 为 u 前的 C 点数。关系 (2.1) 要求 a≤r≤b。若 J_x=k，则还要求 a≤k≤b。固定 a,b,k 后：

- s 前是 L 个 A 点与前 a 个 C 点的交错，方式数 binom(L+a,a)；
- s 和 u 之间有 C 的第 a+1 至 b 项；x 插在其中第 k-a 个旧点之后，恰有一种位置；
- u 后是 M 个 B 点与余下 t-b 个 C 点的交错，方式数 binom(M+t-b,t-b)。

故所需计数除以 eA eB 后为

    [Σ_(a=0)^min(r,k) binom(L+a,a)]
    ·[Σ_(j=0)^min(q,t-k) binom(M+j,j)]。

两次使用有限二项式求和即得 (3.1)。没有把不同删除偏序的概率分布混合。

### 3.2 归一化和三块概率

令

    F=binom(L+r+1,r)binom(M+q+1,q),
    a0=r/(L+2),    b0=q/(M+2),    d=1+a0+b0。

再次作有限求和得

    Σ_(k<r) f_k = a0 F，
    f_r=F，
    Σ_(k>r) f_k = b0 F。

于是 Z=dF，并有

    Pr(J_x<r)=a0/d，
    Pr(J_x=r)=1/d，
    Pr(J_x>r)=b0/d。                                 (3.3)

这三个量随 L、M 和实际分块长度变化，但不依赖 A、B 的内部形状。形状因子抵消属于自治模块计数的已有背景；本稿不认领该基本原理。

## 4. 高拥挤却无法保留原目标：一个无限反例族

取 r=q=3，L=M=n。则

    p_P(x<c_3)=3/(n+8)，
    p_P(x<c_4)=(n+5)/(n+8)，
    Pr(J_x=3)=(n+2)/(n+8)。                            (4.1)

对于所有 n≥2，第一项严格小于1/3，第二项严格大于2/3。其余链比较概率单调，所以 x 与 C 中任何元素都不平衡。又因 x 与全部非 C 元素可比，

    所有 n≥2：x 在整个 P 中没有任何 1/3 平衡伙伴。     (4.2)

这并不意味着 P 没有平衡对；下面还将显式找到不以 x 为端点的伙伴。

### 4.1 拥挤和同时碰撞的精确概率

S=A∪{s,u}∪B 正好是 C 的所有非一致邻域点，并且 S 中每个点都与 x 可比。r=3、b=3 时，避免拥挤等价于 K_s=0 且 K_u=6：s 必在整个 C 之前，u 必在整个 C 之后。此时 A 全在最前，B 全在最后；s 与 u 之间的 C_6 和 x 有7种交错。

记

    Z_n=binom(n+4,3)^2 · (n+8)/(n+2)。

于是

    epsilon_3=1-7/Z_n →1，
    chi_(x,3,3)=(n+2)/(n+8)-1/Z_n →1。                (4.3)

第二式利用不拥挤的7种中仅1种满足 J_x=3。

所以不仅旧 epsilon 可以很高，改进后的同时碰撞 chi 也可以趋于1；仍不能从 S 中挑出一个与原 x 平衡的点，因为那些点全都与 x 可比。

### 4.2 一个小的宽度三实例

n=2，A 为二点反链，B 为二点链。总点数13，宽度三，e(P)=2000，x 的秩计数为

    (40,160,400,800,400,160,40)。

因而 p(x<c3)=3/10，p(x<c4)=7/10，epsilon3=993/1000。

完整前驱掩码及标签映射见 evidence/check_s92.json。此例不是点数最小性主张。

### 4.3 准确否定范围

否定的是：在所有真实宽度三偏序中，仅凭指定 x 的中央半点穿越和高拥挤/高碰撞，就总能保留 x 并从分割点或全体元素中选到平衡伙伴。

**没有**否定：S91 的低拥挤条件定理；允许同时更换两个标签的候选迁移；只在“全体不可比对均低平衡”反设下额外成立的选择引理。此族并不满足全局低平衡反设。

该族的最大不可比度随 n 增长，不否定固定最大不可比度的特殊结论。虽然 x 自己始终只有6个不可比邻居，也不能把它和整个偏序的最大不可比度混同。

## 5. 正向修复：更换两个标签，用真实前缀完成数选择分位点

下面固定 A 为实际 L 点链 a1<...<aL，B 仍可为任意 M 点偏序。r、q 和 M 任意。比较不再以 x 为端点，而改为 c1 与 A 中的标签。

置 v=q/(M+2)，并对整数 z≥0 定义

    H(z)=(1+v) binom(z+r+1,r)+binom(z+r+1,r-1)。       (5.1)

**精确前缀公式。** 对1≤i≤L，

    Pr_P(a_i<c1)=H(L-i)/H(L)，
    p_i:=Pr_P(c1<a_i)=1-H(L-i)/H(L)。                  (5.2)

### 5.1 为什么这是原律的真实计数，而非删除近似

事件 a_i<c1 发生时，最前面的 i 个点恰为 a1,...,ai：没有 C 点能先于 c1，s 又必须等到整个 A 完成，其他 x,u,B 也不能提前。因此删除这个固定有序前缀，是该事件扩张与 P(r,q;A_(L-i),B) 扩张之间的双射。

方向计数准确等于后者的扩张数。由 (3.2)，其除以 eB 后是 binom(M+q+1,q)H(L-i)；共同因子相消，得到 (5.2)。这里“删除”仅用于一个明确前缀事件的双射，并没有把无条件删除边缘设为均匀。

### 5.2 跳跃界

设 p_0=0，仅作虚拟累计值。由 Pascal 恒等式，

    H(z+1)-H(z)
      =(1+v) binom(z+r+1,r-1)+binom(z+r+1,r-2)，       (5.3)

其中下标<0的二项式约定0。该差分非减，所以

    0≤p_i-p_(i-1)
      ≤[H(L)-H(L-1)]/H(L)
      ≤r/(L+r+1)=:alpha。                            (5.4)

最后一步分别比较 (5.1) 的两个正项：它们的相对后向差分分别为 r/(L+r+1) 与 (r-1)/(L+r+1)。

### 5.3 半点穿越与全参数保证

当 L≥3 时 H(0)/H(L)≤1/2。

证明：H 随 z 递增，只需 z=3。r=1 时 H(z)=(1+v)(z+2)+1，故 H(3)-2H(0)=v≥0。r≥2 时

    binom(r+4,r)≥2binom(r+1,r)，
    binom(r+4,r-1)≥2binom(r+1,r-1)，

第二个比值为 (r+4)(r+3)(r+2)/60≥2，第一个更大；对 (5.1) 分项相加即可。

**定理 S92-QUANTILE。** 若

    L≥max{3,2r-1}，                                  (5.5)

令 i 为使 p_i≥1/2 的最小下标，再在 a_(i-1)、a_i 中选择其与 c1 的概率更接近1/2的那个，所得实际标签 a_j 满足

    bal_P(c1,a_j)≥(L+1)/[2(L+r+1)]≥1/3。              (5.6)

由于 p1≤alpha≤1/3 而 pL≥1/2，i≥2，两个候选都是实际标签，不需使用虚拟 a0。相邻跳跃界给距1/2至多 alpha/2，证毕。

这个保证对全部 q≥1、M≥0 以及任意内部 B 统一成立，不需要假定 q,M 固定后取极限，也不需要枚举它们的参数盒。若 w(B)≤2，整个 P 宽度至多三。半点位置依赖实际整数计数，但对每个给定 P，候选在采样前已固定。

### 5.4 在失衡族中的实际迁移

回到 r=q=3、L=M=n，A 为链。n≥5时满足 (5.5)，虽然 x 没有任何平衡伙伴，仍由 (5.2) 选出 c1 的伙伴：

| n | 选取 A 下标 | p(c1<a_j) | 平衡度 | 统一保证 |
|---:|---:|---:|---:|---:|
|5|2|85/156|71/156|1/3|
|10|3|1139/2184|1045/2184|11/28|
|30|7|113785/227392|113607/227392|31/68|
|1000|207|4706591315/9417576224|同左|1001/2008|

B 的内部形状不改变这些概率。可取 B 为一条 n-1 点链与单点的不交并（n≥2），使整个 P 宽度恰三。

n=1000 例仅是闭式精确算术，不声称运行2009点的通用理想DP。对有界 r、v，H 是 r 次多项式，最先跨过1/2的下标除以 L 趋于 1-2^(-1/r)，所以选点一般不是 s 的固定距离近邻。本稿不使用此渐近作为 (5.6) 的证明。

## 6. 与主猜想的距离、失败尝试和归属

1. 本轮排除了“原目标不变，只换到拥挤分割点”的无条件简化。S91 本来并未证明该加强，故不撤回 S91。
2. 同时更换两个标签在此族可精确完成。核心输入是同一 P 的真实前缀事件双射、两块容量和正差分，不是随机扩张后选标签。
3. 最重要的未证连接仍是：任意严格潜在反例中能否提取这种可控结构，或把一般高拥挤区域的完成数压成可用的正差分剖面。没有全局二分闭合，也没有有界次数迁移/终止证明。
4. A、B均为链时属于已知宽度二范围；B为非链自治块时可能已有内部平衡对。因此本轮不将该族的全局定性1/3存在性登记为新的未知类别突破。贡献定位为：准确目标选择障碍、全参数目标秩闭式、针对指定跨块标签的有效选择与 uniform-in-tail 界。
5. 双块内部扩张数因子、有限二项式求和和理想前缀双射属于既有计数背景。S91纤维定理是§1实际输入；§2–5完全自含，不使用U58或新大宽度定理。
