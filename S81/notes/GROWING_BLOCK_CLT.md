# S81：增长自治块的缺陷判别与正确高斯波动

日期：2026-10-01。解析研究稿；未获外部独立审查或全面查新。本文使用 S78/S79 已展开的凸序，不使用 U58、ACPP 全局选点或任何有限验收核。

## 1. 先区分三个量，不能删掉辅助噪声

对第 n 个有限偏序中的 r_n 点自治块，记 q_n=r_n+1、完整块窗口 Z_n=L_n+r_n、μ_n=EZ_n、θ_n=μ_n/q_n。所有离散概率来自同一原偏序的均匀完整扩张，删除纤维按 e(M) C(L+r−1,r) 加权。外部大小、宽度、块内部形状均可变化。

S79 给出辅助指数间隔和 T_n，使

    T_n | Z_n ~ Gamma(Z_n,1),
    ET_n=μ_n,
    T_n <=cx G_n ~ Gamma(q_n,θ_n).

定义

    D_n=μ_n(μ_n−q_n)/q_n−Var Z_n >=0.

于是 Var T_n=Var Z_n+μ_n，Var G_n=q_n θ_n²，Var G_n−Var T_n=D_n。Gamma 第二参数为尺度。Strassen 耦合可取 E(G_n|T_n)=T_n，故 E(G_n−T_n)²=D_n。

关键警告：E(T_n−Z_n)²=μ_n。若 q_n→∞、θ_n→θ>1，在 sqrt(q_n) 尺度上这个噪声的方差趋于 θ，不会消失。因此由 T_n 近 Gamma 的 CLT 不能直接把 Z_n 的波动方差写成 θ²；正确的离散方差系数是 θ(θ−1)。

## 2. 主定理 S81-BLOCK-CLT

假设 q_n→∞ 且 θ_n→θ∈(1,∞)。那么以下两件事等价：

    D_n/q_n → 0;

    (Z_n−μ_n)/sqrt(q_n θ_n(θ_n−1))
        → N(0,1) in W₂.

W₂ 表示二阶 Wasserstein 收敛；等价于弱收敛加二阶矩收敛。本文没有声称离散律对连续高斯的总变差趋零——那种总变差始终为 1。也没有给一般 W₂ 显式收敛速率。

### 2.1 辅助 Gamma 的中心极限

鞅耦合给

    E[((G_n−μ_n)−(T_n−μ_n))/sqrt(q_n)]² = D_n/q_n.

直接展开 Gamma 特征函数

    e^(−iuθ_n sqrt(q_n)) (1−iuθ_n/sqrt(q_n))^(−q_n)
      → exp(−θ²u²/2).

所以 D_n/q_n→0 蕴含 (T_n−μ_n)/sqrt(q_n) ⇒ N(0,θ²)。到这里尚未得到 Z_n 的结论。

### 2.2 正确撤销 Erlang 噪声

写 q=q_n、θ=θ_n。在 |u|/sqrt(q)≤1/2 时，令

    a=−log(1−iu/sqrt(q)),
    b=iu/sqrt(q)−u²/(2q).

两个指数的实部均不大于零，并且 |a−b|≤2|u|³/(3q^(3/2))。因而对整数 Z≥0，积分差值有 |e^(Za)−e^(Zb)|≤Z|a−b|。取期望后误差≤2θ|u|³/(3sqrt(q))。

又由 Var Z≤qθ(θ−1)，

    E|Z/q−θ|≤sqrt(θ(θ−1)/q).

设 φ_T(u)=E exp[iu(T−μ)/sqrt(q)]，φ_Z 类似。以上两式给出

    |φ_T(u)−e^(−θu²/2)φ_Z(u)|
       ≤ [2θ|u|³/3 + (u²/2)sqrt(θ(θ−1))]/sqrt(q).       (1)

故主定理假设下

    φ_Z(u) → exp[−(θ²−θ)u²/2].

Lévy 连续性定理给 (Z_n−μ_n)/sqrt(q_n) ⇒ N(0,θ(θ−1))。

### 2.3 二阶矩与逆方向

精确地，

    E[(Z_n−μ_n)/sqrt(q_n)]²
       =θ_n(θ_n−1)−D_n/q_n.

所以正向同时有二阶矩收敛，推出 W₂ 收敛。反过来，主定理所述标准化的 W₂ 收敛迫使二阶矩趋于 1，代入本式便得到 D_n/q_n→0。逆方向不能只写成弱收敛而不检验二阶矩。

## 3. 可计算的特征函数误差，不冒称 TV 或 W₂ 速率

在 |u|max(1,θ)/sqrt(q)≤1/2 时，Gamma 对数特征函数的相同展开给

    |φ_Z(u)−exp[−θ(θ−1)u²/2]|
    ≤ exp(θu²/2) { |u|sqrt(D/q)
       + [2θ|u|³/3 + (u²/2)sqrt(θ(θ−1))
          + 2θ³|u|³/3]/sqrt(q) }.                     (2)

这清楚分开“窗口凸序缺陷”和“有限块的 Gamma/Erlang 近似误差”。固定频率的控制不直接给相同速率的总变差。

## 4. 真实偏序实现，以及局部与宏观块的差别

令 P=A_m ⊔ B_k，A_m 是任意 m 点偏序，B_k 为 k 点链，两部分全部不可比。置 s=k+1。其二色词均匀，每个词有 e(A_m) 个原像。

对任意连续 r=q−1 个 B 元素的自治块，S79 的精确联合计数给

    Z = q + BetaBinomial(m,q,s−q),
    μ=q(1+m/s),
    Var Z=q(s−q)m(m+s)/[s²(s+1)],
    D=q(q+1)m(m+s)/[s²(s+1)].                         (3)

q=s 时 BetaBinomial 第二形状为零，应单独按 Z=m+s 常量处理，不写普通 Beta 密度。

若 m/s→γ>0、q→∞ 且 q/s→0，则 θ→1+γ、D/q→0。主定理得到

    (Z−q(1+m/s))/sqrt(q(m/s)(1+m/s)) → N(0,1) in W₂.

这是从 S79“固定大小块的负二项极限”到“块大小也无界增长的高斯波动”的推广；A_m 内部可以任意变化，不必形成同一个可数偏序的穷尽。

若 q/s→α∈(0,1)，则 D/q→αγ(1+γ)>0。不能使用前述无修正方差。正确极限为

    (Z−μ)/sqrt(q(m/s)(1+m/s))
        → N(0,1−α) in W₂.                            (4)

简证：令 Θ~Beta(q,s−q)，给定 Θ 后 Z−q~Bin(m,Θ)。独立 Gamma 和的 CLT 与一阶代数展开给 sqrt(s)(Θ−q/s)⇒N(0,α(1−α))。条件二项噪声的特征函数在 Θ→α 时收敛到 N(0,γα(1−α))，并与前项渐近独立；m(Θ−q/s)/sqrt(s) 给方差 γ²α(1−α)。合计为 γ(1+γ)α(1−α)，再除以 q/s→α 得 (4)。精确方差 (3) 提供二阶矩收敛。

最后 q=s 时整个窗口恒为 m+s，波动为零。这不是主定理反例，而是说明小缺陷条件不能省略。有限总体修正 1−α 是真实守恒的效应，不是需要消除的计算误差。

## 5. 对主猜想的实际含义与边界

本定理识别窗口波动，不声称从高斯窗口直接获得平衡对，也不要求/推出全局低平衡。它适用于满足 D/q→0 的实际偏序序列；尚未证明潜在反例会产生这些近等号块。

从“Gamma 边缘 CLT”直接套到 Z 会多出方差 θ；从“固定块局部极限”套到宏观块会漏掉 1−α。这两种都是明确排除的证明捷径，不是撤回旧稿中已带条件的结论。

经典输入是 Strassen、Gamma/Beta 与二项分布的特征函数及 CLT、弱收敛加二阶矩与 W₂ 的等价性。本文对自治窗口缺陷的应用与等价判别未完成优先权调查，不宣称文献首创。
